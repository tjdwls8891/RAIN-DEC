# 코드가 모르는 행동의 일반 경로

> **이 문서의 구현은 지웠다.** 동작을 열거한 것이 설계 위반이었다([40](40-행동을-열거한-잘못.md)). 다시 쓴 것은 [41](41-사전-위의-턴.md)이다. 경위와 실측 수치로만 남긴다.

2026-11-14. [37](37-뼈대와-이어-돌린-실측.md)의 가장 큰 빈자리(동작의 목록)에 대한 첫 답이다.
코드가 아는 동작이 아니어도 턴이 서게 하되, **세계를 바꾸는 것은 코드가 낸 후보 안에서만** 일어나게 한다.

- 코드: `raindec/engine.py`의 `generic`, 그리고 목록에 없는 대상의 처리. 시험 30개 통과.
- 누적 추정 지출: 약 340원.

## 1. 방식

```
해석:  동작이 목록에 없으면 "그밖"으로, PC가 하는 일을 선언의 말 그대로 적는다. 대상과 상대(둘째 것)를 고른다
코드:  대상과 상대의 종류에서 "바뀔 수 있는 것"의 후보를 만든다
         자리  — PC의 손에 / 바닥에 / 상대의 손에 / 상대 곁의 바닥에 / 상대(용기) 안에 / 상대(지점) 위에 / 그대로
         상태  — 흠이 난다 / 부서진다 / 잠금이 풀린다 / 열린다 / 닫힌다
판단:  닫힌 물음에 고른다
         성립(뻔히 된다 / 판정이 필요하다 / 될 수 없다) · 능력 · 난이도 · 방법
         되면 자리(하나만) · 되면 바뀌는 것(여럿) · 소리 · 곁에 있는 인물의 반응
         뜻한 결과의 핵심이 후보로 담기는가
코드:  판정하고, 성공하면 고른 것만 장부에 반영한다. 걸린 것은 고른 후보의 글로 보인다
```

| 원칙 | 뜻 |
| --- | --- |
| 후보 밖의 변화는 일어나지 않는다 | 판단이 무엇을 답하든 장부에 들어가는 것은 코드가 만든 후보뿐이다 |
| **장부가 담지 못하는 결과는 전하지 않는다** | 핵심이 후보에 없으면 "뜻대로 되지 않는다"로 끝내고 저작자의 목록에 적는다. 전한 것은 사실이어야 한다 |
| 제 몸으로 하는 몸짓은 지나간다 | 앉는다, 숨을 고른다. 판단을 부르지 않는다 |
| 지닌 것은 장부가 안다 | 지닌 것을 꺼내는 일은 코드가 한다. 지니지 않은 것("품에서 관아의 패를 꺼낸다")은 판단에 묻지 않고 없다 |

**목록에 없는 대상**

| 판단이 고르는 것 | 처리 |
| --- | --- |
| 이미 있는 것의 일부나 다른 이름 ("자물쇠" → 뒷문) | 그것을 대상으로 삼아 이어 간다 |
| 여기에 없다 | "보이지 않는다" |
| 저작되지 않았으나 있을 법하다 | **아직 없다.** 확정의 사다리의 "채움"이다. 세계에 대해 아무것도 전하지 않고 저작자의 목록에 적는다 |

## 2. 돌려 본 것 (3 flash)

| 선언 | 일어난 일 |
| --- | --- |
| 나무 의자를 계산대 쪽으로 옮겨 놓는다 | 뻔히 된다. 의자가 계산대로 갔다 |
| 찻주전자를 삿갓 쓴 사내 쪽으로 던진다 | 판정(민첩, 보통, 기준 60). 아슬한 성공. 찻주전자가 사내의 손에 넘어갔다 |
| 의자로 뒷문 자물쇠를 내리쳐 부순다 | "자물쇠"를 뒷문으로 이었다. 판정(근력, 어려움, 방법 나쁨, 기준 35). 걸린 것: "뒷문이 흠이 난다, 뒷문의 잠금이 풀린다". 36이 나와 아슬한 실패. 주모가 막아섰다 |
| 검을 뽑아 든다 | 판단 없이. 철검이 손에 |
| 바닥에 주저앉아 숨을 고른다 | 판단 없이 지나갔다 |
| 찻주전자를 들보 위에 올려 둔다 | 들보가 세계에 없다. 핵심이 후보에 없어 "뜻대로 되지 않는다" |
| 품에서 관아의 패를 꺼내 주모에게 보여 준다 | 처음에는 판단이 "있을 법하다"를 골랐다(**역사칭이 통할 뻔했다**). 지닌 것은 코드가 가리게 고쳤다 |

- 판단이 든 턴: 첫 글자까지 3.9~4.9초, 5~7원. 목록에 없는 대상이면 판단을 한 번 더 부른다.

## 3. 돌려 보며 고친 것

| 본 것 | 고침 |
| --- | --- |
| "사내의 손에 넘어간다"와 "곁의 바닥에 떨어진다"를 함께 골랐다 | 자리는 하나만 고르게 물음을 나눴다 |
| 판단이 곁가지(튀는 찻물)를 "후보에 없는 변화"에 적자 행동 전체가 막혔다 | "핵심이 담기는가"를 따로 닫힌 물음으로 물었다. 곁가지는 저작자의 목록으로만 간다 |
| 들보에 올려 두지 못했는데 서술은 올려 뒀다고 썼다 | PC가 "하려 한 일"과 "된 것"을 재료에서 갈랐다 |
| "뒷문으로 간다"가 문을 지나가려는 것으로 처리됐다 | 문을 대상으로 한 "간다"는 다가가는 것. 지나가려는 말이 있을 때만 너머로 |
| 문에 달린 자물쇠를 가리키자 "자물쇠는 보이지 않는다"고 전했다 | 목록에 없는 대상을 판단에 물어 있는 것의 일부면 잇는다 |

## 4. 남은 문제

| # | 문제 | 뜻 |
| --- | --- | --- |
| 1 | **후보의 종류가 곧 자유도의 한계다** | 지금 후보는 자리와 상태 다섯뿐이다. 불을 끄는 것, 적시는 것, 묶는 것, 사람을 붙잡는 것은 "담지 못한다"로 끝난다. 후보는 상태·특성의 목록(4단계)에서 나와야 한다 |
| 2 | **부분이 개체가 아니다** | 자물쇠는 뒷문으로 이어지지만 "자물쇠만 부순다"와 "문을 부순다"가 갈리지 않는다. 항목표의 구성요소가 필요하다 |
| 3 | 없는 것의 채움이 없다 | 들보처럼 있을 법한 것. 확정의 사다리의 마지막 단 |
| 4 | 난이도가 너그럽다 | 천장까지 뛰어오르는 일을 "보통"으로 골랐다. 물건·환경을 상대로 한 난이도도 저작된 항목(높이, 견고함)에서 나와야 한다 |
| 5 | 사람의 몸을 건드리는 일 | 싸움, 붙잡기, 빼앗기는 아직 없다 |
| 6 | 인물이 스스로 움직이지 않는다 | 찻주전자를 받아 든 사내는 그것을 든 채 그대로다. 인물도 같은 경로로 행동해야 한다 |
| 7 | 정도가 귀결에 쓰이지 않는다 | 아슬한 성공과 큰 성공이 같은 결과다 |
