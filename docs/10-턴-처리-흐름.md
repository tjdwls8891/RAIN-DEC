## 2. 역할

| 역할 | 보는 것 | 하는 일 | 호출 |
| --- | --- | --- | --- |
| **심판** | 진실 | 선언을 단계로 옮긴다. 판정을 설계한다. 주목을 정한다. 주목 안의 인물을 움직인다 | 턴마다 한 번 |
| **인물** | 그 인물의 앎만 | 자기 이해관계가 걸린 결정을 내린다 | **결정의 순간에만** |
| **서술자** | PC가 지각한 것만 | 산문 | 턴마다 한 번 |
| **엔진** (코드) | 전부 | 단계 실행, 전제 검사, 역량 계산, 주사위, 시간, 기록, 실패 처리 | — |

- 심판 하나가 "모든 것을 아는 층위"다. 큰 시나리오에서는 심판에만 세계 전체를 캐시로 줄 수 있다 (§8).
- v0.1의 "장면의 주요 인물마다 별도 호출"은 버렸다. 이유는 [21](21-주목-대기-실패.md) §4.

## 3. 한 턴

```
선언
 │                                              ┐
 ├─ ① 심판          단계 계획, 주목, 판정 설계   │ 대기 ①
 ├─ ② 실행 (코드)   단계를 차례로. 멈출 곳에서 멈춘다
 │      ├─ 판정이 필요하면 → 버튼 제시 ─────────┘
 │      │      (플레이어가 누른다 — 대기가 아니다)
 │      │                                       ┐
 │      └─ 굴림, 결과 적용                       │
 ├─ ③ 인물          결정의 순간일 때만           │ 대기 ②
 ├─ ④ 정리 (코드)   PC가 지각한 것을 모은다      │
 ├─ ⑤ 서술자        산문을 흘려보낸다 ───────────┘ (첫 문장이 나오는 순간까지)
 └─ ⑥ 마감 (코드)   한 번에 확정, 상태판 갱신
```

- 판정이 없는 턴은 대기가 하나다: 선언 → 서술의 첫 문장.
- 대기 안에 순차로 놓이는 LLM 호출은 **최대 둘**이다 (심판 → 서술의 시작, 또는 인물 → 서술의 시작).
- 구 세션 기록의 실측으로는 세계 전체를 읽는 호출 하나가 약 9초였다. 이 구조가 15초 안에 드는지는 **측정해야 안다.** [잠정]

### 가장 빠른 첫 반응

- 매 턴의 첫 줄은 **해석의 되읽기**다 ("임성진님은 배낭에서 헬멧을 꺼내 머리에 썼습니다").
- 이 줄은 심판이 낸 단계에서 나온다. 서술자를 기다리지 않고 먼저 보낼 수 있다.
- 플레이어는 자기 선언이 어떻게 이해됐는지를 가장 먼저 안다. 잘못 이해됐다면 긴 서술이 나오기 전에 바로잡을 수 있다. [제안]

## 4. 심판과 단계 계획 [제안]

심판은 선언을 **단계의 목록**으로 옮긴다. 각 단계에는 전제, 걸리는 시간, 남는 것, 판정이 필요한지가 붙는다.

```
선언: "물을 마신다"

단계 1  배낭에서 물병을 꺼낸다     따르는 행동
단계 2  뚜껑을 연다                따르는 행동
단계 3  물을 마신다                선언한 행동      남는 것: 물 −200ml, 갈증 완화
```

### 따르는 행동과 없는 선택 [확정된 선]

| | 예 | 처리 |
| --- | --- | --- |
| 선언에 **따르는** 행동 | 뚜껑을 연다, 배낭에서 헬멧을 꺼낸다 | 심판이 단계로 넣는다. 서술해도 된다 |
| 선언에 **없는 선택** | 멈춘다, 망설인다, 무기를 고쳐 쥔다, 주위를 살핀다 | 넣지 않는다. 서술하지 않는다 |
| 되돌릴 수 없는 따르는 행동 | 자물쇠를 부순다, 하나뿐인 약을 쓴다 | 확인을 묻는다 |

- 가르는 기준: **그 행동 없이는 선언한 행동이 성립하지 않는가.**

### 엔진이 멈추는 곳

| 멈춤 | 다음 |
| --- | --- |
| 단계의 전제가 거짓이다 | 그 자리에서 끝. 뒤 단계는 일어나지 않는다. 막힌 길에서 임의로 우회하지 않는다 |
| 판정이 필요하다 | 버튼을 제시한다 |
| 판정에 실패했다 | 그 자리에서 끝 |
| 다른 인물이 반응할 수 있다 | 인물이 반응하고, 서술한 뒤 유저에게 넘긴다 |
| PC가 새로 지각한 것이 있다 | 서술한 뒤 유저에게 넘긴다. 단, 비가 내리기 시작하는 정도는 서술로 넘기고 계속한다 |
| 되돌릴 수 없는 단계인데 유저가 말하지 않았다 | 확인을 묻는다 |
| 단계를 만들 수 없다 | 되묻는다. 뜻을 확인하는 질문만 하고, 새 목표를 권하지 않는다 |

- "들키면 달아난다" 같은 조건부 선언은 PC가 품은 **의도**로 남긴다. 조건이 맞으면 그대로 할지 묻는다. 엔진이 대신 실행하지 않는다.
- 직전에 실패한 단계와 전제·방법이 같은 단계는 다시 굴리지 않고 같은 결과다. 방법이나 도구가 다르면 새 단계다.
- 실패는 "없다"를 만들지 않는다. 찾지 못한 것과 없는 것은 다르다.
- 세계에 대한 단정("열쇠를 발견했다")은 시도("찾아본다")로 바꾼다.
- 규칙 질문이나 진행에 대한 말은 세계의 시간을 움직이지 않는 다른 길로 보낸다.

### 열린 문제

- **한 턴에 판정이 둘 이상 필요한 계획.** 버튼을 연달아 낼지, 첫 판정 뒤에 멈추고 넘길지 정하지 않았다.
- **심판 한 호출의 부담.** 해석, 단계, 전제, 판정 설계, 주목, 인물의 반응까지 한다. 품질이 떨어지면 나눠야 하고, 나누면 대기가 는다.

## 5. 판정 [제안 — 뼈대만]

- **굴리는 문턱을 높인다.** 뻔한 일에 굴리지 않는다. 구 세션 기록에서는 성공률 80%가 넘는 판정이 대부분이었다.
  위험도 없고 실패해도 달라질 것이 없으면 판정이 아니다.
- **심판은 둘만 판단한다**: 이 일이 얼마나 어려운가, 이 방법이 얼마나 좋은가. 각각 장부의 사실을 근거로 든다.
- **나머지는 코드가 장부에서 센다**: 능력, 숙련, 장비, 상태. 그 판정의 분야에 해당하는 것만.
  코드가 아는 사실을 심판이 다시 세지 않으므로 같은 사실이 두 번 반영될 자리가 없다.
- **효과의 크기는 굴리기 전에 정한다**: 성공하면 얼마나 이루는가, 실패하면 무엇을 잃는가.
- **결과는 넷**: 성공 / 대가가 따르는 성공 / 실패 / 대가가 큰 실패. 맞서는 일에는 양쪽 다 얻지 못하는 결과가 있다.
- 플레이어의 추측이나 추리는 판정 대상이 아니다. 엔진은 PC를 대신해 추론하지 않는다. PC가 **아는 지식**을 묻는 것은 답할 수 있다.

### 주사위의 눈 [확정]

| 경우 | 눈 |
| --- | --- |
| 같은 턴 안에서 기술적 실패로 다시 시도 | **유지한다.** 플레이어가 누른 결과는 장애로 바뀌지 않는다 |
| 되감기 뒤 다시 선언 | **다시 굴린다** |

- 주사위의 종류, 성공 가능성의 표, 버튼에 무엇을 보여 줄지는 정하지 않았다.

## 6. 주목과 정산 [제안 · 잠정]

> 엔진은 **주목 안**에 있는 것만 세밀하게 다룬다. 주목 밖의 것은 **주목이 돌아올 때 정산**한다.

1. 심판이 이번 턴의 주목을 정한다. PC가 상대하는 인물과, 이번 턴에 무언가를 걸고 있는 인물. 보통 하나에서 셋.
2. 주목 안의 인물은 심판이 움직인다. 심판은 그 인물의 앎, 목표, 감정을 **따로 떼어** 받고 그 안에서 반응을 정한다.
3. **결정의 순간**에는 그 인물을 따로 호출한다. 인물의 이해관계가 유저의 바람과 정면으로 부딪히는 선택일 때다.
   그 호출은 그 인물의 앎만 받는다. 실패하면 심판의 판단으로 물러선다.
4. 주목 밖의 인물은 무리로 남는다. 서술자는 무리를 배경으로만 쓴다.
5. 주목이 돌아오면 정산한다. 그 인물의 목표와 그 사이에 실제로 전달된 것에 맞춰, 그동안 보고 한 일을 한 번에 정한다.

- 설득과 협박이 통하는지는 주사위가 아니라 인물이 정한다. 주사위는 **불확실한 지각**(거짓말을 눈치챘는가)에 쓰고, 그 결과가 인물의 판단에 들어간다.
- PC와 다투는 인물의 행동(달려든다, 붙잡는다)은 **시작만** 이번 턴에 반영한다. 유저가 대응을 선언하면 다음 턴에 함께 해소한다.
- 인물은 배경 → 단역 → 주요로 해상도가 오른다. 승격의 계기와 채우는 순서는 [17](17-통찰과-새-설계.md) §5.5.
- 앎은 계승이 아니라 전달로만 퍼진다. 상식과 규범만 물려받는다.

### 측정으로 가를 것

같은 장면을 세 방식으로 돌려 순응, 누설, 대기, 비용을 잰다: (가) 심판이 전부 / (나) 결정의 순간에만 호출 / (다) 주목 안의 인물마다 호출.
측정 전의 잠정안은 (나)다.

## 7. 서술 [제안]

### 서술자가 받는 것

- 해석의 되읽기와 실행된 단계
- **이번 턴에 PC가 새로 지각한 것** — 서술의 중심
- 인물의 말과 겉으로 드러난 행동
- 세계의 신호 (멀리서 보이고 들리는 것)
- 장면의 감각 재료. 이미 여러 번 쓴 것은 **"이미 썼다"는 표시**와 함께
- 유저가 밝힌 PC의 내면
- 문체 지침

### 서술자가 받지 않는 것 (구조로 막는다)

- PC가 모르는 사실. 숨겨진 것, 남의 속마음.
- **PC가 모르는 이름.** 개체의 식별자와 "PC가 아는 호칭"은 따로 있다. 서술자는 호칭만 받는다. 이름을 모르는 사내는 문맥에서도 "삿갓 쓴 사내"다.

### 서술자가 하지 않는 것 (지시와 검사로 막는다)

| 금지 | 구 기록의 사례 |
| --- | --- |
| PC의 선택을 지어내기 | "발걸음은 그 기괴한 리듬 앞에 멈춰 섭니다" |
| PC를 대신해 결론 내리기 | "외부로부터의 침입 가능성이 희박함을 알리는 침묵의 증거입니다" |
| 재료에 없는 사람·물건·출입구 만들기 | — |

- 이 셋은 구조로 막을 수 없다. 자동 검사의 항목으로 두고 비율을 잰다.

### 분량과 되풀이

- 지향은 턴당 700~1,100자다. [확정]
- 다만 구 기록에서는 "옷차림을 본다"에도 네 문단이 나오고 그중 둘이 앞 턴의 되풀이였다.
  **채울 새것이 없으면 줄인다**를 제안한다. 분량의 지향과 되풀이의 방지가 부딪힐 때 어느 쪽이 우선인지는 사용자 확인이 필요하다.
- 세계의 신호와 압박은 서술자가 지어내는 것이 아니라 받아야 하는 재료다. 그 재료가 어디서 오는지는 화면 밖 세계의 진행에 달려 있고, 그 영역은 **보류** 중이다.

### 서술이 지어낸 세부 [보류]

- 서술이 재료에 없는 질감을 더했을 때 그것을 어떻게 기록하는가(P4의 실현 방식)는 보류다.
- 범위를 좁히는 후보(닫힌 범위)는 [17](17-통찰과-새-설계.md) §5.2에 있다.

## 8. 캐시 [제안 · 선택]

- 캐시 없이도 도는 구조를 기본으로 한다. 사용자의 전제("안 쓸 수 있으면 좋다")를 따른다.
- 큰 시나리오에서는 **심판에만** 세계 전체를 캐시로 준다. 그 뒤에 "개설 이후 변한 것"과 이번 장면을 붙인다.
- 인물의 호출과 서술자에게는 주지 않는다. 비밀이 들어 있기 때문이다.
- 변화가 쌓이면 캐시를 다시 만든다.
- 근거가 되는 실측: 영도 전체가 약 4만 3천 토큰, 그것을 읽는 호출 하나가 약 18원·9초 ([20](20-구-세션-기록-관찰.md)).

## 9. 실패 [제안]

1. 어떤 실패도 세계를 반쯤 바꾼 채 남기지 않는다. 턴의 변화는 ⑥에서 한 번에 확정된다.
2. 이미 한 일은 다시 하지 않는다. 서술자가 실패했다고 심판부터 다시 돌리지 않는다.
3. 덜 중요한 역할의 실패가 턴을 막지 않는다.
4. 플레이어는 언제나 지금 무슨 일이 벌어지는지 안다.

| 역할 | 물러서는 순서 |
| --- | --- |
| 심판 | 다시 시도 → 다른 모델 → 플레이어에게 알리고 선언을 보존 |
| 인물 | 다시 시도하지 않고 심판의 판단으로 |
| 서술자 | 다시 시도 → 다른 모델 → 짧은 서술 → 되읽기 한 줄과 확정된 사실만 |
| 턴 뒤의 일 | 밀린 채로 다음 턴을 받는다 |

- 실패의 종류별 대응(과부하, 빈 응답, 끊긴 응답, 깨진 형식, 시간 초과, 안전 필터)은 [21](21-주목-대기-실패.md) §6.
- 호출마다 시간 상한을 둔다. 상한은 대기 허용선에서 거꾸로 계산한다.
- 검사에 걸린 제안은 실패가 아니다. 걸린 것만 버리고 나머지로 진행한다.

## 10. 측정할 것

Gemini를 부를 수 있게 되면 가장 먼저 잰다.

| 항목 | 방법 |
| --- | --- |
| 대기 ①, 대기 ② | 선언 → 버튼 또는 첫 문장 / 버튼 → 첫 문장 |
| 턴당 비용 | 역할별 토큰과 캐시 |
| 제안이 검사를 통과하는 비율 | 심판이 낸 단계와 변화 가운데 거부된 것 |
| 주권 침범 | 서술에서 PC의 선택을 지어낸 문장의 비율 |
| 대신 추론, 이름 누설 | 같은 방식 |
| 되풀이 | 직전 턴들과 겹치는 표현의 비율 |
| 순응 | 숨길 것이 있는 인물이 압박에 얼마나 쉽게 무너지는가 (§6의 세 방식 비교) |
| 굴림의 빈도와 성공률 분포 | 뻔한 판정이 남발되는지 |
