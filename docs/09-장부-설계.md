# 장부 설계 (통합본 v0.2)

2026-11-12. 세계 표현의 형식을 정한다. **[제안 — 종이 위에서 14개 영역 시험 통과, 구현 검증 전]**

- v0.1은 사용자 재설계 자료를 보기 전에 쓴 독자안이었다. (이전 판은 git 기록에 있다.)
- v0.2는 14개 영역의 형식 시험([12](12-형식-시험-물건과-장소.md), [13](13-형식-시험-나머지-열두-영역.md))에서 나온
  개정 사항 열셋과 [조건 언어](14-조건-언어.md)를 반영해 고쳐 썼다.
- 표기 예시는 개념을 보이기 위한 것이고 최종 문법이 아니다.

## 1. 설계 목표

- 형식은 하나다. 새 장르·새 개념이 오면 **형식이 아니라 어휘가 늘어난다.**
- 코드가 다루는 사실은 해석이 하나뿐이다.
- 호출마다 필요한 조각만 골라낼 수 있다.
- LLM은 장부를 직접 고치지 못한다.

## 2. 여섯 가지 구성 요소

| 요소 | 무엇인가 | 누가 만드는가 |
| --- | --- | --- |
| **개체** | 정체성을 가진 모든 것 | 틀에서 찍혀 나옴, 플레이 중 생성 |
| **사실** | 개체에 대한 한 줄의 참 | 틀, 사건의 결과 |
| **정의** | 어휘. 어떤 속성이 있고 어떻게 행동하는가 | 엔진 공용 + 시나리오의 수정·추가 |
| **사건** | 일어난 일의 기록. 덧붙이기만 한다 | 턴 처리 |
| **시야** | 명제를 담는 것. 형식은 장부와 같다 | 지각, 전달 |
| **틀** | 빈칸 있는 사실 묶음 | 엔진 공용 + 시나리오 |

## 3. 개체

- 식별자와 **표지** 여럿을 가진다. 표지는 계층이 아니다 (`인물`, `무림인`, `용기`, `의복` …). 한 개체가 여러 범주에 속할 수 있다.
- 다음이 모두 개체다.

| 종류 | 예 |
| --- | --- |
| 인물, 세력 | 강호민, 흑풍채 |
| 장소, 지점, 통로 | 객잔 1층, 창가, 뒷문 |
| 분류 헤드 | 강남 저잣거리류 (장소가 아니며 속성을 물려주는 머리) |
| 물건 | 약통, 물병, 외투 |
| 현상 | 화재, 폭우 |
| 부상, 질병 | 왼팔의 자상, 감염 |
| 계획, 사건의 진행, 과업 | 흑풍채의 습격 계획, 진행 중인 매복 |
| 명제를 담는 것 | 소문, 편지, 단서 |

- **지점**은 최하위 장소 안의 가벼운 개체다. 필요할 때 생긴다. 세밀한 위치는 최하위 장소 안에서만 다룬다.

## 4. 사실

```
속성(주체) = 값
속성(주체 → 대상) = 값         # 대상은 개체 또는 어휘 항
                                 + 언제부터(–언제까지) · 어느 사건에서 비롯
```

```
피로(강호민) = 높음
숙련(강호민, 검술) = 상
호감(주모 → 강호민) = 경계
수량(물#3) = 350ml
피복(겨울외투) = [몸통, 양팔]
경계(객실_3호 ↔ 객실_4호) = "얇은 판자벽"
시각(사건#398) = 3일차 밤 무렵
앞섬(사건#398 → 사건#401) = 직전
```

### 값의 종류

| 종류 | 예 | 코드가 읽는가 |
| --- | --- | --- |
| 등급·수치 | 높음, 14 | 예 |
| 단위 있는 양 | 350ml, 12정 | 예 |
| 열거 | 비, 착용 | 예 |
| 집합 | [몸통, 양팔] | 예 |
| 개체 참조 | 객잔_1층 | 예 |
| 시간 (범위 허용) | 3일차 21:40, 3일차 밤 무렵 | 예 |
| 명제 | «위치(범인) = 보트창고» | 예 (참으로 취급하지 않음) |
| 서술문 | "쉰 줄의 여인. 손등에 화상 자국." | **아니오** |

- 서술문은 **묘사 재료로만** 쓰인다. 해석이 갈릴 수 있는 것은 서술문 안에만 있다.
- 긴 세계관 설명도 개체에 딸린 서술 사실로 **쪼개어** 둔다.
- 사건도 사실의 주체가 될 수 있다 (사건 사이의 선후 관계).
- 대칭 관계(`↔`)인지는 정의가 정한다.

### 위치는 하나의 관계다

```
위치(무엇 → 어디) = 방식
```

```
위치(강호민 → 창가) = 곁에
위치(창가 → 객잔_1층) = 안에
위치(객잔_1층 → 만리객잔) = 안에
위치(철검 → 강호민) = 손에
위치(외투#2 → 강호민) = 착용
위치(물#3 → 물병#1) = 안에
위치(건전지#4 → 손전등#1) = 장착
위치(부상#7 → 강호민) = 왼팔
```

- 방 안의 사람, 손에 든 검, 병 속의 물, 건물 안의 방, 몸의 상처가 같은 관계다.
- "손에 든 것 / 착용한 것 / 지닌 것"의 구분은 **방식**이다.
- 이동 연결은 포함과 별개다. **통로** 개체가 두 장소를 잇고, 잠김·막힘·숨김을 가진다.

## 5. 정의

속성 하나하나는 정의를 가진다. 공용 항목이 사는 곳이다.

```
정의: 피로
  값: 등급 [없음, 낮음, 보통, 높음, 극심]
  적용 대상: 인물
  겉보기: 관찰하면 보임
  계승: 아니오
  기제: 게이지 — 활동 시 상승, 휴식 시 하강
  규칙:
    동안: 피로(이것) 이상 높음
      효과: 보정 — 신체 판정에 불리
  묘사 단서: 높음 = "눈꺼풀이 무겁고 동작이 굼뜨다"
```

- **적용 대상**: 이 속성이나 상태가 붙을 수 있는 개체의 조건.
- **겉보기**: 누구나 보임 / 관찰하면 보임 / 숨겨짐. 지각 판단의 근거.
- **계승**: 값이 없을 때 위에서 가져오는가 (§8).
- 행동은 세 층으로 적는다. 위에서부터 단단하다.
  1. **기제** — 코드로 구현된 부품에 매개변수를 채운다 (§6).
  2. **규칙** — [조건 언어](14-조건-언어.md)로 쓴 조건과 효과.
  3. **자연어 지침** — 규칙의 효과 `심판에게`로 건넨다. 언제 유효한지는 조건이 정한다.

### 행동 유형도 정의다

```
정의: 행동유형·관찰
  열어 볼 것: 대상의 겉보기 사실, 장소의 조도, 행위자의 감각
  고칠 수 있는 것: 행위자의 시야
  기본 소요: 짧음
```

- **열어 볼 것**은 문맥 조립의 기준이 되고, **고칠 수 있는 것**은 제안의 쓰기 권한이 된다.

## 6. 기제

14개 영역을 다 적고 남은 기본 기제는 일곱이다.

| 기제 | 하는 일 | 예 |
| --- | --- | --- |
| 게이지 | 등급·수치가 조건에 따라 오르내린다 | 피로, 분노, 신뢰, 상함, 화재의 세기 |
| 시계 | 단계가 순서대로 진행된다 | 세력의 계획, 감염, 사건의 국면 |
| 전이 | 상태가 표에 따라 옮겨 간다 | 날씨, 단역의 일과 |
| 예약 | 정해진 시점에 일이 일어난다 | 약효의 끝, 불이 번지는 시점, 소문의 확산 |
| 위치 제약 | 자리 수, 용량, 허용 종류 | 양손, 의복의 부위와 층, 용기, 좌석 |
| 변환 | 재료가 결과로 바뀐다 | 제작, 조리, 장전 |
| 계승 | 없는 사실은 가장 가까운 위에서 가져온다 | 원형, 분류 헤드, 역할, 집단 시야 |

- 시나리오는 기제를 **조합**해 새 정의를 만든다. 코드를 쓰지 않는다.
- 어떤 기제로도 안 되는 것은 자연어 지침으로 시작하고, 여러 시나리오에서 반복되면 엔진에 기제로 승격한다.

## 7. 사건

```
사건 #412  시각: 3일차 21:40  장소: 객잔_1층
  행위자: 강호민   유형: 조작   대상: 뒷문_자물쇠
  판정: 기준 62, 주사위 71 → 실패
  변화: 소음(객잔_1층) = 큼
  지각: 강호민(보고 들음), 주모(소리만)
```

- 세계의 현재 상태는 사건을 처음부터 쌓은 결과다. 사건은 고치거나 지우지 않는다.
- 주사위 값과 호출의 입력·출력도 남긴다. 어떤 턴이든 그대로 재현할 수 있다.
- 되감기는 "N번 사건까지만 쌓기"다. 턴 처리 도중 실패하면 아무것도 쌓이지 않는다.
- 사건은 기억의 단위다.

## 8. 계승

값이 없으면 가장 가까운 위에서 가져온다. 한 원리가 네 곳에 쓰인다.

| 아래 | 위 |
| --- | --- |
| 실물 | 원형 |
| 장소 | 상위 장소 → 분류 헤드 |
| 인물 | 역할 |
| 개인의 시야 | 집단의 시야 → 세계의 상식 |

- 계승되는 속성은 정의에서 **선정한 것만**이다.

## 9. 시야 — 명제를 담는 것

- 세계 장부가 하나 있고, **명제를 담는 것**이 여럿 있다. 형식은 장부와 같다.
- 담는 것: 마음(인물), 집단, 문서, 소문, 기록, 단서.
- 담긴 명제에는 `언제 알았나 · 어떻게 알았나 · 얼마나 확신하나`가 붙는다.
  앎은 낡을 수 있고, 틀릴 수 있고, 출처가 있다.
- **PC의 시야 = 플레이어에게 전달된 것.**
- 편지를 읽으면 편지의 명제가 읽은 이의 시야로 복사된다. 소문이 퍼지면 집단의 시야로 복사된다.
- 평판은 어떤 집단의 시야에 담긴 그 인물에 대한 명제다. 규범은 집단의 시야에 담긴 관습이다.
- 명제는 식별자를 가질 수 있다. "이 단서가 저 결론을 뒷받침한다"를 사실로 적는다.
- **엔진은 PC를 대신해 추론하지 않는다.** PC의 시야에는 지각한 것만 들어가고 결론은 유저가 낸다.

## 10. 틀

> 틀은 빈칸 있는 사실 묶음이다. 빈칸을 채워 장부에 찍어낸다.

| 무엇 | 빈칸 | 찍어내면 |
| --- | --- | --- |
| 물건의 원형 | 수량 | 실물 하나 |
| 단역 인물 | 이름, 있는 곳 | 인물 하나 |
| 몸의 틀 | — | 부위 어휘 |
| 장소 조각 | 붙는 곳, 방의 수 | 장소·통로·지점·있을 법한 물건 |
| 사건 틀 | 누가, 무엇을, 어디서 | 계획·시계·관련 사실 |
| 시나리오 | 변수 | 세션의 첫 장부 |

```
틀: 매복
  빈칸: 매복자(세력의 무리), 표적(인물), 길목(장소)
  발동:
    모두:
      - 적대(매복자의 세력 → 표적) 이상 높음
      - 매복자의 시야에서: 위치(표적) = 길목
  국면(시계): 잠복 → 포위 → 습격 → 추격 또는 철수
  방치 시: 표적이 지나가지 않으면 철수
  반복: 세력당 3회
```

- 빈칸에는 후보 목록, 범위, 조건을 걸 수 있다. 구 프로젝트의 "빈칸과 후보", "가변 시작 정보"가 여기에 해당한다.
- 분류 헤드는 "여기 있을 법한 조각" 목록을, 장소는 "있을 법한 원형" 목록을 갖는다.
  **미저작 세부의 생성은 이 목록에서 고르고 빈칸을 채우는 일이다.**

### 세션 개설

```
공용 사전 (정의, 원형, 틀)
  + 시나리오 (정의의 수정·추가, 틀, 변수)
  + 변수 값 결정
  = 첫 사건 묶음  →  세계 장부
```

## 11. 지각과 기억

### 지각

- **명백한 경우는 코드가 정한다.** 같은 지점·같은 장소에 있으면 지각한다. 연결도 보임도 없으면 지각하지 못한다.
- **경계 사례는 심판이 정한다.** 코드는 근거가 되는 사실(경계, 차음, 통로 상태, 거리, 조도, 감각 능력)을 골라 준다.
- **판단 결과는 사실로 기록된다.** 한 번 정해지면 다음에도 같다.
- 코드가 보장하는 것은 계산이 아니라 **격리와 기록**이다. 지각했다고 정해지지 않은 것은 그 인물의 문맥에 들어가지 않는다.
- 사건의 지각에는 **어떤 감각으로**가 붙는다.

### 말은 명제의 전달이다

- 인물이 말할 때는 **무엇을 알려 주는가**가 먼저 정해진다: 자기 시야의 무엇을 밝히고, 숨기고, 꾸미는가.
- 들은 쪽의 시야에는 "누가 이렇게 말했다"가 출처와 함께 들어간다. 참인지는 별개다.

### 기억은 요약이 아니라 선별이다

- 한 마음의 기억 = 그 마음이 지각한 사건들 + 시야의 명제들.
- 호출에 넣을 기억은 관련 개체, 최근성, 중요도로 골라낸다. 대화 기록을 LLM으로 압축하지 않는다.

## 12. LLM이 장부에 쓰는 방법

- LLM은 **제안**만 낸다: 개체 생성 / 사실 설정 / 사건 발생 / 틀 찍어내기 / 판정 요청.
- 코드가 검사한다.
  - 정의에 맞는 값인가, 적용 대상이 맞는가
  - 위치 제약을 어기지 않는가
  - 기존 사실과 모순되지 않는가
  - 행동 유형이 허용한 쓰기인가
  - 주권을 넘지 않는가 (PC의 내면을 정하려 하는가)
- 통과한 것만 사건으로 기록된다.

## 13. 문맥 조립

각 호출의 문맥은 장부에 대한 **질의의 결과**다.

1. 고정부: 공용 지침, 시나리오의 어조와 전제 (모든 턴에 같음 — 캐시 대상)
2. 장면: 현재 장소의 개체와 사실 (호출 주체의 시야 기준)
3. 언급: 선언에 등장한 개체와 한 걸음 떨어진 관계
4. 행동 유형이 정한 "열어 볼 것"
5. 기억: 관련 사건 몇 개
6. 어휘: 위에 등장한 속성의 정의, 그리고 **지금 조건이 참인 지침만**

- 토큰 예산 안에서 우선순위로 자른다. 세계가 커져도 호출 크기는 장면 크기에 비례한다.

## 14. 스스로 보는 약점

- **조건 언어의 표현력.** [14](14-조건-언어.md)에서 설계했으나 장르 고유 규칙으로 시험하지 않았다.
- **공용 사전의 분량.** 정의, 원형, 틀이 수백 개 필요하다. 첫 시나리오에 필요한 만큼부터 쓴다.
- **위치 사슬의 깊이.** 건전지 → 손전등 → 배낭 → 인물 → 지점 → 장소 → 건물. 질의 비용을 재야 한다.
- **서술문의 선별.** 심리·관계·규범은 서술문이 대부분이다. 어떤 것을 호출에 넣을지는 표지와 관계로 정해야 한다.
- **말의 구조화.** "무엇을 알려 주는가"를 먼저 정하는 방식이 대화의 자연스러움을 해치지 않는지.
- **세력의 재계획.** 계획이 부서졌을 때 새 계획을 세우는 방법.
- **종이 위의 설계다.** LLM이 이 형식의 제안을 안정적으로 내는지는 구현으로만 확인된다.
