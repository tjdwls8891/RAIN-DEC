# 조건 언어와 규칙

2026-11-12. [13](13-형식-시험-나머지-열두-영역.md)에서 가장 큰 위험으로 지목된 조건 언어의 설계다. **[제안]**

## 1. 무엇을 푸는가

조건은 엔진의 다섯 곳에서 쓰인다.

| 쓰이는 곳 | 묻는 것 |
| --- | --- |
| 규칙 | 이 효과가 지금 적용되는가 |
| 사건 틀의 발동 | 이 사건이 지금 일어날 수 있는가 |
| 시계의 진행 | 이 단계가 다음으로 넘어가는가 |
| 상태의 적용 대상 | 이 상태가 이 물건에 붙을 수 있는가 |
| 변수의 제약 | 이 후보가 빈칸에 들어갈 수 있는가 |

다섯 곳이 하나의 언어를 쓴다. 이 언어는 서로 당기는 세 요구를 만족해야 한다.

- **코드가 계산할 수 있다.** 같은 장부에 대해 언제나 같은 답이 나온다.
- **사용자가 읽고 쓸 수 있다.** 프로그래머가 아닌 저작자가 쓴다.
- **표현력이 충분하다.** 모자라면 자연어 지침으로 넘치고, 넘친 만큼 해석이 흔들린다.

## 2. 설계의 요지

> 조건은 **사실과 같은 모양**으로 쓴다. 새 문법을 배우는 것이 아니라 "이런 사실이 있는가"를 묻는다.
> 못 하는 일을 **일부러** 정해 두고, 그 너머는 심판에게 넘긴다.

네 가지 결정으로 이루어진다.

1. 조건의 낱개는 사실 한 줄에 비교를 붙인 것이다.
2. 누구를 가리키는지는 **정해진 지시어**로만 쓴다. 장부를 타고 돌아다니는 표현은 없다.
3. 자주 쓰는 공간·소지 관계는 코드가 계산해 주는 **파생 술어**로 제공한다.
4. 조건으로 못 쓰는 판단은 **조건은 단단하게, 효과만 자연어로** 심판에게 넘긴다.

## 3. 조건

### 3.1 낱개 조건

```
속성(주체) 비교 값
속성(주체 → 대상) 비교 값
```

```
피로(이것) 이상 높음
위치(이것 → 지닌 자) = 착용
재질(이것) 포함 천
잠김(뒷문) = 참
적대(흑풍채 → 행위자) 이상 높음
내공(행위자) 이하 내공(상대) - 2단계
```

- 비교: `=` `≠` `이상` `이하` `초과` `미만` `포함` `있음` `없음`
- 등급의 크고 작음은 정의에 적힌 순서를 따른다.
- 오른쪽에는 값, 또는 다른 사실에 `± N` 을 붙인 것이 올 수 있다. 산술은 이것뿐이다.

### 3.2 지시어

장부의 다른 곳을 가리킬 때는 아래 지시어만 쓴다.

| 지시어 | 가리키는 것 |
| --- | --- |
| `이것` | 이 규칙이 딸린 개체 |
| `이곳` | `이것`이 있는 장소 |
| `지닌 자` | `이것`을 들거나 입거나 지닌 인물 |
| `행위자` | 지금 처리 중인 행동을 하는 인물 |
| `상대` | 그 행동의 대상 |
| `지금` | 현재 세계 시각 |

- 틀 안에서는 **빈칸의 이름**(매복자, 표적, 길목)도 지시어처럼 쓴다.

### 3.3 파생 술어

위치 사슬을 저작자가 직접 따라가지 않도록 코드가 계산해 준다.

| 술어 | 뜻 |
| --- | --- |
| `같은 곳(가, 나)` | 같은 최하위 장소에 있다 |
| `안에(가, 나)` | 가가 나의 안에 있다 (몇 겹이든) |
| `지닌다(가, 나)` | 가가 나를 지니고 있다 (가방 속의 것 포함) |
| `이어짐(가, 나)` | 두 장소가 지나갈 수 있는 통로로 이어져 있다 |
| `안다(가, «명제»)` | 가의 시야에 그 명제가 있다 |
| `믿는다(가, «명제»)` | 위와 같되 확신의 정도를 비교할 수 있다 |
| `지속(조건)` | 그 조건이 참이 된 뒤 흐른 시간 |
| `수(어떤 …)` | 조건에 맞는 개체의 수 |

- 목록은 닫혀 있다. 시나리오가 새 술어를 만들 수 없다. 필요해지면 엔진에 더한다.

### 3.4 묶기와 "어떤"

```
모두:
  - 위치(이것 → 지닌 자) = 착용
  - 기온(이곳) 이하 추움

하나라도:
  - 젖음(이것) = 참
  - 날씨(이곳) = 비

아님:
  - 같은 곳(살인마, 플레이어)

어떤 ㄱ: 인물
  - 같은 곳(ㄱ, 행위자)
  - 적대(ㄱ → 행위자) 이상 높음
```

- `어떤`은 "이런 것이 하나라도 있는가"다. 찾은 것은 이름(ㄱ)으로 효과에서 다시 쓸 수 있다.
- "모든 것이 그러한가"는 `아님` + `어떤`으로 쓴다. 따로 두지 않는다.

### 3.5 모름

- 사실이 장부에 없고 정의에 기본값도 없으면 그 조건은 **모름**이다. 참도 거짓도 아니다.
- 규칙과 발동은 **참일 때만** 작동한다. 모름은 작동하지 않는다.
- 검사기는 "이 조건은 지금 장부에서 항상 모름"인 경우를 저작 오류로 알려 준다.

### 3.6 누구의 눈으로 보는가

- 조건은 기본적으로 **세계의 진실**에 대해 계산한다.
- `~의 시야에서:` 로 감싸면 그 마음이 아는 것에 대해 계산한다. 인물이 **믿는 대로** 행동하게 하는 데 쓴다.

```
매복자의 시야에서:
  - 위치(표적) = 길목
```

### 3.7 일부러 못 하게 한 것

| 못 하는 것 | 이유 | 대신 |
| --- | --- | --- |
| 반복, 재귀, 함수 정의 | 프로그래밍 언어가 된다 | 엔진에 기제나 술어를 더한다 |
| 여러 단계로 장부를 타고 가기 | 읽을 수 없고, 구조가 바뀌면 깨진다 | 지시어와 파생 술어 |
| 일반 산술 | 수치 설계가 시나리오로 새어 나간다 | 기준값 계산은 엔진의 표 |
| 서술문의 내용 판단 | 코드가 읽지 못한다 | 심판 |
| "하지 않았다"의 감지 | 무한히 많은 것이 일어나지 않는다 | 그것을 본 인물의 호출 |
| 의도, 분위기, 예의 | 사실이 아니다 | 인물, 심판 |

## 4. 규칙

조건에 **언제**와 **무엇을**을 붙이면 규칙이다. 규칙은 정의나 원형, 틀에 딸린다.

### 4.1 두 종류

```
때: 섭취                                   # 일이 일어난 순간 한 번
  효과:
    - 변화: 통증(행위자) 한 단계 하강
    - 예약: 6시간 뒤, 변화: 통증(행위자) 한 단계 상승

동안:                                       # 조건이 참인 내내
  모두:
    - 위치(이것 → 지닌 자) = 착용
  효과:
    - 보정: 보온(지닌 자) 두 단계 상승
```

- **때 규칙**: 사건에 반응해 한 번 실행된다. 계기는 닫힌 목록이다 — 행동 유형(섭취, 착용, 진입, 공격 …), 상태의 변화, 시계 단계의 완료, 일정 시간의 경과.
- **동안 규칙**: 조건이 참인 동안 보정이 유지된다. 조건이 거짓이 되면 저절로 사라진다. 되돌리는 규칙을 따로 쓸 필요가 없다.

### 4.2 효과

효과는 [09](09-장부-설계.md)의 **제안**과 같은 것이다. 코드가 검사한 뒤 기록한다.

| 효과 | 하는 일 |
| --- | --- |
| `설정` | 사실의 값을 정한다 |
| `변화` | 등급·수치를 올리거나 내린다 |
| `부착` / `제거` | 상태를 붙이거나 뗀다 |
| `보정` | (동안 규칙에서) 값이나 판정에 유리·불리를 준다 |
| `예약` | 정해진 시간 뒤에 다른 효과를 실행한다 |
| `발생` | 틀을 찍어낸다 (사건, 개체) |
| `알림` | 누군가의 시야에 명제를 넣는다 |
| `판정` | 명백한 성공 또는 명백한 실패로 정한다 |
| `심판에게` | 자연어 지침을 건넨다 |

### 4.3 조건은 단단하게, 효과만 자연어로

```
동안:
  모두:
    - 행동 유형 = 공격
    - 내공(행위자) 이하 내공(상대) - 2단계
  효과:
    - 심판에게: "기량 차이가 압도적이다. 정면으로 맞서는 수는 통하지 않는다."
```

- 자연어 지침은 없앨 수 없다. 코드로 미리 만들 수 없는 판단이 반드시 남는다.
- 대신 **언제 그 지침이 유효한지는 코드가 정한다.** 심판은 해당될 때만 그 지침을 받는다.
  지침이 늘어도 심판의 문맥은 늘지 않고, "이 지침이 지금 적용되는가"를 LLM이 판단하다 흔들리는 일이 없다.
- 구 프로젝트에서 자연어가 문제였던 두 이유(해석이 호출마다 달라짐, 선별 전달이 어려움) 가운데 선별을 푼다.

## 5. 저작 난이도

저작자가 조건 언어와 만나는 깊이는 세 단계다.

| 단계 | 하는 일 | 누가 | 조건 언어 |
| --- | --- | --- | --- |
| 1 | 공용 정의와 틀을 고르고 값을 채운다 | 시나리오 저작 | 쓰지 않음 |
| 2 | 변수의 제약, 사건의 발동에 조건 한두 줄 | 시나리오 저작 | 낱개 조건 |
| 3 | 새 정의, 새 틀, 묶기와 "어떤" | 공용 사전 저작 | 전부 |

- 시나리오 하나는 대부분 1단계로 쓰인다. 이것이 저작 난이도 제약에 대한 답이다.
- 3단계는 엔진의 사전을 키우는 일이고, 한 번 쓰면 모든 시나리오가 쓴다.

### 되읽기

저작자가 조건을 직접 쓰지 않아도 되게 한다.

1. 저작자가 자연어로 쓴다: "상대보다 내공이 두 단계 넘게 낮으면 정면 대결은 안 통한다."
2. LLM이 조건 언어로 옮긴다.
3. 검사기가 그것을 **다시 한국어로 풀어** 보여 준다: "공격 행동이고, 행위자의 내공이 상대의 내공보다 두 단계 이상 낮은 동안: 심판에게 지침을 건넨다."
4. 저작자는 풀어 쓴 문장이 뜻과 같은지만 확인한다.

- 풀어 쓰기는 LLM이 아니라 **코드**가 한다. 조건의 모양이 단순해서 가능하고, 그래서 저작자가 확인한 것과 실제 작동이 어긋나지 않는다.
- 저작자에게 조건 언어는 쓰는 언어가 아니라 **확인하는 중간 표현**이 된다.

## 6. 검증: 지금까지의 사례로

[12](12-형식-시험-물건과-장소.md)·[13](13-형식-시험-나머지-열두-영역.md)에서 규칙이 필요했던 사례를 이 언어로 적어 보았다.

| 사례 | 결과 |
| --- | --- |
| 약을 먹으면 통증이 줄고 6시간 뒤 돌아온다 | 때 규칙 + 예약 |
| 외투를 입으면 따뜻하다 | 동안 규칙 |
| 젖음은 천·종이·가죽에만 붙는다 | 낱개 조건 `포함` |
| 고기는 서늘한 곳에서 천천히 상한다 | 게이지의 변화 조건에 `기온(이곳)` |
| 방전된 손전등은 켜지지 않는다 | 동안 규칙 + `판정: 명백한 실패` |
| 열쇠는 맞는 자물쇠만 연다 | 관계 사실 + 낱개 조건 |
| 살인마는 플레이어와 다른 곳에서 시작한다 | 변수 제약 `아님: 같은 곳` |
| 범인은 알리바이가 거짓인 용의자 중 하나 | `어떤 ㄱ: 용의자` + 조건 |
| 적대적인 세력이 표적의 경로를 알면 매복한다 | `~의 시야에서` |
| 처치하지 않은 감염은 악화된다 | 시계의 진행 조건 |
| 기량 차이가 크면 정면 대결은 안 된다 | 조건 + `심판에게` |
| 선배에게 포권하지 않으면 눈총을 받는다 | **못 씀** (하지 않은 것의 감지) → 인물 호출 |
| 왼팔 부상이 이 행동에 불리한가 | **못 씀** (어느 부위를 쓰는 행동인지) → 심판 |

- 열셋 중 열하나가 적혔다. 못 쓴 둘은 §3.7에서 일부러 넘긴 종류다.
- 묶기와 "어떤"이 필요했던 것은 넷이다. 나머지는 낱개 조건 한두 줄이었다.

## 7. 남은 문제

- **동안 규칙의 계산 비용.** 조건이 참인지 계속 알아야 한다. 관련 사실이 바뀔 때만 다시 계산하도록 해야 한다.
- **규칙끼리의 충돌.** 두 규칙이 같은 사실을 다르게 정할 때의 우선순위. 시나리오의 것이 공용의 것을 이긴다는 것 외에는 미정.
- **계기 목록.** 때 규칙의 계기를 닫힌 목록으로 두었으나 무엇이 들어가는지는 행동 유형 설계와 함께 정해야 한다.
- **표기.** 여기서는 한국어 낱말을 썼다. 실제 파일 형식과 낱말은 구현하며 다듬는다.
- **장르 시험을 하지 않았다.** 다섯 장르의 고유 규칙을 적어 보아야 표현력이 충분한지 알 수 있다.
