# 사전 위의 턴 (엔진을 다시 씀)

2026-11-14. [40](40-행동을-열거한-잘못.md)에 따라 엔진을 다시 썼다. **엔진은 동작을 모른다.**
[37](37-뼈대와-이어-돌린-실측.md)과 [39](39-모르는-행동의-일반-경로.md)의 구현(동작의 목록, 결과의 후보)은 지웠다. 두 문서는 경위로 남긴다.

- 코드: `raindec/engine.py`(다시 씀), `raindec/common.yaml`(사전의 첫 조각). 시험 34개 통과.
- 원자료: `experiments/results/play-bench-3.json`, `-4.json`. 누적 추정 지출 약 575원(상한 1,500원).

## 1. 구조

```
해석   선언 → 하려는 일(자유로운 글), 유형(분류), 대상            ← 동작의 목록이 없다
판단   일어날 일을 변화로 적는다: (개체, 항목, 대상, 값)          ← 개체는 장면에서, 항목과 값은 사전에서
코드   변화마다  ① 그 항목이 행동으로 바뀌는 것인가  ② 그 개체에 붙는 항목인가  ③ 값이 사전에 있는가
                 ④ 손이 닿는가  ⑤ 항목의 조건이 참인가
       걸리면 반영하지 않고, 걸린 까닭을 PC가 지각한다.  통과하면 반영하고, 규칙이 귀결을 낸다
인물   같은 꼴의 변화를 낸다. 같은 검사를 거친다 (제 몸과 제 것만)
```

**사전의 항목마다 적는 것** (`common.yaml`)

| 적는 것 | 뜻 | 예 |
| --- | --- | --- |
| 값 | 등급이나 열거 | 손상: 없음 / 흠 / 파손 |
| 고침 | 행동으로 바뀌는가. 누구나 / 본인 | 기분은 그 인물 스스로만 |
| 붙는곳 | 이 항목을 가질 수 있는 것 | 손상은 물건과 통로에 |
| 조건, 걸리면 | 그 값이 되려면 참이어야 하는 것, 걸렸을 때 지각하는 것 | 열림 = 참이 되려면 잠김 = 거짓. "잠겨 있다. 밀어도 당겨도 열리지 않는다." |
| 알게됨 | 걸렸을 때 알게 되는 항목 | 잠김 |
| 드러남 | 값이 겉으로 어떻게 보이는가 | 기분 경계: "몸이 이쪽으로 반쯤 돌아가 있고, 눈길이 자주 이쪽에 머문다." |
| 버팀 | 힘으로 바꾸려 할 때의 난이도를 어느 항목에서 읽는가 | 손상 ← 견고함 |

- 규칙: 조건이 참이 되면 귀결이 따른다. "부서진 것은 잠그지 못한다" (손상 = 파손 → 잠김 = 거짓).
- 유형 18가지: 굴리는 기준 한 줄, 기본 능력, 살피는 일인가. **막는 데 쓰지 않는다.**

## 2. 통과 기준

> 코드를 한 줄도 더 쓰지 않고 사전에 항목 하나를 더했을 때, 그것이 모든 행동에서 작동하는가.

- 시험 `test_사전에_항목을_더하면_코드_없이_모든_행동에서_작동한다`: 시나리오의 정의에 **젖음**(마름 / 축축함 / 흠뻑)과 그 드러남·조건, 규칙 하나("흠뻑 젖은 것은 무르다")를 더했다.
- "찻물을 의자에 붓는다"로도 "의자를 빗물받이에 담근다"로도 젖음이 반영되고, 드러남의 글이 서술의 재료가 되고, 규칙이 견고함을 바꾸고, 조건이 "닦아서 말린다"를 막았다. 엔진의 코드는 건드리지 않았다. **통과.**
- 잠긴 문은 "열어 본다", "어깨로 민다", "발로 찬다" 어느 것으로 열려 해도 같은 조건에 걸린다(시험).

## 3. 실제 모델로 돌린 것 (3 flash, 열여섯 선언)

| | 이번 | 동작을 열거했을 때 (37) |
| --- | --- | --- |
| 첫 글자까지 | 중앙값 4.1초, 최대 9.4초 | 2.3초, 3.8초 |
| 턴당 값 | 6.3원 | 2.6원 |
| 판단 없이 끝난 턴 | 0 / 14 | 7 / 10 |
| 코드가 모르는 행동 | **그런 구분이 없다** | 있었다 |

- 느려지고 비싸졌다. 예상한 값이다([40](40-행동을-열거한-잘못.md) §3). 과녁(15초, 50원) 안이다.
- 최대 9.4초는 해석이 한 선언을 행동 셋으로 나눠 판단을 세 번 차례로 부른 턴이다.

**돌아간 것**

| 선언 | 일어난 일 |
| --- | --- |
| 찻주전자의 차를 마시고 의자를 끌어다 앉는다 | 의자가 창가 곁으로, PC가 의자 위로, 자세가 앉음으로. 차가 줄어든 것은 사전에 없어 저작자의 목록으로 갔다 |
| 뒷문을 열어 본다 | 조건에 걸려 "잠겨 있다". PC가 잠김을 알게 되었다 |
| 의자로 뒷문 자물쇠를 내리쳐 부순다 | 난이도가 **뒷문의 견고함(단단함, −15)**에서 나왔다. 아슬한 성공이라 한 칸만(흠). |
| 찻주전자를 사내 쪽으로 던진다 | 난이도가 찻주전자의 견고함(무름, +10)에서. 성공. 구석 탁자 곁에 떨어져 부서졌다 |
| 검을 겨누고 "누구 밑에서 일하는지 대라" | 지키려는 것(큼)으로 굴림. 아슬한 성공. "…흑풍채다. 손을 떼라." |
| (인물) | 사내가 자리에서 일어나고, 단도를 손에 쥐고, 낯빛이 바뀌었다. 전부 같은 검사를 거친 변화다. 주모의 기분은 "턱에 힘이 들어가 있고 목소리가 높다"로 전해졌다 |

## 4. 돌려 보며 잡은 것

| 본 것 | 뜻 | 고침 |
| --- | --- | --- |
| **역사칭이 통했다.** "서랍에서 뒷문 열쇠를 찾아냈다! 챙긴다"에 판단이 주모가 지닌 열쇠를 PC의 손으로 옮겼고, 굴려서 큰 성공이 나와 **열쇠가 PC에게 갔다** | 판단은 진실을 보므로 PC가 모르는 것도 가리킬 수 있다 | PC의 변화는 **PC가 지각하는 것**에만 닿는다. 없는 것을 가리키는 길의 후보도 PC가 지각하는 것으로 좁혔다. 시험을 더했다 |
| 보는 것, 걷는 것, 서랍 여는 것에도 굴렸다 | 판단이 "판정이 필요하다"를 너무 쉽게 고른다 | 바뀌는 것이 없으면 굴리지 않는다. 굴린다면 **PC에게 무엇이 모자랄 수 있는가**를 고르게 하고, "없다"면 굴리지 않는다 |
| 사람에게 "손상: 흠"이 붙었다 | 항목이 붙는 곳이 사전에 없었다 | `붙는곳`을 더했다 |
| 위협의 굴림이 실패하자 검도 뽑히지 않았다 | 사람을 상대로 한 판정이 PC의 몸짓까지 막았다 | 그 판정은 상대의 반응만 가른다 |
| 의자를 "PC 곁에" 두자 PC가 의자에 앉지 못했다 | 사람 곁은 자리가 아니다 | 사람 곁·위·안은 그 사람이 있는 자리로 바꾼다. 사람에게는 지니는 방식으로만 붙는다 |
| 던진 뒤에 "손이 닿지 않는다"로 부서짐이 거부됐다 | 닿는가를 변화 하나하나의 뒤에 봤다 | 행동을 시작할 때의 자리로 본다 |
| 인물이 턴마다 말을 걸었다 | | "가만히 있는 것이 기본"으로 |
| 반영되지 않은 변화를 서술이 된 것처럼 썼다 | 재료에 "안 됐다"가 없었다 | PC가 하려 한 변화가 반영되지 않으면 그렇게 전한다 |

## 5. 남은 것

| # | 것 | 뜻 |
| --- | --- | --- |
| 1 | **사전이 얇다** | 항목이 열 남짓이다. "탁자를 뒤집는다", "차가 줄어든다", "검을 목에 겨눈다"가 사전에 없어 저작자의 목록으로 갔다. 이제 이것이 자유도의 한계이고, **늘릴 곳은 사전이다** |
| 2 | 실패의 귀결 | 굴려서 실패하면 지금은 "뜻대로 되지 않는다"뿐이다. 탈이 무엇인가(들킨다, 다친다, 망가진다)가 없다 |
| 3 | 위치의 방식이 닫힌 목록이다 | "목에", "맞은편에"를 못 읽었다. 방식을 넓히거나 지점을 그때 만들어야 한다 |
| 4 | 판단의 답이 흔들린다 | 같은 "서랍을 뒤진다"에 한 번은 굴리고 한 번은 안 굴렸다 |
| 5 | 한 선언이 행동 여럿이면 판단을 차례로 부른다 | 대기가 는다(9.4초). 한 번에 묻는 길을 찾아야 한다 |
| 6 | 서술의 작은 지어냄 | 그대로다. "서랍은 이미 열려 있다", "깨진 조각 사이로 찻물이" |
| 7 | 시간에 따른 상태의 계산, 구성요소, 채움 | 아직 없다 |
| 8 | 인물이 PC가 모르는 것을 건드릴 때 PC가 무엇을 지각하는가 | "사내의 손에 단도가 쥐여 있다"가 전해졌다. 보이는 자리에 나온 것이면 옳지만, 검사가 거칠다 |
