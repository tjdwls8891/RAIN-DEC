## 2026-11-12 — 착수

- 사용자가 미션을 소개함: 실패한 구 프로젝트의 전면 재설계·재개발.
- 진행 방식과 소통 원칙을 지정함 → [00-배경과-협업-원칙.md](00-배경과-협업-원칙.md)

### 열린 질문

- 이 프로젝트(엔진)가 무엇을 하는 것인지 — 아직 전달받지 않음.
- 사용자의 생각과 바람 — 다음 단계에서 청취 예정.

  → [04-상태-서사-저작-예산.md](04-상태-서사-저작-예산.md) 후속 답변

- 큰 그림 문서를 신설하고 원칙 초안과 질답 지도를 작성 → [05-큰그림.md](05-큰그림.md)

## 2026-11-12 — 원칙 수용과 P4 정정

- 사용자가 P4~P8을 수용. P8은 "모든 장르를 안다"로 대체 가능하다는 의견 (구상은 미청취).
- "멈춤 규칙"은 구 프로젝트에 이미 있었고, 미전달의 원인은 서술 오차(누락·첨가·환각)였음이 밝혀짐.
  Claude가 P4의 근거를 정정하고 오차 처리 방식을 새로 제안.
- 구 프로젝트의 세계 표현은 혼합형이었고 자연어에서 필드로 옮겨 가는 흐름이었음.
