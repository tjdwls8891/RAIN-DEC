## 2026-11-12 — 원칙 수용과 P4 정정

- 사용자가 P4~P8을 수용. P8은 "모든 장르를 안다"로 대체 가능하다는 의견 (구상은 미청취).
- "멈춤 규칙"은 구 프로젝트에 이미 있었고, 미전달의 원인은 서술 오차(누락·첨가·환각)였음이 밝혀짐.
  Claude가 P4의 근거를 정정하고 오차 처리 방식을 새로 제안.
- 구 프로젝트의 세계 표현은 혼합형이었고 자연어에서 필드로 옮겨 가는 흐름이었음.
  → [06-서술오차-장르-세계표현.md](06-서술오차-장르-세계표현.md), [05-큰그림.md](05-큰그림.md) 갱신

## 2026-11-12 — 철회 금지, 엔진의 두께

- 사용자가 "착각이었다" 식 철회를 거부. 구 추출 층위의 존재 이유가 이것이었음.
  Claude가 P4를 다시 정정: 전달된 것은 불변, 미전달은 조정 가능, 추출은 턴을 막지 않게.
- P8 확정: 엔진은 공용 항목을 풍부하게 갖추고 시나리오는 고르고 고치고 더한다. 세션 개설 시 유일한 세계 상태 생성.
- 세계 표현 요건(P9)을 도출: 유일한 해석, 선별 가능, 균일한 형식.
  → [07-전달불변-엔진두께-표현요건.md](07-전달불변-엔진두께-표현요건.md), [05-큰그림.md](05-큰그림.md) 갱신
