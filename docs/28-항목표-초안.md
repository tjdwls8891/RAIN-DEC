# 항목표 초안 (3단계) — 사용자 스케치를 설계도에 놓아 보기

2026-11-13. 사용자의 러프 스케치([원문](자료/사용자-러프-스케치-항목-2026-11-13.md))를 [27-전체-설계도.md](27-전체-설계도.md)의 틀에 놓았다.
사용자의 단서: 한 번에 적은 것이라 부족할 수 있고, 늘거나 나뉘거나 빠질 수 있으며, 소속이 적절치 않은 항목도 있다.

- 이 문서는 **전 영역을 같은 깊이로** 본다. 항목마다 한 줄이다. 값의 범위나 규칙의 내용은 적지 않는다(4단계).
- 스케치의 항목은 빠짐없이 옮겼다. 영역마다 Claude가 보기에 **빠진 것**을 따로 적었다.

## 읽는 법

| 열 | 뜻 |
| --- | --- |
| 적는 꼴 | **값**(코드가 읽는 수·등급·열거) / **관계**(다른 개체를 가리킴) / **규칙**(조건에서 귀결로) / **조건** / **가이드**(마스터가 따르는 기준) / **문장**(묘사에 그침) |
| 꿰는 것 | 상태 · 위치 · 앎 · 조건 · 계승 가운데 무엇으로 처리되는가 |
| 집 | 그 사실의 원본이 사는 영역. 스케치의 소속과 다르면 **→ 옮김**으로 적었다 |

## 1. 발견 (먼저)

### 가. 인물은 "집"이 아니라 "창"이다

- 스케치의 인물 항목은 50개 가까이다. 그 가운데 절반 이상이 **다른 영역에도 있다**: 소속·직책(조직), 관계별 태도·평가·유대·평판(관계),
  지식·비밀·오인·기억·거짓말·추론·믿음(정보), 목표·계획(계획), 소지품·의복(물건), 위치·지리지식·연관장소(장소), 권리/의무(규범).
- 같은 사실을 두 곳에 적으면 어긋난다. 구 프로젝트에서 수정 비용을 키운 종류의 문제다.
- 사용자는 청사진에서 이미 답을 말했다: "세계 시뮬레이션 영역에서는 … 각 범주의 적절한 부분을 모아 **인물 정보, 관계도, 조직도** 등 필요한 저장구조를 만들어야 합니다."
- 따라서: **사실마다 집은 하나다. 인물 정보는 여러 집에서 그 인물에 관한 것을 모아 보는 창이다.** 관계도와 조직도도 같다.
- 인물이 집인 항목은 스무 개 남짓으로 줄어든다 (§2.11).

### 나. 영역으로 서지 못한 것 셋

| | 스케치에서는 | 판단 |
| --- | --- | --- |
| **사회 규범** | 조직의 "규칙", 관계의 "권한", 인물의 "권리/의무"로 흩어져 있다 | 하나로 모은다. 규범은 조직에만 있지 않다(지역의 관습, 직업의 예법) |
| **감각** | 장소의 "가시성", 정보의 "인지 조건"에 들어 있다 | 저장하는 영역이 아니라 **오감을 모아내는 기능**으로 둔다 (사용자 구상 채택, [29](29-꿰는-것과-판정.md) §3) |
| **시간** | 없다 (청사진에서는 따로 언급) | 영역으로 둔다. 정책 여덟이 이미 승인되어 있다 |

- 신체와 건강은 스케치에서 인물의 "신체"에 들어 있다. 인물의 일부로 두되 **상태**(꿰는 것)가 대부분을 처리한다.

### 다. 꿰는 것이 둘 더 보인다

27 문서의 다섯(상태, 위치, 앎, 조건, 계승)에 더해:

| | 걸치는 항목 | 판단 |
| --- | --- | --- |
| **권한** | 관계의 권한, 조직의 규칙·직책·체계, 인물의 권리/의무, 장소의 접근, 물건의 소유, 행동선언의 "소유/거래" | 여섯 번째로 둔다. "누가 무엇을 해도 되는가"는 판정의 난이도, 인물의 반응, 사건의 조건에 두루 쓰인다 |
| **이력** | 관계의 만난 이력, 정보의 기억·사실의 변화, 물건의 제작·수리 내력 | 기록 방식이 **보류** 중이다. 필요하다는 것만 적어 둔다 |

### 라. 스케치에서 새로 보인 것

27 문서에 없던 것.

- 과업의 **달성 조건, 후속 과업, 세계 변화** — 앞서 과업은 "강제도 보상도 없는 방향 추천"이라고 했다. 달성 조건과 후속 과업이 있다면 그보다 구조가 있다. **확인 필요** (§4).
- 사건의 **복수·반복·동시 발생**
- 정보의 **사실의 생성**, **기억**
- 판정의 **액티브/패시브 스킬**, **협력**
- 환경의 **환경장**, **자연재해**
- 관계의 **약속**, **만난 이력**
- 조직의 **사상, 체계, 위상, 영향력**
- 계획의 **장애물**, **일정**
- 인물의 **모순, 약점, 거짓말, 오인, 행동 유형, 이동능력**
- 행동선언이 **18유형**이다 (앞서 전달된 16유형에 "장기과업/조직운용", "목표/선택/거부"가 더해짐. 조사 자료의 18개 기능군과 같다)

## 2. 영역별 항목표

### 2.1 장소

| 항목 | 적는 꼴 | 꿰는 것 | 코드 / 마스터 |
| --- | --- | --- | --- |
| 위치관계 | 관계 (포함, 이웃, 방위) | 위치 | 코드 |
| 이동개연성 | 통로(개체)와 그 상태 값, 거리·걸리는 시간의 등급 | 위치, 상태 | 코드: 갈 수 있는가, 얼마나 걸리는가 / 마스터: 예상 밖의 통과(벽을 부순다) |
| 외/내관 | 문장 | 계승 | 저작. 서술의 재료 |
| 정보 인지 여부 | → **정보로 옮김** (그 장소를 누가 아는가) | 앎 | |
| 물리적 특성 | 값(크기의 등급, 경계의 재질) + 문장 | 계승 | 마스터 판단의 근거 |
| 장소 내 위치관계 | 지점(개체)과 관계 | 위치 | 코드. 지점은 필요할 때 생긴다 |
| 가시성 | 관계(어디서 무엇이 보이는가) | 앎 | 명백한 경우는 코드, 경계는 마스터 |
| 환경 | → **환경으로 옮김** (장소는 값을 물려받는다) | 계승 | |
| 물건/인물의 배치 | 위치 관계 + 있을 법한 것의 목록 | 위치 | 코드. 미저작은 확정의 사다리 |

빠진 것: 분류 헤드와 계승, 권역(멀리서 보이고 들리는 것), 장소 조각, 통로의 상태(잠김·막힘·숨김), 접근의 권한, 닫힌 범위.

빠진 것: 수량, 호환(열쇠와 자물쇠), 소유(지닌 것과 구별), 상태가 붙을 수 있는 대상의 조건, 실물과 원형의 구분.

| 수단 | 쓸 수 있는 자원·사람 | 위치, 권한 | 코드: 실제로 있는가 |
| 내용 | 단계의 목록 | — | **마스터**가 세운다 |
| 일정 | 걸리는 시간 (보조) | — | 코드 |

| 재수립 | | | **마스터** (그 주체의 앎과 자원으로) |

### 2.11 인물

**인물이 집인 것**

| 항목 | 적는 꼴 | 꿰는 것 | 비고 |
| --- | --- | --- | --- |
| 능력치, 숙련, 스킬 | 값, 규칙 | — | 판정이 읽는다 |
| 외모, 나이, 성별, 첫인상 | 값, 문장 | — | |
| 상태, 부상 | 상태(등급), 부상(개체) | 상태 | 신체와 건강 |
| 일과, 행동 유형 | 가이드, 값 | — | 주목 밖에 있을 때의 근거 |
| 직업, 이동능력 | 값 | — | |
| 성격, 말투, 가치관, 습관, 선호, 행동양식 | 문장 | 계승 | 사람 일반 → 세계관 → 역할 → 인물 |
| 두려움, 모순, 약점, 욕구 | 문장 + 값 | — | 판정의 난이도와 인물의 반응에 쓰인다 |
| 의사결정 | **가이드** (경우별 판단 방식) | 계승 | 사용자가 저작 부담을 감수하기로 한 곳 |
| 감정 | 등급 (대상이 있을 수 있다) | 상태 | 관계의 감정과 한 집 |

**다른 영역이 집인 것** (인물 정보에서는 모아서 본다)

| 스케치의 항목 | 집 |
| --- | --- |
| 소지품, 의복 | 물건 (위치) |
| 위치, 연관장소/물건 | 장소, 물건 (위치) |
| 지식, 비밀, 믿음, 오인, 기억, 거짓말, 추론, 지리지식 | 정보 (앎) |
| 소속, 직책 | 조직 |
| 관계별 태도, 유대, 평가, 평판 | 관계 (평판은 집단의 앎) |
| 권리/의무 | 규범 (권한) |
| 목표, 계획 | 계획 |

- 스케치에 두 번 적힌 것(두려움, 모순, 유대)은 한 번으로 쳤다.

### 2.12 행동선언

18유형. 유형마다 **열어 볼 정보, 고칠 수 있는 정보, 판정의 기준**을 4단계에서 채운다. 여기서는 어느 영역에 닿는지만 본다.

| 유형 | 주로 닿는 영역 |
| --- | --- |
| 메타/규칙 입력 | 세계를 움직이지 않는다 |
| 관찰/조사/지식 | 정보, 장소 |
| 이동/운송 | 장소, 시간 |
| 물체/설비 조작 | 물건, 장소 |
| 자원/소유/거래 | 물건, 규범 |
| 제작/수리/건설 | 물건, 시간 |
| 신체/치료/생존 | 인물(신체), 물건 |
| 공격/제압/피해 | 인물(신체), 판정 |
| 방어/회피/보호 | 인물(신체), 판정 |
| 환경/공간 변화 | 환경, 장소 |
| 의사소통/설득/기만 | 정보, 관계, 판정 |
| 은폐/위장/추적 | 정보(앎), 장소 |
| 관계/소속/약속 | 관계, 조직 |
| 협력/지휘 | 관계, 계획 |
| 계획/준비/조건부행동 | 계획 |
| 장기과업/조직운용 | 계획, 조직, 시간 |
| 특수능력 | 시나리오가 정의. 효과는 다른 유형으로 풀린다 |
| 목표/선택/거부 | 과업, 계획 |

### 2.13 스케치에 없던 영역

| 영역 | 내용 |

## 4. 판단이 필요한 것

> **사용자 답변 (2026-11-13):** 1번 — 과업의 진행이 직접 세계 변화를 일으킬 수 있다(기본안을 버림). 4번 — 감각은 오감을 모아내는 영역으로 구상했으나 따를 필요는 없다(→ 모으는 기능으로 채택).
> 나머지는 기본안으로 진행. 반영은 [29-꿰는-것과-판정.md](29-꿰는-것과-판정.md) §0.

기본안을 적었다. 다르게 정할 것만 알려 주면 된다.

| # | 쟁점 | 기본안 |
| --- | --- | --- |
| 1 | **과업의 "세계 변화"는 무슨 뜻인가.** 과업을 이루면 세계가 바뀐다는 것인가, 세계가 바뀌면 과업이 생기거나 사라진다는 것인가 | 뒤의 것으로 읽는다. 과업은 세계의 사실을 참조할 뿐 세계를 바꾸지 않는다. 달성 조건은 "그 사실이 참이 되었는가"다 |
| 2 | 사실마다 집은 하나이고, 인물 정보·관계도·조직도는 모아 보는 창이다 | 그렇게 한다 |
| 3 | 규범을 영역으로 모은다 | 그렇게 한다 |
| 4 | 감각은 영역으로 두지 않고 앎의 일부로 둔다 | 그렇게 한다 |
| 5 | 권한을 여섯 번째 꿰는 것으로 둔다 | 그렇게 한다 |
| 6 | 관계의 감정과 인물의 감정을 한 집(인물)으로 합친다 | 그렇게 한다 |
| 7 | 영역마다 "빠진 것"으로 적은 항목을 더한다 | 더한다. 사용자가 뺄 것을 지적한다 |
