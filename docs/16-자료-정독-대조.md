# 자료 정독과 설계 대조

2026-11-12. [11](11-사용자-재설계-자료-대조.md)에서는 사용자 원문만 읽었다. 이번에는 GPT 조사 자료와 영역별 설계 문서까지 읽고,
현재 설계([05](05-큰그림.md), [09](09-장부-설계.md), [10](10-턴-처리-흐름.md), [14](14-조건-언어.md))에 **빠진 것**을 찾았다.

## 1. 읽은 범위

| 문서 | 읽은 정도 |
| --- | --- |
| 현행엔진 정보자산 재조사 | 전문 |
| 판정구조 및 시스템 원리 추출 | 본문 전부 (원천 색인 제외) |
| 플레이어행동·세계상태 통합조사 | 제1~7부 전부 |
| 차기엔진 외부게임 확장조사 | 본문 전부 (출처 목록 제외) |
| 행동 기능분류 1차검토안 | 원칙, 직교 축, 교차 사례. 353건 전수표는 표본만 |
| 세계상태 비교조사 원자료 | 교차 색인과 대조 지점. 게임 16종 개별 카드는 읽지 않음 |
| 행동가능성 원자료 1차조사 | 보존 메모만. 353건 본문은 읽지 않음 |
| 장소 및 공간 v0.2 | 제1~3부 전부. 제4부 이후(GPT 제안 15개의 수정 이력, v0.1 첨부)는 읽지 않음 |
| 환경 및 현상 | 사용자 구상, 5~11장. 12~14장(사례, 위험, 미결)은 읽지 않음 |
| 물건 통합시안 | 0.3~12장. 13~17장(사례 실험, 미결 선택지, 자기 비판)은 읽지 않음 |
| 시간 설계실 | 0~3장, 5~7장. 4장(정책별 논의 본문)은 읽지 않음 |
| 물건 GPT 조사결과 상세보존 | **읽지 않음** |

- 자료의 구 프로젝트 관련 내용은 문제의 증거와 요구의 원천으로만 읽었다. 구조는 가져오지 않는다.
- GPT의 제안은 사용자 미승인으로 취급했다. 아래에서 "자료에 있다"는 채택 근거가 아니다.

## 2. 결론

- **뼈대는 유지된다.** 자료가 요구하는 것 가운데 여섯 요소와 턴 흐름의 틀을 뒤집는 것은 없었다.
- **그러나 빠진 것이 많다.** 서른 개가 넘는다. 성격이 달라 넷으로 나눈다.
  - **가.** 형식을 고쳐야 하는 것 (9건) — 장부가 지금은 적지 못하는 것
  - **나.** 턴 처리를 고쳐야 하는 것 (8건) — 심판과 판정이 지금은 하지 못하는 것
  - **다.** 사용자의 정책 결정이 필요한 것 (6건)
  - **라.** 아직 설계하지 않은 영역 (9건)
- **설계가 틀린 곳이 셋 있다** (§7). 그중 "집단 시야의 계승"은 구 프로젝트가 일부러 피했던 것이다.
- 자료에는 **검증에 바로 쓸 자산**이 있다 (§8). 행동문 353개, 불변 조건, 검사 기준.

## 3. 가. 형식을 고쳐야 하는 것

### 가-1. "없다"를 적을 수 없다

- 자료는 존재의 상태를 다섯으로 구별한다: 기록에 없음 / **명시적으로 없음** / 존재함 / 존재하지만 이 주체는 모름 / 아직 미결정.
- 현재 장부는 사실이 없으면 "모름"뿐이다. "이 방에 뒷문은 없다"를 적을 수 없다.
- 결과: 한 번 "없다"고 서술한 것이 다음에 생길 수 있다. 탐색 실패("찾지 못함")와 부재("없음")를 구별할 수 없다.
- 고칠 방향: **부정 사실**을 사실의 한 종류로 둔다. 탐색 실패는 부정 사실을 만들지 않고, 심판이 명시적으로 "없다"고 정할 때만 만든다.

### 가-2. 위치가 아닌 물리 관계

- [12](12-형식-시험-물건과-장소.md)에서 "위치는 하나의 관계"라고 했으나 과했다. 자료는 관계를 일곱으로 나눈다:
  수납 / 위에 놓임 / **부분·구성** / 장착 / **물리적 연결** / 묶음·포장 / **잠금·제어**.
- 위치가 덮는 것은 수납, 위에 놓임, 장착뿐이다.
  - 부분: 문의 손잡이. 평소에는 서술이면 충분하고, 떼어내면 독립 개체가 된다.
  - 연결: 충전 케이블과 장치, 발전기와 조명. 양쪽 끝이 있고 작동 조건이 된다.
  - 제어: 자물쇠가 문을 막는다.
- 긴 케이블이나 길처럼 **여러 곳에 걸친 대상**은 "어떤 것은 한 번에 한 곳에만 있다"는 규칙을 깬다.
- 고칠 방향: 위치는 그대로 두고, 부분·연결·제어를 별도의 관계 사실로 추가한다. 기능의 **작동 조건**(전력, 연결)을 정의에 적을 수 있게 한다.

### 가-3. 값의 해상도가 한 가지뿐이다

- 자료는 같은 속성에 "약간 차가움" / "10~15℃" / "12℃"가 공존할 수 있어야 한다고 본다. 수량도 "몇 개", "한 상자"를 임의로 환산하지 않는다.
- 현재 값의 종류는 정의가 정한 한 형태만 허용한다.
- 고칠 방향: 값에 **범위**와 **불명확한 양**을 허용한다. 미상은 0도 정상도 아니다. 부분별 상태(소매만 젖음)도 필요하다.

### 가-4. 앎의 깊이와 계보

- 구 프로젝트는 인지 수준을 구별했다: **존재만 앎** / 내용까지 앎 / 부분 조각. 현재 시야는 명제를 통째로 알거나 모른다.
- 정보의 판본: 현재 / 대체됨 / 반박됨. 사실이 바뀌어도 그것을 믿던 사람은 자동으로 교정되지 않는다 — 이것은 시야가 이미 다룬다.
- 추론의 근거 의존: A와 B에서 C를 믿게 되었다면, A가 반증될 때 C를 다시 본다. [13](13-형식-시험-나머지-열두-영역.md)의 "뒷받침" 관계로 적을 수 있으나 재평가 절차는 없다.
- 물증 – 해석 – 결론의 구분: 지문이 나와도 동기까지 확정되지 않는다.

### 가-5. 사실의 출처 등급

- 자료는 사실의 권위를 구별한다: 원저작 / 판정으로 확정 / 규칙 추론 / LLM의 추정 / 인물의 발언.
- 현재 사실에는 "어느 사건에서 비롯"만 있다. 저작된 핵심 사실과 심판이 즉석에서 채운 소품이 같은 무게다.
- 고칠 방향: 사실에 **출처 등급**을 붙인다. 충돌이 나면 등급이 높은 쪽이 이긴다. 다-2(생성 권한)의 전제이기도 하다.

### 가-6. 공간: 열린 연속, 닿을 수 있는가, 이동 중, 추적하지 않는 위치

- **열린 연속**: 긴 길을 구간으로 끊되 구획 경계가 벽처럼 작동하면 안 된다. 현재 "같은 장소면 지각"은 옆 구간을 못 본다.
- **보임과 닿음의 분리**: 유리 상자 속 서류는 보이지만 집을 수 없다. 현재 "겉보기"는 보임만 다룬다.
- **이동 중**: 구간 위에 있고, 예정 도착이 있고, 중단되거나 되돌아갈 수 있다. 현재는 한 장소에 있는 상태뿐이다.
- **추적하지 않는 위치**: 구 프로젝트는 일과에서 계산되는 위치 / 명시된 위치 / 정보 없음을 구별했고, "정보 없음은 부재가 아니다"를 지켰다.
  화면 밖 인물이 다시 나타날 때 순간이동하지 않게 하는 장치다.
- 그 밖에 사용자가 따로 든 가시성 셋(외관·내관 / 어느 위치에서 무엇이 보이는가 / 들어가면 무엇이 보이는가), 주체별 통과 가능성, 일방향 통로, 닫힘과 잠김의 구별, 이동하는 공간(승강기, 선박).

### 가-7. 예약과 시계

- **전망은 확정된 미래가 아니다.** 예약한 확산은 문이 닫히거나 바람이 바뀌면 갱신되어야 한다. 강제 종료된 화재의 예약이 그대로 실행되면 안 된다.
  현재 예약에는 취소도 재평가도 없다.
- **시계는 뒤로도 간다.** 경계 수준은 진압으로 내려간다. 두 시계가 경쟁한다(탈출 대 포위). 현재 시계는 앞으로만 간다.
- **수행 중 유지 조건**: 수리 도중 부품을 빼면 작업이 무효가 된다.
- **연쇄의 종료 기준**: 규칙이 규칙을 부르는 파급에 끝이 없다. 깊이 제한이 필요하다.

### 가-8. 시간이 지났다는 이유만으로 바꾸면 안 된다

- 자료의 경고: 3일이 지났다는 것만으로는 그동안 냉장고가 돌았는지 알 수 없다. 이력 없이 정교한 변질값을 내면 **허위 정밀도**다.
- 현재 게이지의 "시간당 변화"가 정확히 이 위험을 가진다. 화면 밖 대상을 한꺼번에 계산할 때 그 사이의 조건을 모른다.
- 고칠 방향: 지연 계산은 정성적 결과만 내거나, 조건의 이력이 있을 때만 정밀하게 한다.

### 가-9. 묶음, 분할, 병합

- 묶음의 세 의미: 동종의 수량 집합 / 물리적 포장 / 서로 다른 실물의 동거.
- 분할·병합의 불변 조건: 총량이 보존되고, 상태가 다른 것을 합쳐서 차이를 지우지 않는다. 알약을 빻으면 단위 기준이 바뀐다.
- 효과의 중첩: 방한복 두 벌의 보온은 더하는가, 큰 쪽만인가. 현재 "보정" 규칙에 중첩 규칙이 없다.

## 4. 나. 턴 처리를 고쳐야 하는 것

### 나-1. 되묻는 길이 없다

- 구 프로젝트의 판정 경로는 다섯이다: 확실히 성립 / 확실히 불성립 / 불확실(굴림) / **의미가 불명확(명료화 질문)** / 정보 확인.
- 현재 심판은 어떤 선언이든 처리하려 든다. "방법 없이 판정만 요청"하거나 대상이 모호한 선언에 되물을 수 없다.
- 주의할 점도 자료에 있다: 질문은 의도 확인용이고 횟수를 제한한다. 새 목표나 행동을 강요하지 않는다.

### 나-2. 성공과 실패 둘뿐이다

- 자료 전반이 **성공 여부와 효과의 크기를 분리**하라고 한다. 소화기 하나로 대형 화재를 끌 수 없다.
- 구 판정은 여유치(기준 − 주사위)를 남겨 재사용했다: 대결에서 여유가 큰 쪽이 우세, 여유차로 부상 단계.
- 대결은 **항상 승자를 만들지 않는다.** 무승부와 양측 실패가 있다.
- 부분 성립도 필요하다.
- 현재 심판은 귀결을 성공/실패 한 쌍으로만 낸다.

### 나-3. 여러 단계로 된 선언

- "창문을 깨 주의를 돌리고 옆문으로 나간다"는 세 단계이고 뒤가 앞에 의존한다. 문 열기에 실패하면 안쪽 절도는 일어나지 않는다.
- "들키면 달아난다"는 조건부다. [13](13-형식-시험-나머지-열두-영역.md)에서 "PC에 딸린 임시 규칙"이라고만 적었다.
- **중간 개입 시점**: 경비와 대화하다 훔치는 일을 한순간에 성공 처리하지 않는다. 상대가 반응할 시간이 있다.
- 현재 심판은 행동을 목록으로 뽑지만 판정과 귀결은 턴 전체에 하나다.

### 나-4. 보정 요인에 종류가 없다

- 구 판정은 요인을 나눴다: 능력 / 숙련 / 장비 / 방법 / 상태 / 난이도 / 협력. 각각 범위가 있고, **같은 사실을 두 요인에 중복 반영하지 않는다.**
- 상태와 장비와 기술은 **판정 분야**가 맞을 때만 영향을 준다. 다리 부상이 설득을 어렵게 하지 않는다.
- 현재 요인은 "근거, 방향, 정도"의 무분류 목록이다. 심판이 같은 사실을 두 번 세도 막을 수 없다.

### 나-5. 다시 시도하는 것

- 같은 조건에서 다시 굴릴 수 없다. 방법, 범위, 도구가 바뀌면 새 기회다.
- 실패는 부정 사실을 만들지 않는다 (가-1과 연결).
- 판정의 선례: 비슷한 상황에서 이전 판단의 조건과 근거를 다시 쓴다. "판단 결과는 사실로 기록한다"와 같은 방향이나 판정에는 적용하지 않았다.

### 나-6. 말하지 않은 중간 동작

- 먹기 전에 꺼내기, 문 열기 전에 자물쇠 풀기. 자동으로 해도 되는 것과 플레이어의 확인이 필요한 것이 있다.
- 확인의 범위는 좁다. 한 문을 열라고 했다고 다른 잠금까지 승인한 것은 아니다.
- 아는 길로 가다 막히면 **그 자리에서 멈춘다.** 임의로 우회시키지 않는다.

### 나-7. 실패의 이유를 어디까지 말하는가

- 비밀을 드러내지 않고 실패 이유를 전해야 한다. 현재 "PC지각" 필드는 이 구분 없이 심판의 재량이다 ([15](15-최소-구현.md)에서 구멍으로 지목한 곳).

### 나-8. 지각과 반응 사이의 시간

- 구 프로젝트의 추적자는 소리를 듣고 **다음 턴에** 움직인다. 현재 인물은 지각한 턴에 바로 반응한다.
- 위협 반응에는 단계가 있다: 소음 → 경계 → 추적 → 수색 → 복귀.

## 5. 다. 사용자의 정책 결정이 필요한 것

| 다-1 | **소급 선언** | "어젯밤 미리 줄을 묶어 두었다". 다른 TRPG에는 허용 규칙(플래시백)이 있다. 허용할지, 현재 시점의 시도로만 볼지 |

| 다-3 | **단역의 승격** | 배경 인물을 장기 동료로 삼을 때, 기존 설정과 충돌하지 않게 배경을 채우는 절차 |
| 다-4 | **되감기와 주사위** | 구 프로젝트는 굴린 눈을 다시 굴리지 않았다. 되감기 후 같은 선언은 같은 결과인가 |
| 다-5 | **두 층위의 뜻** | 사용자 원문은 "세계를 추적·계산·관리·시뮬레이션하는 데 **사용할** 세계 데이터"와 "실제로 시뮬레이션되는 세계"다. 현재 설계는 이를 원형 → 찍어낸 실물로 읽었는데, 자료는 그 해석이 **승인된 것이 아님**을 여러 번 적고 있다 |
| 다-6 | **사건 기록과 예약** | 자료에는 "이벤트 소싱은 독립적인 기술 선택", "이산사건 처리는 채택되지 않았다"고 적혀 있다. 현재 설계의 사건 기록과 예약은 Claude의 제안이다. 사용자 승인이 없었다 |

## 7. 설계가 틀린 곳

### 집단 시야의 계승

- [09](09-장부-설계.md)는 개인의 시야가 집단의 시야를 물려받는다고 했다. 세력이 알면 구성원도 안다.
- 구 프로젝트는 **일부러 반대로** 했다: "세력이 알았다는 이유만으로 소속원 전원이 즉시 알게 하지 않는다."
  목격자가 무전을 해야 다른 경비가 안다. 전지적 NPC를 막던 장치다.
- 고칠 방향: 계승은 **상식과 규범처럼 원래 모두가 아는 것**에만 쓴다. 새로 생긴 정보는 전달 사건이 있어야 퍼진다.

### "위치는 하나의 관계"

- 가-2. 수납·위·장착에는 맞지만 부분·연결·제어까지 덮지 못한다. 주장을 좁힌다.

### 화면 밖의 시간 계산

- 가-8. 게이지의 시간당 변화를 화면 밖 대상에 그대로 적용하면 허위 정밀도가 생긴다.

## 9. 자료가 이미 경고한 것 가운데 현재 설계에 해당하는 것

- **LLM을 여러 번 부른다고 정합성이 보장되지 않는다.** 각 호출이 보는 정보, 확정 권한, 검증 기준이 중요하다. — 역할 분리의 근거이자 한계.
- **오프스크린을 촘촘히 갱신하면 모순의 면적이 커진다.** — 시계와 예약을 얼마나 촘촘히 돌릴지의 기준.
- **진행도는 세계의 진실을 대체하지 않는다.** 시계가 찼다고 조건이 안 된 변화가 일어나면 안 된다. — 시계 기제에 해당.
- **가정은 사실로 자동 승격하지 않는다.** — 가-5.
- **일부 제약이 프롬프트 지시뿐이다.** 구 프로젝트의 한계로 적혀 있고, 최소 구현의 심판 지시문도 같은 상태다.
