# 코드 권위의 세계 — 사용자 구상의 명확화와 합의

2026-11-13. [25](25-전부-양식으로-저작하는-방안의-검토.md)에서 Claude가 사용자의 방안에 반대했고, 사용자가 그 구상이 실제로 무엇인지 설명했다.
설명을 듣고 나니 **반대한 대상이 사용자의 구상이 아니었다.** 무엇이 같고 무엇이 남는지 정리한다.

## 1. 사용자의 설명 (요지)

### "코드만으로 대부분 기능"의 뜻

- **코드가 상태를 권위 있게 갖는다**는 뜻이다. 행동의 결과까지 코드의 규칙이 정한다는 뜻이 아니다.
- 물건이 젖었는가의 **판단은 마스터**가 한다.
- 젖은 물건의 기능이 어떻게 되고 판정에 어떤 영향을 주는가는 **코드가 가이드를 제시**한다. 물건에 상태 항목을 부여하는 것으로 처리한다.
- 상태를 부여하는 조건과 해제하는 조건에는 **저작된 기준**이 있다. 그 기준은 마스터가 판단할 수도, 코드가 스스로 처리할 수도 있다.

### 예: 추위

> 젖은 의복을 입고 있고, 기온이 일정 이하이고, 바람이 부는가, 플레이어의 신체 조건과 피복 정도를 따져
> 코드가 플레이어에게 추위 상태를 부여할 수 있고, 세계 시간의 흐름에 따라 추위의 등급을 올리거나 낮추고 저체온증 상태를 추가할 수 있다.

### 왜 이 방식인가 — 사용자의 경험

> 플레이어의 신체에 상태를 부여하고 판정에 영향을 주는 기능이 등장했으나,
> 이 상태의 일관적 관리와 기준, 부여와 해제가 **LLM의 판단 하에서는 대체로 형편없었다.**

- **LLM은 명확한 기준과 정해진 판단만 수행하고, 그것을 바탕으로 계산은 코드가 일관적으로 한다.**
- 가능한 상황을 모두 대응할 수 있게 구조를 짜고 저작하는 부담은 있다. 그러나 목표의 달성으로 이어진다면 가치 있다.
- 같은 일이 인물의 정보 보유, 인격, 사회적 행동, 공간과 이동의 개연성 등 많은 영역에서 생긴다.
  그래서 주요 항목뿐 아니라 사회 규범과 인간관계까지 관리·저작의 범주에 넣어 **필요한 정보를 통합적으로 활용**하고자 했다.

### 물건의 기능은 둘이다

| | 뜻 | 예 |
| --- | --- | --- |
| 명시적 기능 | 그 물건이 하도록 만들어진 일 | 도자기 병은 액체를 담는다 |
| 성질에 의해 가능한 행동 | 재질 등의 성질에서 나오는 일 | 도자기는 충격을 받으면 깨지고 날카로워진다. 그래서 흉기로 쓸 수 있다 |

- 재질의 정보는 저작되어 있거나, **비어 있으면 LLM이 필요한 시점에 채운다.** 채운 정보는 판단에 따라 **공용 정보에 편입**할 수 있다.
- 물건은 구성요소를 갖는다. 구성요소는 분리되면 물건의 위상을 가질 수 있다. 도자기 파편도 분리된 뒤에는 기능을 가진 물건으로 등록될 수 있다.

## 2. Claude가 반대한 것은 무엇이었나

- 25 문서는 방안을 "세계가 코드의 규칙으로 굴러간다"와 "모든 것을 양식으로"로 읽고 반대했다.
- 사용자의 구상은 그것이 아니다. **판단은 마스터가 하고, 그 판단에서 나오는 귀결의 계산과 유지를 코드가 한다.**
- 병을 깨서 날붙이로 쓰는 예를 "코드가 모르는 상호작용"의 반례로 들었는데, 사용자의 구상에는 이미 답이 있었다: 재질의 성질과 구성요소.
- 25 문서의 근거 여섯을 다시 본다.

| 근거 | 다시 본 결론 |
| --- | --- |
| 1. 구 기록의 문제는 양식이 모자라서 생긴 것이 아니다 | **약해졌다.** Claude가 구한 반례를 사용자가 냈다: LLM의 판단에 맡긴 상태 관리가 대체로 형편없었다. Claude의 관찰은 두 세션이고, 사용자의 경험은 프로젝트 전체다. 다만 Claude가 본 일곱 문제(주권, 누설, 반복 등)는 별개로 여전히 풀어야 한다. 둘 다 참이다 |
| 2. 양식이 엄격할수록 LLM과의 접점에서 부러진다 | **유효하다.** 반대의 근거가 아니라 **설계 요구**로 남긴다 (§5) |
| 3. 자유도 100%와 코드가 굴리는 세계는 서로 당긴다 | 사용자의 구상이 "코드가 굴리는 세계"가 아니므로 과녁이 틀렸다. 성질 기반 행동이 답의 큰 부분이다 |
| 4. 구 프로젝트가 이미 걸어 본 길이다 | **경고로 유효하다.** 같은 방향으로 가되 같은 곳에서 멈추지 않으려면 무엇이 달라야 하는지가 과제다 (§5) |
| 5. 저작 부담 | 사용자가 알고 감수한다고 했다. 줄이는 방법을 찾는 것은 여전히 과제다 |
| 6. 읽는 곳이 없는 항목 | **규율로 유효하다** |

## 3. 2회차의 결론 하나를 뒤집는다

- [23](23-구조-검토.md) 2회차는 "규칙은 코드가 실행하지 않고, 문장으로 심판에게 건넨다"고 했다.
- 이것이 바로 사용자가 해 보고 **형편없었다**고 한 방식이다.
- Claude는 이 위험을 알 만한 근거를 이미 갖고 있었다. 물건 조사 자료에 "LLM 단독은 상태 전이를 안정적으로 유지하지 못한다"는 연구 보고가 인용되어 있었고, [17](17-통찰과-새-설계.md)에 스스로 옮겨 적었다. 그러고도 걷어냈다.
- **뒤집는다: 상태의 부여·해제·등급 변화의 규칙은 코드가 실행한다.**
  그러므로 조건을 적는 언어([14](14-조건-언어.md))와 오르내리는 값의 기제는 미룰 것이 아니라 **핵심이고, 구현 순서에서도 앞**이다. 사용자가 가장 아팠던 곳이기 때문이다.
- 처음의 구상([08](08-Claude-독자-구상.md) 구상 2 "장부 정리는 코드가, LLM은 좁은 역할로", [09](09-장부-설계.md)의 정의 세 층)이 사용자의 구상과 같은 방향이었다.
  사용자가 "준비하던 재설계와 거의 일치한다"고 한 것이 그 구상이다. **검토 2회차와 25 문서가 거기서 벗어났다.**

## 4. 합의된 원칙

> **판단은 마스터가 한 번 하고, 그 귀결은 코드가 굴린다.**

| | 누가 | 예 |
| --- | --- | --- |
| 무슨 일이 일어났는가의 **판단** | 마스터(LLM). 명확한 기준이 주어진 정해진 판단 | 이 외투가 젖었는가. 이 충격이 병을 깰 만한가 |
| 그 사실에서 나오는 **귀결의 계산** | 코드. 저작된 기준에 따라 | 젖은 옷 → 보온이 준다 → 추위가 오른다 → 판정에 불리 → 저체온증 |
| 시간에 따른 **유지와 변화** | 코드 | 추위의 등급이 시간에 따라 오르내린다. 옷이 마른다 |
| 상태의 **권위** | 코드 | 지금 추위가 몇 단계인가는 장부가 답한다. LLM은 그것을 읽는다 |
| 사전에 **없는 것을 채우기** | LLM. 채운 것은 저장되고, 검토를 거쳐 공용에 편입될 수 있다 | 도자기의 성질 |

- LLM이 일관되게 못 하는 것은 **같은 기준을 여러 번, 시간에 걸쳐 똑같이 적용하는 일**이다. 그 일을 코드로 옮긴다.
- LLM이 잘하는 것은 **이 상황이 그 기준에 해당하는가**를 한 번 가리는 일이다. 그 일을 LLM에게 남긴다.

### 예 1. 추위를 장부의 형식으로

```
마스터의 판단 (한 번):   강호민이 개울에 빠졌다 → 젖음(외투#2) = 참, 젖음(바지#5) = 참

코드가 굴린다:
  보온(강호민)  = 입은 옷의 피복과 두께에서 계산. 젖은 옷은 보온이 준다. 바람이 불면 더 준다
  추위(강호민)  : 기온(이곳)이 쌀쌀함 이하이고 보온이 모자란 동안 → 시간이 흐르는 만큼 등급이 오른다
                  보온이 충분하거나 불 곁에 있는 동안 → 내린다
  저체온증      : 추위가 극심인 채로 일정 시간이 지나면 → 부여
  판정에의 영향 : 추위가 높음 이상이면 손을 쓰는 일에 불리
  젖음(외투#2)  : 마른 곳에서 시간이 지나면 → 해제

서술자가 받는 것:  추위(강호민)가 보통에서 높음으로 올랐다 → "손끝의 감각이 무뎌진다"
```

- 이 예는 [09](09-장부-설계.md)와 [14](14-조건-언어.md)의 형식으로 그대로 적힌다. 조건(`기온(이곳) 이하 쌀쌀함`), 동안 규칙, 오르내리는 값.

### 예 2. 도자기 병

```
사전:  재질 도자기 — 충격에 깨진다. 깨진 조각은 날카롭다.          ← 저작되어 있거나, 비어 있으면 LLM이 채운다
       원형 술병   — 구성: 몸체(도자기), 마개(나무).  명시적 기능: 액체를 담는다

선언: "술병을 탁자 모서리에 내리쳐 깨고, 조각을 집어 든다."

마스터의 판단:   이 충격은 도자기를 깰 만하다
코드가 굴린다:   술병#7 → 깨짐.  담긴 술 → 쏟아짐 (용기가 깨지면 내용물은 쏟아진다)
                 파편#51 생성 (도자기, 날카로움 → 베는 일에 쓸 수 있다)
                 위치(파편#51 → 강호민) = 손에
```

- 플레이어의 예상 밖 선언이 **재질의 성질**을 거쳐 코드가 추적하는 결과가 된다.
- 도자기의 성질이 사전에 없었다면 그 자리에서 채워지고, 그 뒤로 이 세계의 도자기는 언제나 같은 식으로 깨진다.

## 5. 남는 과제

사용자의 구상에 동의한다. 다음은 반대가 아니라 **이 구상이 성립하려면 풀어야 하는 것**이다.

### 가. LLM과의 접점을 어떻게 만드는가

- 구 기록에서 물건 연산이 28턴에 3번 통째로 버려졌다. LLM이 자유롭게 낸 연산이 양식에 맞지 않았다.
- 사용자의 원칙 "LLM은 명확한 기준과 정해진 판단만"을 접점에 그대로 적용하면: **LLM이 연산을 지어내게 하지 않고, 코드가 물음을 내고 LLM이 후보에서 고르게 한다.**
  "이 행동으로 젖는 것은 무엇인가 — 후보: 외투#2, 바지#5, 배낭#1"처럼. 후보 밖의 답이 나올 자리가 없다.
- 다만 자유 선언을 처음 해석하는 일은 열려 있어야 한다. 어디까지 열고 어디부터 닫을지가 설계의 핵심이 된다.
  사용자의 "행동선언 유형에 따라 열어 볼 정보와 고칠 정보를 구별한다"가 이 자리에 들어간다.

### 나. 시간에 따른 계산은 보류 중인 영역에 닿는다

- 추위의 예는 "세계 시간의 흐름에 따라 등급을 올린다"를 요구한다. 사용자는 "예약"과 화면 밖 세계의 진행을 보류했다.
- 적어도 **PC와 그 주변의 상태를 턴마다 흐른 시간만큼 계산하는 일**은 이 구상에 꼭 필요하다. 이것은 사건 대기열 없이 된다.
- 보류의 범위를 좁혀야 한다: 턴 끝의 경과 계산은 하고, 화면 밖의 것을 어떻게 진행시키는가만 보류로 남기는 식이다. 사용자의 확인이 필요하다.

### 다. 구 프로젝트와 같은 곳에서 멈추지 않으려면

- 구 프로젝트도 이 방향으로 갔고 수정 비용에서 멈췄다. 같은 방향으로 가면서 달라야 하는 것:
  1. **형식이 하나다.** 상태, 규칙, 재질, 원형이 모두 같은 모양으로 적힌다. 영역을 더할 때 구조를 고치지 않는다.
  2. **규칙마다 시험이 딸린다.** "젖은 옷, 영하, 바람 → 두 시간 뒤 추위 높음"이 자동으로 확인된다. 규칙을 고쳤을 때 무엇이 달라졌는지 안다.
  3. **항목마다 읽는 곳이 있다.** 코드가 읽지 않는 항목은 양식으로 두지 않는다. 검사기가 읽는 곳이 없는 항목을 알려 준다.
- 이 셋이 Claude가 이 구상에 보탤 수 있는 것이다.

### 라. 저작 부담

- 사용자는 감수한다고 했다. 그래도 줄일 수 있는 만큼 줄인다.
- 사용자의 구상에 이미 길이 있다: **비어 있으면 LLM이 채우고, 검토 뒤 공용에 편입한다.** 사전이 플레이하면서 자란다.
- 채운 것의 질을 어떻게 지키는가(검토 없이 세션에 쓰이는 동안의 일관성, 편입의 기준)는 설계해야 한다.

### 마. 인격과 사회적 행동

- 추위는 계산할 수 있다. 인격과 사회적 행동은 계산의 대상이 아니다.
- 사용자의 말은 "필요한 정보를 통합적으로 활용"이다. Claude는 이것을 **저작해 두고, 상황에 맞는 것을 골라 일관되게 제공한다**로 읽는다.
  무엇을 할지는 마스터가 판단하고, 기만과 설득은 판정이 강제한다. 이 읽기가 맞는지 확인이 필요하다.

### 바. 구 기록에서 본 일곱 문제

- 주권의 침범, 이름의 누설, 대신 추론, 반복, 순응, 서술과 세계의 어긋남, 대기 시간. 이것들은 코드 권위의 세계가 완성되어도 저절로 풀리지 않는다.
- 턴의 흐름과 역할의 분리([10](10-턴-처리-흐름.md))가 맡는 일이다. 두 작업은 함께 가야 한다.

## 6. 정리

| | |
| --- | --- |
| 사용자의 구상 | 코드가 상태의 권위를 갖는다. 판단은 마스터가 명확한 기준으로 하고, 귀결의 계산과 유지는 코드가 한다. 사전에 없는 것은 LLM이 채우고 편입한다 |
| Claude의 판단 | **동의한다.** 근거: 사용자의 직접 경험(LLM에 맡긴 상태 관리의 실패), LLM이 같은 기준을 되풀이해 적용하는 데 약하다는 것, 성질 기반 행동이 자유 선언에 답한다는 것 |
| 철회하는 것 | 25 문서의 반대. 23 문서 2회차의 "규칙은 문장으로 심판에게". 조건 언어와 오르내리는 값을 미룬 것 |
| 유지하는 것 | 접점의 설계, 시험이 딸린 규칙, 읽는 곳이 없는 항목을 두지 않기, 묘사에 그치는 것은 문장으로 |
| 이번 물러섬이 지난번과 다른 점 | 지난번(24 문서)은 반론이 타당해 보여 물러섰다. 이번에는 사용자가 **Claude가 구한 반례**를 냈고, 반대의 과녁이 사용자의 구상이 아니었음이 확인됐다 |
