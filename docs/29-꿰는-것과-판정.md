# 꿰는 것 여섯과 판정 (3단계)

2026-11-13. [27](27-전체-설계도.md)과 [28](28-항목표-초안.md)에서 영역을 가로지르는 것으로 뽑은 여섯(상태, 위치, 앎, 조건, 계승, 권한)과 판정의 명세다.
영역마다 따로 만들지 않고 **한 번만** 만드는 것들이다.

- 깊이는 "무엇을 적고, 코드가 무엇을 하고, 마스터에게 무엇을 묻는가"까지다. 값의 범위와 규칙의 실제 내용은 4단계다.
- 전부 **[제안]**이다. 확정된 것은 따로 표시했다.

## 0. 답변 반영 (2026-11-13)

| 쟁점 | 사용자의 답 | 처리 |
| --- | --- | --- |
| 과업의 "세계 변화" | **과업의 진행이 직접 세계 변화를 일으킬 수 있다.** 플레이어가 과업을 따라가기로 하면, 미리 저작된 선 안에서 어울리는 사실이 만들어진다 | 28 문서의 기본안(과업은 세계를 바꾸지 않는다)을 버린다. 과업은 **빈칸이 있는 틀**이고, 플레이어가 따르기로 할 때 빈칸이 채워져 세계 사실이 된다. 확정의 사다리와 같은 길을 탄다 (§5) |
| 감각 | 여러 사실을 모아 플레이어나 인물이 **어떤 오감을 느끼는지 모아내는** 영역으로 구상했다. 반드시 따를 필요는 없다 | **사용자의 구상을 채택한다.** 다만 저장하는 영역이 아니라 **모으는 기능**으로 둔다 (§3). 서술의 지향이 감각 중심이므로 이 기능이 서술의 재료를 만든다 |

## 1. 상태

> 붙고 떨어지며 귀결을 낳는 것. 물건, 인물, 장소, 환경에 두루 쓰인다.

### 상태 하나의 정의에 적는 것

| 항목 | 뜻 | 예 (추위) |
| --- | --- | --- |
| 붙는 대상 | 어떤 것에 붙을 수 있는가 | 인물 |
| 값의 꼴 | 있다/없다, 또는 등급 | 등급 |
| 부여의 기준 | 언제 붙는가 | 기온이 낮고 보온이 모자란 동안 |
| 해제의 기준 | 언제 떨어지는가 | 보온이 충분하거나 불 곁에 있는 동안 내려간다 |
| 시간에 따른 변화 | 얼마나 빨리 오르내리는가 | 신체 조건과 추위의 정도에 따라 |
| 귀결 | 다른 상태, 기능, 판정에 주는 영향 | 손을 쓰는 일에 불리. 오래가면 저체온증 |
| 얽힘 | 함께 있을 수 없거나 서로 키우는 상태 | 젖음이 추위를 키운다 |
| 드러남 | 남이 알아볼 수 있는가 | 살펴보면 보인다 (떨림) |
| 묘사의 단서 | 등급마다의 느낌 | "손끝의 감각이 무뎌진다" |
| 구실 | 이름과 별개의 기능 표지 | 행동 불능, 사망, 숨어 있음 같은 것 |

### 붙는 세 가지 길

| 길 | 누가 | 예 |
| --- | --- | --- |
| 일이 일어나서 | 마스터가 판단한다 | 개울에 빠졌다 → 젖음 |
| 조건이 맞아서 | 코드가 규칙으로 | 젖은 옷 + 추운 곳 → 추위 |
| 판정의 결과로 | 코드가 여유의 정도로 | 크게 실패 → 부상 |

### 코드가 하는 일

- 턴이 끝날 때 **흐른 시간만큼** PC와 주변(같은 장면의 인물과 물건)의 상태를 계산한다. [확정된 방향]
- 계산의 순서를 정해 둔다: 환경 → 물건 → 인물. 앞의 것이 뒤의 것의 조건이 되기 때문이다.
- 상태가 상태를 부르는 연쇄에는 깊이의 끝을 둔다.
- 주목 밖의 것은 계산하지 않는다. 주목이 돌아올 때 그동안의 시간으로 한 번에 계산하되, 그 사이의 조건을 모르면 마스터에게 묻는다.

### 마스터에게 묻는 꼴

```
이 일로 "젖음"이 붙는 것은?      후보: 외투, 바지, 배낭, 배낭 속 지도, 없음
```

- 이런 물음도 되도록 줄인다(§4). 코드가 항목에서 정할 수 있으면 묻지 않는다.

### 특성 (사용자 설명, 2026-11-13)

- 방수처럼 **바뀌지 않는 성질**은 물건의 기능이나 특성, 재질의 특성으로서 **상태처럼 저작 항목을 붙이는** 방향으로 관리한다.
- 상태와 같은 꼴로 정의하고 붙인다. 다른 점은 시간이나 일로 붙었다 떨어지지 않는다는 것이다.
- 재질에 붙은 특성은 그 재질로 된 물건이 물려받는다 (§5). 규칙의 조건은 특성을 읽는다 ("방수가 아닌 착용물은 젖는다").

### 미결

- 등급의 단계 수를 통일할 것인가 (예: 모두 다섯 단계).
- 같은 종류의 귀결이 겹칠 때 (방한복 두 벌) 더하는가, 큰 쪽만인가.

## 2. 위치

> 무엇이 어디에, 어떤 방식으로 있는가.

```
위치(무엇 → 어디) = 방식
```

- **어디**가 될 수 있는 것: 장소, 지점, 권역, 인물, 물건(용기, 자리).
- **방식**: 안에, 위에, 곁에, 손에, 착용, 품에, 장착.

### 제약 (코드가 지킨다)

| 제약 | 예 |
| --- | --- |
| 한 번에 한 곳 | 검이 두 사람의 손에 있을 수 없다 |
| 용량 | 병에 든 물의 합이 병의 용량을 넘지 않는다 |
| 자리 | 손은 둘이다. 같은 부위의 같은 층에 옷을 둘 입지 못한다 |
| 받아들이는 종류 | 칼집에는 칼이 들어간다 |
| 수량의 보존 | 나누고 합쳐도 총량이 조용히 변하지 않는다 |

### 위치에서 나오는 것 (코드가 계산한다)

| 물음 | 어떻게 |
| --- | --- |
| 어느 장소에 있는가, 누가 지녔는가 | 사슬을 따라 올라간다 |
| 그냥 보이는가 | 닫힌 것 속, 남의 품속, 숨겨진 것은 보이지 않는다 |
| **닿을 수 있는가** | 보이는 것과 따로 따진다. 유리 너머의 것은 보이지만 닿지 않는다 |
| 갈 수 있는가, 얼마나 걸리는가 | 통로의 상태, 방위, 거리의 등급 |
| 멀리서 느껴지는가 | 권역에 걸린 것 (연기, 종소리) |

### 위치가 아닌 연결

위치로 적지 않고 따로 관계로 적는다.

| 연결 | 예 | 쓰이는 곳 |
| --- | --- | --- |
| 구성 | 문의 손잡이, 병의 마개 | 분리되면 물건이 된다 |
| 작동의 이음 | 발전기와 조명 | 한쪽이 서면 다른 쪽도 선다 |
| 호환 | 열쇠와 자물쇠 | |
| 소유 | 누구의 것인가 | 권한 (§6) |

### 미결

- 이동하는 도중의 상태 (길 위에 있다, 도착 예정, 중단).
- 여러 곳에 걸친 것 (긴 밧줄, 강).

## 3. 앎

> 누가 무엇을 어디까지 아는가. 그리고 지금 무엇을 느끼는가.

### 앎 하나에 붙는 것

| | |
| --- | --- |
| 누구의 | 인물, 집단, 문서·소문 같은 담는 것 |
| 무엇을 | 명제 (사실과 같은 꼴. 진실과 다를 수 있다) |
| 인식 단계 | 모름 / 기척 / 겉 / 정체 |
| 믿음의 정도 | 의심 … 확신 |
| 출처와 시각 | 직접 봤다, 누구에게 들었다, 읽었다 / 언제 |

### 앎이 생기는 길

| 길 | 누가 정하는가 |
| --- | --- |
| 지각 | 명백한 경우는 코드, 경계는 마스터에게 묻는다 |
| 전달 (말, 문서) | 일어났는가는 마스터, 기록은 코드 |
| 판정 | 기만의 성공 → 상대의 앎에 거짓 명제가 확신으로 들어간다 |
| 추론 | 인물은 마스터가. **PC는 엔진이 대신하지 않는다** |
| 저작 | 처음부터 아는 것, 캐릭터의 배경 지식 |

- 물려받는 앎은 상식과 규범뿐이다. 그 밖의 것은 전달이 있어야 퍼진다. 조직이 안다고 구성원이 다 아는 것이 아니다.

### 감각 모으기 (사용자의 구상)

> 흩어진 사실을 모아, 어떤 인물이 **지금 오감으로 무엇을 느끼는지**를 내는 기능.

| 감각 | 모으는 곳 |
| --- | --- |
| 보이는 것 | 위치(그냥 보이는가), 장소의 조도와 가시성, 권역의 신호, 물건과 인물의 겉모습, 드러난 상태 |
| 들리는 것 | 이번 턴의 일과 그 소리, 장소의 소음, 권역의 신호 |
| 냄새, 맛 | 환경장, 물건의 상태 (상함, 탐) |
| 닿는 느낌 | 들거나 입은 것, 닿은 것의 재질과 상태 |
| 몸 안의 느낌 | 자기 상태 (추위, 허기, 통증, 피로) |

- 쓰이는 곳은 둘이다.
  1. **서술자의 재료.** 서술의 지향이 감각 중심이다. 서술자가 감각을 지어내지 않고 받는다.
  2. **인물의 판단의 입력.** 인물이 무엇을 보고 들었는가.
- 느낀 것 가운데 새것은 그 인물의 앎에 들어간다.
- 저장하는 영역이 아니다. 인물 정보·관계도·조직도와 같은 **모아 보는 창**이다. 다만 창 가운데 **턴마다 반드시 도는 것**이다.

### 격리

- 각 호출은 그 주체의 앎과 감각만 받는다. 판단 층위만 진실을 본다.

### 미결

- 기억이 흐려지는 것을 다룰 것인가.
- 감각의 경계 사례를 마스터에게 묻는 일이 턴마다 얼마나 생기는가 (대기에 걸린다).

## 4. 조건

> 상태의 기준, 사건의 발생, 계획의 진행, 과업의 달성, 정보의 인지, 규범을 적는 **하나의 언어**.

뼈대는 [14](14-조건-언어.md)에 있다. 요약과 더할 것만 적는다.

| | |
| --- | --- |
| 낱개 | 사실과 같은 꼴에 비교를 붙인다: `기온(이곳) 이하 쌀쌀함` |
| 가리킴 | 정해진 지시어만: 이것, 이곳, 지닌 자, 행위자, 상대, 지금 |
| 미리 계산해 주는 것 | 같은 곳, 안에, 지닌다, 닿는다, 안다, 지속된 시간, 개수 |
| 묶기 | 모두, 하나라도, 아님, 어떤 |
| 답 | 참, 거짓, **모름**. 모름은 발동하지 않는다 |
| 누구의 눈으로 | 기본은 진실. `~가 아는 바로는`으로 감싸면 그 주체의 앎 |

### 더할 것

- **권한**을 묻는 술어: `해도 된다(누가, 무엇을)`.
- ~~판단 물음을 조건에 끼우는 꼴~~ → **고친다** (사용자 지시, 2026-11-13).

### 판단 물음은 되도록 없앤다 [확정된 방향]

사용자: 판단 물음에는 주의가 필요하다. **시스템으로 판단 물음이 불필요하게 만드는 것을 우선한다.**
정보가 부족한 경우는 어차피 마스터가 그 **항목을 저작해야 하는** 경우라는 가설이다.

- 처음 제안은 조건 안에 "바람을 막아 주는 곳인가"를 그때그때 묻는 물음으로 끼우는 것이었다.
- 고친 안: 조건은 **항목만** 가리킨다. 물음을 따로 두지 않는다.

```
모두:
  - 위치(이것 → 지닌 자) = 착용
  - 기온(이곳) 이하 쌀쌀함
  - 바람막이(이곳) = 거짓          ← 물음이 아니라 장소의 항목이다
```

- 그 항목이 비어 있으면 **빈 곳을 채우는 길**(§5)을 탄다: 위에서 물려받고, 없으면 마스터가 그 항목을 채우고, 채운 값은 남는다.
- 달라지는 것:

| | 판단 물음 | 항목 채우기 |
| --- | --- | --- |
| 묻는 것 | 이 상황에 대한 그때그때의 질문 | 사전에 정의된 항목의 값 |
| 답의 꼴 | 질문마다 다르다 | 그 항목에 정해진 값 가운데 하나 |
| 남는 곳 | 따로 정해야 한다 | 그 개체의 그 항목 |
| 다음에 | 비슷한 질문을 또 만들 수 있다 | 같은 항목을 다시 읽는다 |
| 사전 | 자라지 않는다 | 채운 것이 편입되어 자란다 |

- 조건을 쓰다가 가리킬 항목이 사전에 없으면, 그것은 **사전에 항목이 빠져 있다**는 신호다. 물음을 만들지 않고 항목을 더한다.
- 따로 남는 것은 "이 일로 무엇이 일어났는가"의 판단뿐이다(§1의 "일이 일어나서"). 이것도 되도록 줄인다:
  행동의 유형과 대상의 항목에서 코드가 정할 수 있는 것은 코드가 정한다 (물에 들어갔다 → 방수가 아닌 착용물은 젖는다).

### 저작

- 저작자는 글로 쓰고, LLM이 조건으로 옮기고, 코드가 다시 한국어로 풀어 보여 준다. 저작자는 뜻이 같은지만 본다.

## 5. 계승

> 없는 값은 가까운 위에서 가져온다.

| 아래 | 위 | 물려받는 것 |
| --- | --- | --- |
| 실물 | 원형 | 유형의 항목, 기능 |
| 물건 | 재질 | 성질 (깨진다, 탄다, 날카롭다) |
| 장소 | 상위 장소 → 분류 헤드 | 분위기, 환경, 있을 법한 것 |
| 인물 | 역할 → 세계관 → 사람 일반 | 태도와 판단 방식의 가이드, 기대되는 언행 |
| 시나리오 | 공용 사전 | 유형, 상태, 규칙 |

- 가까운 것이 이긴다. 물려받는 항목은 정해 둔 것만이다. [확정 — 사용자의 장소 구상]

### 빈 곳을 채우는 일

| 단계 | 내용 |
| --- | --- |
| 1 | 값이 없고 위에도 없다 |
| 2 | LLM이 그 자리에서 채운다 (도자기의 성질) |
| 3 | 이 세션의 사전에 "채운 것"이라는 표시와 함께 남는다. 이 세션에서는 계속 그 값이다 |
| 4 | 사람이 보고 시나리오나 공용 사전에 편입한다 |

- 사전이 플레이하면서 자란다. [확정된 방향 — 사용자 구상]

### 과업과 사건의 빈칸도 같은 길이다

- 과업은 빈칸이 있는 틀이다. 플레이어가 따르기로 하면 **미리 저작된 선 안에서** 빈칸이 채워져 세계 사실이 된다. [확정 — 사용자 답변]
- 채우는 데 쓰는 것은 확정의 사다리다: 이미 있는 것 → 사전에서 고른 것 → 채운 것.
- 채워진 것은 이미 확정된 사실과 어긋날 수 없고, 닫힌 범위(유일한 물품, 저작된 인물의 정체)를 건드릴 수 없다.

### 미결

- 목록인 항목을 물려받을 때 아래 것이 위 것을 **덮는가, 더하는가**.
- 채운 것의 질을 편입 전에 어떻게 지키는가.

## 6. 권한

> 누가 무엇을 해도 되는가.

### 권한이 생기는 곳

| 곳 | 예 |
| --- | --- |
| 소유 | 이 검은 누구의 것인가 |
| 출입 | 주방은 일하는 사람만 |
| 지휘 | 누가 누구에게 명령할 수 있는가 |
| 약속 | 내일까지 갚기로 했다 |
| 규범과 역할 | 문도는 사부의 말을 따른다. 손님은 계산대 뒤로 들어가지 않는다 |

### 가장 중요한 성질: 권한은 행동을 막지 않는다

- 자유도 100%가 확정이다. 남의 것을 집을 수 있고, 들어가면 안 되는 곳에 들어갈 수 있다.
- 권한은 **그 행동이 무엇을 뜻하는가**를 정한다.

| 권한이 작용하는 곳 | 어떻게 |
| --- | --- |
| 판정 | 해도 되는 일과 안 되는 일은 난이도가 다르다 (빌리기와 훔치기) |
| 인물의 반응 | 본 사람이 어떻게 구는가의 가이드가 달라진다 |
| 평판과 관계 | 위반이 알려지면 바뀐다 |
| 사건과 계획 | 위반이 조건이 된다 (도둑이 들었다 → 경비가 는다) |

### 코드가 하는 일

- 행동이 **누구의 어떤 권한을 건드리는지**를 찾아 판단 층위에 알려 준다.
- 위반이 일어났다는 사실과 그것을 누가 아는지를 기록한다.

### 미결

- 규범이 서로 부딪힐 때 (문파의 규칙과 나라의 법).

## 7. 판정

### 구도 [확정]

- 주사위 둘(각 1~50)을 더한다. **기준값보다 작으면 성공**이다.
- **여유**(기준값 − 굴린 값)에 따라 성패의 **정도**가 갈린다.
- 플레이어가 버튼을 눌러 굴린다. 한 턴에 둘이 필요하면 연달아 낸다.
- 같은 턴의 기술적 재시도에서는 눈을 유지하고, 되감으면 다시 굴린다.
- 기만과 설득에 **강제권**이 있다. 없었던 사실의 발견도 경우에 따라 가능하다.

### 기준값을 이루는 것

| 요소 | 누가 | 근거 |
| --- | --- | --- |
| 스탯 | 코드 | 인물의 값 |
| 숙련 | 코드 | 인물의 값. 판정의 분야에 맞을 때 |
| 스킬 (상시 / 발동) | 코드 | 상시는 저절로, 발동은 선언했을 때. 발동에는 비용 |
| 장비 | 코드 | **실제로** 들거나 입은 것. 분야에 맞을 때 |
| 상태 | 코드 | 분야에 걸리는 상태 |
| 협력 | 코드 | 실제로 함께하고 할 수 있는 이 |
| **난이도** | **마스터** | 이 일이 얼마나 어려운가 |
| **방법** | **마스터** | 이 방법이 얼마나 좋은가 |

- 코드가 장부에서 세는 것을 마스터가 다시 세지 않는다. 같은 사실이 두 번 들어갈 자리가 없다.
- **분야**: 그 판정이 무엇을 쓰는 일인가. 상태·장비·스킬은 분야가 맞을 때만 든다. 다리의 부상은 설득에 들지 않는다.

### 굴리지 않는 경우

- 뻔히 된다 / 될 수 없다 / 실패해도 달라질 것이 없다.

### 여유와 정도

| 정도 | 뜻 |
| --- | --- |
| 크게 성공 | 바란 것보다 더 얻는다 |
| 성공 | 바란 것을 얻는다 |
| 아슬한 성공 | 얻되, 탈이 하나 난다 |
| 아까운 실패 | 얻지 못하되, 틈이 하나 생긴다 |
| 실패 | 얻지 못한다 |
| 크게 실패 | 얻지 못하고, 탈이 크게 난다 |

- 마스터는 굴리기 **전에** 정한다: 되면 무엇이 되는가, 이 일에 걸린 탈은 무엇인가.
- 경계가 되는 여유의 값은 4단계에서 정한다. [24](24-검토에-대한-반론과-수정.md)의 확률표가 근거다.

### 맞서는 판정

- 양쪽이 따로 굴리고 여유를 견준다. 한쪽만 성공하면 그쪽이, 둘 다 성공하면 여유가 큰 쪽이 앞선다.
- 비기는 결과와 둘 다 얻지 못하는 결과가 있다.

### 기만과 설득의 강제

- 성공하면 인물을 구속한다. 기만은 상대의 앎을 바꾸고, 설득은 상대의 의도를 바꾼다.
- 인물의 자율은 판정 **앞**에서 작동한다.

| | |
| --- | --- |
| 난이도 | 인물이 지키려는 것이 클수록 높다. **하한은 코드가 정한다** (비밀의 무게, 관계의 단계에서). 마스터가 낮게 잡아 순응으로 흐르는 것을 막는다 |
| 굴리지 않는 실패 | 말이 안 되는 요구 |
| 정도 | 성공해도 여유만큼만 얻는다. 아슬한 성공은 한 걸음이다 |

### 발견의 판정

- "여기서 ○○를 찾는다"는 선언은, 그 범위가 닫혀 있지 않고 그럴듯하면 판정한다. 성공하면 사전에서 골라 확정한다.
- 중요한 물건과 저작된 품목은 판정 없이 막힌다. [확정 — 역사칭 대응]

### 미결

- 두 능력치를 결합하는 방식 (사용자가 가능성을 언급).
- 버튼에 무엇을 보여 주는가 (기준의 내역, 성공률).
- 값: 평범하게 유능한 인물의 보통 일이 기준 52~62 근처에 오도록 스탯·숙련·난이도의 폭을 다시 잡는다. 4단계.
