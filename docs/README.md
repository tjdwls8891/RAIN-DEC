# RAIN-DEC 설계 기록

이 디렉터리는 재설계 과정에서 나온 설계·원칙·철학·결정을 누적 기록하는 곳이다.
대화에서 확정되거나 의미 있게 논의된 내용은 모두 여기에 파일로 남긴다.

**지금의 기준 문서는 여덟이다.** [27 전체 설계도](27-전체-설계도.md) · [32 항목표](32-항목표.md) · [29 꿰는 것과 판정](29-꿰는-것과-판정.md) · [30 진행](30-진행-조직-계획-사건-과업.md) · [31 접점과 턴](31-접점과-턴.md) · [33 묘사와 경험](33-묘사와-경험.md) · [34 운영](34-운영.md) · [35 구현 순서와 미결](35-구현-순서와-미결.md). 앞선 문서와 어긋나면 이 여덟이 우선한다. 어디부터 읽을지는 35의 §1에 있다.

처음 읽는다면 [22-구상-안내서.md](22-구상-안내서.md)부터(다만 22는 검토 이전의 구상이다). 지금까지의 구상을 한 문서로 설명한다.
그 구상을 비판하고 고친 결과는 [23-구조-검토.md](23-구조-검토.md)에, 그 검토에 대한 사용자의 반론과 수정은 [24-검토에-대한-반론과-수정.md](24-검토에-대한-반론과-수정.md)에 있다.

## 기록 규칙

- **사용자 발언과 Claude의 해석을 구분한다.** 해석·추론에는 `(해석)` 표시를 붙인다.
- **확정 / 미확정을 구분한다.** 합의되지 않은 내용은 `미확정` 또는 `열린 질문`으로 남긴다.
- 결정에는 가능한 한 **이유**를 함께 적는다. 이유가 사라지면 결정도 재검토 대상이다.
- 구 프로젝트에서 온 정보는 출처를 `구 프로젝트`로 명시하고, 새 설계의 근거로 삼을 때는 따로 판단한다.
