# RAIN-DEC 설계 기록

이 디렉터리는 재설계 과정에서 나온 설계·원칙·철학·결정을 누적 기록하는 곳이다.
대화에서 확정되거나 의미 있게 논의된 내용은 모두 여기에 파일로 남긴다.

| 파일 | 내용 |
| --- | --- |
| [00-배경과-협업-원칙.md](00-배경과-협업-원칙.md) | 프로젝트 배경, 진행 방식, 협업 규칙 |
| [01-대화-기록.md](01-대화-기록.md) | 대화 단계별 요약 로그 (시간순) |
| [02-목표와-핵심가치.md](02-목표와-핵심가치.md) | 프로젝트 정의, 대목표, 핵심 가치, 구 프로젝트의 실패 |
| [03-주권-판정-개연성.md](03-주권-판정-개연성.md) | 주권 분리, 판정, 개연성 실패 양상, 시나리오 차이, 플레이 형태 |

이후 주제가 생기는 대로 문서를 추가한다 (예: 목표·요구사항, 설계 원칙, 아키텍처, 결정 기록).

## 기록 규칙

- **사용자 발언과 Claude의 해석을 구분한다.** 해석·추론에는 `(해석)` 표시를 붙인다.
- **확정 / 미확정을 구분한다.** 합의되지 않은 내용은 `미확정` 또는 `열린 질문`으로 남긴다.
- 결정에는 가능한 한 **이유**를 함께 적는다. 이유가 사라지면 결정도 재검토 대상이다.
- 구 프로젝트에서 온 정보는 출처를 `구 프로젝트`로 명시하고, 새 설계의 근거로 삼을 때는 따로 판단한다.
