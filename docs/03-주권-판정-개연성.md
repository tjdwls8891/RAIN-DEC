# 주권, 판정, 개연성 실패 양상

## 주권 분리 (사용자 진술, 확정)

유저와 마스터(게임 진행자 = 디스코드 봇)의 주권은 **완전히 분리**한다.

| | 유저 | 마스터 |
| --- | --- | --- |
| **권한** | PC의 생각, 발화, 행동, 의도를 온전히 결정 | 세계의 현재 상태, 세계의 변화, NPC 반응, 행동의 성공 여부 |
| **금지** | 행동의 성공 여부, 세계의 현재 상태("여기서 ~를 발견했습니다!" 등), 세계의 변화, NPC 반응에 간섭 | 플레이어가 명시하지 않은 PC의 생각·의도·행동·감정을 묘사하거나 대리 결정 (명시한 내용은 예외) |

### 마스터의 묘사 원칙

- 변하는 세계를 **PC가 감각하고 인지할 수 있는 범위 내에서** 묘사한다.
- 플레이어가 **직접 보고 듣는 것처럼 생생하게** 묘사한다.

### 귀결 (해석)

- "자유도 100%"는 **선언의 자유**다. 결과는 세계(마스터)가 판정한다. → 02 문서의 열린 질문 해소.
- 묘사 범위가 PC의 인지로 제한되므로, **세계의 실제 상태**와 **PC가 인지한 상태**는 별개로 존재한다.
  엔진은 서술되지 않은 진실을 보유하고 있어야 한다.

## 판정 (사용자 진술)

- 행동의 성공 여부는 **TRPG의 판정 방식**을 채용해 결정한다.
- 컴퓨터 프로그램의 특성(빠르고 복잡한 계산)을 살려, 행동 방식·도구·난이도 등 **다양한 요소를 조합해 기준값**을 만든다.
- **명백한 상황은 판정 없이** 성공/실패를 결론짓는다.
- 구 프로젝트는 **2d50**을 사용했다. (구 프로젝트 — 새 설계에서 유지 여부는 미확정)

## 개연성이 깨졌던 양상 (구 프로젝트, 사용자 진술)

### 세계 추적의 실패

- 사실의 망각 또는 사실 간 모순
- NPC가 알 수 없는 것을 알고 있음
- 시간·공간·소지품의 어긋남
- 유저가 보지 않는 곳의 세계가 멈춰 있음
- 마스터가 유저의 선언에 지나치게 순응함

### 인물의 실패 ("큰 문제"로 진술)

- NPC의 반응이 기계적임
- LLM 특성인 **과적합·관성**에 이끌림
- NPC가 **묘사의 도구** 정도의 위상만 가짐
- **하나의 LLM이 여러 인물을 동시에 통제하는 티**가 남
- 감정과 대화 자체가 어색함

### 해석 (미확정)

- 실패가 두 계열로 나뉜다: **상태의 문제**(무엇이 참인가)와 **인물의 문제**(누가 왜 그렇게 행동하는가).
  둘은 서로 다른 해법을 요구할 가능성이 크다.
- 인물의 실패는 NPC가 서술자에 종속되어 있을 때 생기는 증상으로 읽힌다.
  NPC가 자기만의 지식·목표·감정 상태를 갖고 서술과 분리되어 결정되는 구조가 필요할 수 있다.
  이는 턴당 LLM 호출 수(비용·지연)와 직결되므로 예산 확인이 선행되어야 한다.

## 시나리오 간 차이 (구 프로젝트, 사용자 진술)

- 어려움의 원인은 **구현할 대상의 성격 차이**였다.
- 예: 좀비 아포칼립스, 무협지, 추리물, 살인마 생존물(『13일의 금요일: 더 게임』 모방),
  게이트 헌터물(『나 혼자만 레벨업』 모방).

### 해석 (미확정)

- 장르마다 **핵심 긴장과 추적 대상**이 다르다
  (자원·생존 / 성장 체계 / 숨겨진 진실과 단서 / 추격과 시간 압박 / 수치화된 능력과 등급).
- 엔진이 특정 장르의 개념을 내장하면 다른 장르에서 깨진다.
  엔진은 장르 중립적인 기반을 제공하고, 장르 고유의 것은 시나리오 쪽에서 정의되어야 한다.
  그 경계를 어디에 긋는지가 확장성 설계의 핵심이다.

## 플레이 형태 (사용자 진술)

- 구 프로젝트는 **1인 플레이**까지만 구현. **다인 세션은 추후 고려 중.**
- 세션 구조(구 프로젝트): Gemini API의 **캐시 시스템**을 이용.
  비용을 지불하고 세션을 연 동안 플레이 가능, 만료되면 재오픈해 이어서 플레이.
- 템포: 시나리오에 따라 한 플레이에 **몇 시간에서 며칠 이상**.

## 열린 질문

- PC의 비자발적 반응(통증, 반사, 기절, 공포·정신 조작 등 강제 상태)의 귀속.
- 서사의 주도권: 기저작된 줄거리·결말이 있는가, 마스터가 사건을 능동적으로 일으키는가.
- 시나리오 저작: 누가 쓰는가, 순수 데이터인가 시나리오 고유 규칙을 포함하는가.
- 턴당 비용·지연 예산, 다중 LLM 호출 허용 여부.
