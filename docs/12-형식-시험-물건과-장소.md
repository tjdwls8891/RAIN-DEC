# 형식 시험 1: 물건과 장소

2026-11-12. [09-장부-설계.md](09-장부-설계.md)의 형식으로 사용자의 **물건 구상**과 **장소 구상**을 실제로 적어 본 결과다.
사용자 원문은 `자료/INDAIM/`의 「03 물건 사용자구상」 U02와 「02 장소및공간」 부록 C02~C08이다.
목적은 형식이 버티는지, 어디서 부러지는지 찾는 것이다. 표기는 예시이며 최종 문법이 아니다.

## 1. 결론

- **형식은 버텼다.** 두 영역의 요구 가운데 다섯 요소(개체, 사실, 정의, 사건, 시야)의 틀 자체를 바꿔야 하는 것은 없었다.
- 그러나 **그대로는 못 썼다.** 고쳐야 할 것이 여덟 가지 나왔고(§4), 그중 둘은 발견에 가깝다.
  - **위치는 하나의 관계다.** 방 안의 사람, 손에 든 검, 병 속의 물, 건물 안의 방이 모두 같은 관계로 적힌다.
  - **틀은 여섯 번째 요소다.** 물건의 원형, 장소 조각, 사건 틀, 시나리오의 변수가 모두 "빈칸 있는 사실 묶음"이다.
- 09 문서의 주장 하나는 **철회**한다: "지각은 코드가 계산한다"는 과했다 (§3.4).

## 2. 물건

### 2.1 적어 본 것

```
# 원형 (세계 사전)
원형: 타이레놀
  분류: [소모성, 약]            # 분류는 여럿 가능
  단위: 정
  섭취 시: 통증(섭취자) 한 단계 하강, 6시간 지속

원형: 물병
  분류: [용기]
  용량: 500ml      허용: [액체]      개구부: 뚜껑

원형: 겨울외투
  분류: [의복]
  피복: [몸통, 양팔]      층: 겉옷
  착용 시: 보온(착용자) 두 단계 상승

원형: 손전등
  분류: [도구, 작동 장치]
  용도(조명) = 가능
  자리: 건전지 1

# 실물 (세션의 장부)
원형(약통#17) = 타이레놀         수량(약통#17) = 12정
위치(약통#17 → 강호민) = 주머니에
위치(물#3 → 물병#1) = 안에        수량(물#3) = 350ml
위치(외투#2 → 강호민) = 착용
위치(건전지#4 → 손전등#1) = 장착
방전(건전지#4) = 참
여는것(열쇠#5 → 자물쇠#9) = 참
위치(열쇠#5) = 변수{ 주모의 방 | 계산대 서랍 | 주모의 허리춤 }
```

### 2.2 요구별 판정

| 사용자 요구 | 결과 | 필요했던 것 |
| --- | --- | --- |
| 원본 데이터와 세션의 실물 구분 | 됨 | **원형–실물**, 실물에 없는 사실은 원형에서 계승 |
| 종류는 이름으로 구분, ml·g 등 단위 | 됨 | 값의 종류에 **단위 있는 양** 추가 |
| 손에 든 것, 착용한 것, 소지한 것의 구분 | 됨 | **위치 관계의 방식** (손에 / 착용 / 주머니에) |
| 착용·소지가 판정과 상태에 영향 | 됨 | 규칙이 "착용자", "소지자"를 가리킬 수 있어야 함 |
| 의복 겹쳐 입기, 옷마다 다른 피복 범위 | 됨 | 값에 **집합** 추가, **자리 기제** (부위 × 층) |
| 젖음·방전 등은 붙을 수 있는 물건에만 | 됨 | 정의에 **적용 대상 조건** |
| 상태가 기능을 바꿈 | 됨 | 둘째 자리에 개체가 아닌 **어휘 항**(용도 종류)을 허용 |
| 미배치 물건을 랜덤·LLM 선정으로 존재 처리 | 됨 | 장소에 **있을 법한 원형의 목록** — 생성은 사전에서의 선택이 됨 |
| 묘사에 등장한 물건의 활용 | 보류 | P4 실현 방식에 달림 |
| 열쇠는 대응하는 자물쇠에만, 개연성 있는 의도적 배치 | 됨 | 관계 사실, 변수 |
| 나눠 보관, 다 마시면 빈 통 | 됨 | 내용물과 용기가 별개 개체. 수량이 0이 되면 내용물만 사라짐 |
| 섭취 효과 | 됨 | 지속 시간이 끝나는 시점의 **예약** |
| 오염도·상함을 정도로 | 됨 | 등급 게이지. 규칙이 "이것이 있는 곳의 온도"를 읽어야 함 |
| 제작 레시피, 구성요소 | 됨 | **변환 기제** (재료 → 결과), 구성요소는 위치 관계(장착) |

## 3. 장소

### 3.1 적어 본 것

```
# 분류 헤드 — 장소가 아님. 속성을 물려주기 위한 머리
분류헤드: 강남_저잣거리류
  분위기 = "사람과 수레가 뒤섞여 시끄럽다."       # 계승 대상으로 선정된 속성
  있을법한 조각 = [객잔, 노점, 골목, 약방]

# 상위 장소와 하위 장소 — 물리적 포함
소속(만리객잔 → 강남_저잣거리류)
위치(객잔_1층 → 만리객잔) = 안에
위치(객실_3호 → 만리객잔) = 안에
위치(객잔앞_대로_2구간 → ?) ...                   # 길도 장소. 긴 길은 구간으로 끊는다

# 이동 연결 — 포함 계층과 독립
통로: 뒷문#3
  잇는다: [객잔_1층, 뒷골목]
  잠김 = 참        겉보기: 누구나 보임
통로: 개구멍#8
  잇는다: [객잔_창고, 뒷골목]
  겉보기: 숨겨짐

# 경계와 전이 — 정성적
경계(객실_3호 ↔ 객실_4호) = "얇은 판자벽"       차음(객실_3호 ↔ 객실_4호) = 낮음
보임(객잔_2층_난간 → 객잔_1층) = 참

# 장소 안의 위치 — 최하위 장소 안에서만 세밀하게
위치(창가 → 객잔_1층) = 안에                      # 지점: 가벼운 개체
위치(강호민 → 창가) = 곁에
위치(주모 → 계산대) = 뒤에
거리(창가 ↔ 계산대) = 가까움
```

### 3.2 요구별 판정

| 사용자 요구 | 결과 | 필요했던 것 |
| --- | --- | --- |
| 여러 개의 분류 헤드, 가장 가까운 위 항목에서 속성 계승, 선정된 속성만 | 됨 | **계승**을 일반 기제로. 정의마다 계승 여부 표시 |
| 상위 장소와 물리적으로 포함된 하위 장소 | 됨 | 위치 관계 (물건과 같은 관계) |
| 복도·길·산·들까지 빈 곳 없이, 긴 길은 끊어서 | 됨 | 개체 |
| 포함 계층과 무관한 이동 연결, 문·창문·개구멍 | 됨 | **통로**를 개체로 |
| 막힘·숨김·잠김 | 됨 | 통로의 사실, 겉보기 등급 |
| 벽을 부수면 새 구멍의 저작 | 됨 | 개체 생성 제안 |
| 벽의 재질, 타 공간에서 전이되는 현상의 정성적 표현 | 됨 | 두 장소 사이의 **대칭 관계 사실** |
| 어디서 무엇이 보이는가, 외관과 내관 | 됨 | 보임 관계, 서술 사실 |
| 정밀 위치는 최하위 장소 안에서만, 장소 내 위치 관계 | 됨 | **지점**: 장소 안의 가벼운 개체. 필요할 때 생긴다 |
| 물건 영역이 관리하지 않는 가구·물건도 장소에 존재 | 됨 | 서술 사실로만 두었다가, 건드리면 실물로 승격 |
| 장소 조각을 만들어 두고 가져다 붙이기 | 됨 | **틀** (§3.3) |

### 3.3 발견: 틀

장소 조각은 여러 개체와 사실이 한 덩어리로 찍혀 나와야 한다. 이것을 적으려다 보니 같은 모양이 네 군데에 있었다.

| 무엇 | 빈칸 | 찍어내면 |
| --- | --- | --- |
| 물건의 원형 | 없음 또는 수량 | 실물 하나 |
| 장소 조각 | 어디에 붙는가, 방의 수 | 장소·통로·지점·있을 법한 물건의 묶음 |
| 사건 틀 | 누가, 무엇을, 어디서 | 계획·시계·관련 사실의 묶음 |
| 시나리오 전체 | 변수 | 세션의 첫 장부 |

- 전부 **"빈칸 있는 사실 묶음을, 빈칸을 채워 장부에 찍어내는 것"**이다. 이것을 **틀**이라 부르고 여섯 번째 요소로 둔다.
- 사용자 구상의 "사건은 틀로써 존재해 빈칸에 물건이나 NPC를 채워 재활용", "장소 조각을 가져다 붙이기",
  "빈칸과 후보", 구 프로젝트의 "세션 개설 시 유일한 세계 상태 생성"이 한 장치가 된다.
- 단역 인물("주모", "문지기")도 틀이다. 저작 부담을 낮추는 길이 한 가지로 모인다.

### 3.4 철회: 지각을 전부 코드로 계산하지 않는다

- 09 문서는 "사건이 일어나면 코드가 누가 지각했는지 정한다"고 썼다.
- 옆방의 소리가 들리는지를 적어 보니, 코드로 하려면 소리 크기 × 차음 등급 × 거리 × 문의 열림을 표로 만들어야 했다.
  사용자가 C08에서 경고한 그대로다: 세부 물리를 시스템화하면 과적합이나 시스템 한계에 의한 개연성 붕괴가 온다.
- 고친 안:
  - **명백한 경우는 코드가 정한다.** 같은 지점·같은 장소에 있으면 지각한다. 연결도 보임도 없으면 지각하지 못한다.
  - **경계 사례는 심판이 정한다.** 코드는 근거가 되는 사실(경계, 차음, 통로 상태, 거리)을 골라 주고, 심판이 판단한다.
  - **판단 결과는 사실로 기록된다.** 한 번 "3호실에서 4호실의 말소리가 들린다"고 정해지면 다음에도 같다.
- 코드가 보장하는 것은 계산이 아니라 **격리와 기록**이다. 심판이 지각했다고 정하지 않은 것은 인물의 문맥에 들어가지 않는다.

## 4. 09 문서에 반영할 개정 사항

1. **틀**을 여섯 번째 요소로 추가한다. 원형, 조각, 사건 틀, 변수를 여기로 통합한다.
2. **위치**를 하나의 관계로 통합한다: `위치(무엇 → 어디) = 방식`. "어디"는 장소, 지점, 인물, 용기, 장치.
   위치의 제약(자리 수, 용량 합, 허용 종류)을 **위치 제약 기제**로 둔다.
3. 값의 종류에 **단위 있는 양**과 **집합**을 더한다.
4. 사실의 둘째 자리에 개체뿐 아니라 **어휘 항**을 허용한다. 대칭 관계를 정의에서 표시할 수 있게 한다.
5. **계승**을 일반 기제로 둔다: 실물←원형, 장소←분류 헤드, 개인 시야←집단 시야. 정의마다 계승 여부를 정한다.
6. 정의에 **적용 대상 조건**을 둔다.
7. 기제 목록에 **예약**(정해진 시점에 일어날 일)과 **변환**(재료 → 결과)을 더한다.
8. 규칙의 조건이 가리킬 수 있는 대상을 **정해진 몇 가지**로 제한한다: 이것, 이것이 있는 곳, 이것을 지닌 자·착용한 자.
9. 지각: 명백한 경우만 코드, 경계 사례는 심판, 결과는 사실로 기록 (§3.4).

## 5. 미저작 공간의 창작에 대하여

사용자 입장(2026-11-12): 개연성을 부여할 수 있다면 허용한다.
배제했던 이유는 사용자 구상의 장소 구조를 창작으로 잘 채울 수 있을지가 미지수였기 때문이다.

이 시험에서 나온 답의 후보:

- 공간의 창작을 **자유 생성이 아니라 틀의 선택과 조립**으로 정의한다.
  1. 분류 헤드가 "여기 있을 법한 조각"의 목록을 갖는다.
  2. 심판은 목록에서 **고르고 빈칸을 채울** 뿐이다. 구조를 지어내지 않는다.
  3. 코드가 구조를 검사한다: 포함 관계가 맞는가, 통로가 양쪽을 잇는가, 기존 장소와 겹치지 않는가.
  4. LLM이 새로 쓰는 것은 **서술문**(외관, 분위기)뿐이다.
- 맞는 조각이 없을 때는 더 작은 조각(방, 복도)을 조립한다. 이 경우의 품질이 진짜 미지수다.
- **미지를 밝히는 방법**: 조각 사전 몇 개와 분류 헤드 하나를 만들어, 가상 플레이어가 미저작 구역을 돌아다니게 하고 결과를 본다.
  구현 초기에 할 수 있는 실험이다. 결과에 따라 허용 범위를 정한다.

## 6. 남은 걱정

- **규칙 언어의 팽창.** 물건만으로 조건·효과·지속·대상 지시가 필요했다. 영역이 늘수록 작은 프로그래밍 언어가 될 위험이 있다.
  저작 난이도 제약과 정면으로 부딪힌다. 대응: 시나리오 저작자는 규칙을 쓰지 않고 **공용 정의를 고르고 값만 채우는 것**을 기본으로 한다.
- **위치 사슬의 깊이.** 건전지 → 손전등 → 배낭 → 강호민 → 창가 → 객잔 1층 → 만리객잔. 질의와 지각 계산의 비용을 재야 한다.
- **기제 목록이 벌써 늘었다.** 두 영역에서 자리, 용량, 예약, 변환이 추가됐다. 남은 열두 영역에서 얼마나 더 늘지 모른다.
  늘어나는 속도가 줄지 않으면 "형식은 하나"라는 주장을 재검토해야 한다.
- **신체**는 물건·장소와 성격이 다르다(부위, 부상, 상태의 상호작용). 다음 시험 대상으로 적합하다.
