# 묘사와 경험 (3단계)

2026-11-14. 다섯 덩어리 가운데 "라. 묘사와 경험"이다. 플레이어가 보고 누르는 것 전부를 다룬다.
서술의 원칙은 이미 확정되어 있다([27](27-전체-설계도.md) §5, [31](31-접점과-턴.md) ⑥). 여기서는 그 밖의 것을 같은 깊이로 정한다.
표시가 없는 것은 **[제안]**이다.

## 1. 원칙

| 원칙 | 뜻 |
| --- | --- |
| 화면은 소설이다 | 화면의 중심은 서술이다. 숫자와 장치는 서술을 가리지 않는 자리에 둔다 |
| 화면은 PC의 앎이다 | 서술, 상태판, 과업, 물음의 답 어디에도 PC가 모르는 것은 나오지 않는다. 전부 같은 창(PC의 앎)에서 그린다 |
| 보여 준 것은 사실이다 | 화면에 나간 것은 철회되지 않는다. [확정] 그래서 화면에 나가는 것은 전부 장부에서 온다 |
| 고르게 하지 않는다 | 선택지를 내밀지 않는다. 방향은 세계의 신호와 압박으로 준다 |

## 2. 한 턴에 보이는 것

```
[플레이어의 선언]
  ↓ 1~2초
① 되읽기 한 줄          "계산대 뒤로 돌아가 뒷문을 열어 본다."
  ↓
② 판정 판 (필요할 때)    무엇을 하는가 · 걸린 것 · 기준값 · [굴린다] 버튼
  ↓ 플레이어가 누른다
③ 굴린 결과             눈 두 개, 합, 여유, 정도
  ↓
④ 서술                  흘러나오듯 이어 쓴다
  ↓
⑤ 상태판                턴마다 갱신: 곳, 상태, 시간, 지닌 것
```

| 조각 | 내용 | 정해진 정도 |
| --- | --- | --- |
| ① 되읽기 | 해석이 선언을 어떻게 읽었는지 한 줄. 잘못 읽었으면 플레이어가 여기서 안다 | 제안 |
| ② 판정 판 | 분야와 하려는 일, **걸린 것**(되면 무엇이, 탈은 무엇인가), 기준값. 버튼은 플레이어가 누른다 | 버튼은 확정. 보여 줄 것은 제안 |
| ③ 결과 | 눈과 합, 여유, 여섯 정도 가운데 하나 | 제안 |
| ④ 서술 | 감각 중심. 700~1,100자를 지향하되 새것이 없으면 짧게 | 확정 |
| ⑤ 상태판 | 턴마다 갱신한다. 서술이 끝난 뒤에 낸다 | 사용자의 말 |

- 되읽기가 틀렸을 때: 판정 버튼을 누르기 전이면 "그게 아니다"로 물릴 수 있다. 세계는 아직 바뀌지 않았다. 버튼 뒤나 서술 뒤에는 되감기다.
- 걸린 것을 굴리기 전에 보여 주는 이유: 플레이어가 무엇을 걸고 굴리는지 알아야 버튼을 누르는 일이 선택이 된다. 걸린 것에는 PC가 알 수 있는 것만 적는다.
- 기준값을 수로 보여 줄지는 판단이 필요하다(§10의 1).

### 디스코드에서

| 것 | 방식 |
| --- | --- |
| 세션의 자리 | 세션마다 스레드 하나. 그 안의 글은 그 세션의 것이다 |
| 선언 | 스레드에 쓰는 보통의 글. 명령어를 붙이지 않는다 |
| 서술이 흘러나오게 | 글 하나를 보내고 고쳐 가며 잇는다. 고치는 간격은 디스코드의 제한 안에서(1초 남짓) |
| 긴 서술 | 2,000자 제한에 걸리면 문단의 경계에서 다음 글로 넘긴다 |
| 버튼 | 누르면 곧바로 받았다고 답하고(3초 안), 그 뒤에 결과를 잇는다 |
| 판정 판과 상태 | 서술과 겉모습이 다른 판(임베드)으로. 서술은 보통의 글로 둔다 |
| 처리 중인 턴에 온 글 | 받지 않고 "아직 앞의 일이 끝나지 않았다"고 알린다 |

## 3. 서술 (확정된 것에 더하는 것)

| 것 | 내용 |
| --- | --- |
| 닫는 법 | 서술은 **세계가 PC 앞에 놓인 채로** 끝난다. 질문("어떻게 하시겠습니까?")과 선택지로 끝내지 않는다 |
| 인물의 말 | 서술 안에 인용으로 넣는다. 말 자체는 판단에서 정해진 것을 그대로 쓴다(서술자가 고치지 않는다). 따로 판을 나누지 않는다 |
| 부름말 | 인식 단계에 맞춘다. 이름을 모르면 "삿갓 쓴 사내". 이름을 알게 된 턴부터 이름 |
| 되풀이 | 이미 쓴 감각에는 표시가 붙어 온다. 같은 냄새와 같은 추위를 턴마다 다시 쓰지 않는다. 바뀌었을 때만 다시 쓴다 |
| 시간 건너뛰기 | 오래 걸리는 행동(길을 간다, 잔다)은 한 턴에 쓴다. 다만 도중에 끼어드는 것(사건의 시작, 상태가 등급을 넘음, 새 지각)이 있으면 **거기서 멈춘다** |
| 문체 | 시나리오가 정한다(시점, 시제, 어조, 금지어). 엔진의 기본은 2인칭 현재가 아니라 시나리오가 고르게 비워 둔다 |
| 유저가 밝힌 내면 | 유저가 쓴 PC의 생각과 감정은 서술에 반영할 수 있다. 쓰지 않은 내면은 만들지 않는다 [확정] |

## 4. 상태판

모아 보는 창이다([32](32-항목표.md) §15). 장부에서 그리며, 따로 저장하지 않는다.

| 칸 | 담는 것 | 보이는 꼴 |
| --- | --- | --- |
| 때와 곳 | 시각(그 세계의 달력으로), 장소, 날씨 | PC가 알 수 있는 만큼. 시계 없이 갇혀 있으면 "밤 무렵" |
| 몸 | 상태와 부상 | **낱말로**. "오한이 든다", "왼 손목을 접질렸다". 등급의 수를 내보이지 않는다 |
| 지닌 것 | 든 것, 입은 것, 넣어 둔 것 | 담긴 곳을 따라 접어서 |
| 함께하는 이 | 동행 | 부름말로 |
| 품은 뜻 | 조건부 선언, 플레이어가 세운 목표 | 플레이어가 쓴 말로 |

- PC가 모르는 것은 나오지 않는다. 걸린 줄 모르는 병은 **증상으로만** 나온다.
- **상태판은 턴마다 갱신한다. 갱신하는 때는 서술이 끝난 때다.** (사용자의 말. Claude가 "부를 때만"으로 썼던 것을 2026-11-14에 바로잡았다.)
- 능력치와 숙련의 수는 **인물 정보**(캐릭터 시트)에 있다. 상태판과 따로 부른다.

## 5. 과업의 표시

| 것 | 내용 |
| --- | --- |
| 무엇이 뜨는가 | 과업의 후보: 저작된 과업 가운데 시작 조건이 맞은 것, PC가 아는 계획과 약속, 플레이어가 세운 목표 |
| 어떻게 | 플레이어가 부를 때 목록으로. PC가 아는 만큼만 적는다 |
| 새로 생겼을 때 | 턴 끝의 한 줄에 조용히 한 줄. 서술을 끊고 알리지 않는다 |
| 따른다는 것 | 따로 "수락"을 누르지 않는다. 플레이어가 그쪽으로 행동하면 따르는 것이다 |
| 끄기 | 시나리오와 플레이어가 끌 수 있다. 꺼도 세계는 같다 |

## 6. 세계 밖의 입력

행동 유형의 첫째(메타/규칙 입력)다. 세계의 시간이 흐르지 않는다.

| 입력 | 처리 |
| --- | --- |
| 상태, 지닌 것, 인물 정보, 과업 | 창을 그려 보인다 |
| 기억을 묻기 ("아까 그 사내가 뭐라고 했지?") | PC의 앎과 지난 서술에서 답한다. 새 사실을 만들지 않는다 |
| 지금 보이는 것을 다시 묻기 | 이미 지각한 것을 다시 적는다. **새로 살피는 것은 행동이다** |
| 규칙을 묻기 | 엔진의 설명에서 답한다 |
| 되감기 | [34](34-운영.md) §2 |
| 세션을 쉬기, 끝내기 | [34](34-운영.md) §1 |

- 세계 안의 말인지 세계 밖의 말인지 모호하면 되묻는다.

## 7. 캐릭터 만들기

시나리오가 셋 가운데 고른다. 섞을 수 있다.

| 방식 | 내용 | 맞는 시나리오 |
| --- | --- | --- |
| 정해진 PC | 저작자가 다 써 둔 인물 | 인물이 이야기의 축일 때 |
| 틀에서 고르기 | 출신, 직업, 특기를 골라 맞춘다 | 세계관에 맞는 폭 안에서 |
| 자유롭게 쓰기 | 플레이어가 글로 쓴다 → **양식으로 옮긴다** → 되읽어 확인받는다 | 폭이 넓을 때 |

**자유롭게 쓸 때의 선**

| 것 | 선 |
| --- | --- |
| 능력치와 숙련 | 시나리오가 정한 예산 안에서. 넘치면 되읽기에서 깎인 값을 보여 주고 플레이어가 고르게 한다 |
| 지닌 것 | 흔한 것은 자유. 유일한 것과 핵심 물품은 안 된다(생성 권한의 등급과 같은 선) |
| 세계에 대한 단정 ("나는 문주의 숨겨진 아들이다") | 시나리오가 **열어 둔 자리** 안에서만 사실이 된다. 밖이면 PC의 믿음이나 자칭으로 남는다 |
| 내면과 과거 | 자유. PC의 것이다 |
| PC가 처음 아는 것 | 출신과 직업에서 물려받는다(계승). 저작자가 더 준다 |

- PC도 인물이다. 같은 항목표를 쓴다. 다른 것은 주권뿐이다(가이드와 의사결정이 비어 있고 유저가 채운다).
- 능력치의 폭은 판정 값의 재조정과 함께 정한다(미결).

## 8. 시작

| 저작하는 것 | 내용 |
| --- | --- |
| 시작 상황 | 때, 곳, PC가 지닌 것과 몸의 상태 |
| PC가 처음 아는 것 | 왜 여기 있는가, 무엇을 아는가 |
| 첫 장면 | 저작자가 쓴 글, 또는 감각 모으기에서 쓰게 맡김 |
| 처음의 계기 | PC를 움직이게 하는 것. 이미 진행 중인 계획의 조짐이거나 시작 조건이 맞은 과업 |
| 변수 | 세션을 열 때 정해지는 것(열쇠가 있는 곳, 범인) |

- 첫 턴 앞에 세계는 이미 돌고 있다. 조직의 계획은 첫 단계에 있고 조짐이 걸려 있다.
- 첫 장면 뒤에도 선택지를 내밀지 않는다. 처음의 계기가 그 일을 한다.

## 9. 결말

| 것 | 내용 |
| --- | --- |
| 결말의 틀 | 저작한다. **조건**(사건·과업과 같은 조건 언어)과 종류, 닫는 글의 가이드 |
| 종류 | 이룸 / 잃음 / 떠남 / 죽음 / 그 밖(시나리오가 더함) |
| 조건이 맞으면 | 닫는 서술을 쓴다. 세션은 닫히지 않고 **닫을지 묻는다** |
| PC의 죽음 | 판정과 상태의 귀결로만 온다. 마스터가 정하지 않는다. 죽음에 닿을 수 있는 판정은 걸린 것에 그렇게 적힌다 |
| 저작되지 않은 끝 | 플레이어가 끝내자고 하면 끝난다. 그때까지의 일로 닫는 글을 쓴다 |
| 닫은 뒤 | 돌아보기: 지나온 일의 줄거리. PC가 몰랐던 진실은 **플레이어가 청할 때** 보여 준다(시나리오가 막을 수 있다) |
| 이어 하기 | 결말 뒤에도 세계는 장부에 남는다. 이어서 할지는 시나리오가 정한다 |

- 결말은 엔진이 몰아가지 않는다. 조건이 맞았을 때 알아볼 뿐이다.

## 10. 필요한 판단

> **아래의 기본안은 허가받지 않은 것이다**(2026-11-14). 사용자가 이해하고 허가한 것만 정해진 것으로 본다.

| # | 쟁점 | 기본안 | 반대쪽의 이유 |
| --- | --- | --- | --- |
| 1 | 판정 판에 기준값을 수로 보이는가 | 보인다. 직접 굴리는 경험에는 과녁이 보여야 한다 | 수가 소설의 감각을 깬다. 낱말("만만치 않다")로만 |
| 2 | 서술 끝에 선택지나 물음을 두는가 | 두지 않는다 | 처음 하는 플레이어가 막막할 수 있다. 과업의 표시가 그 일을 맡는다 |
| 3 | 몸의 상태를 낱말로만 보이는가 | 낱말로만 | 수가 없으면 얼마나 급한지 가늠이 어렵다 |
| 4 | 캐릭터 만들기의 세 방식을 시나리오가 고르게 하는가 | 그렇게 한다 | |
| 5 | 결말 뒤에 숨은 진실을 보여 주는가 | 플레이어가 청하면 | 다시 하는 재미가 준다. 시나리오가 막을 수 있게 |
| 6 | 인물의 말을 따로 판으로 나누는가 | 나누지 않고 서술 안에 | 구 프로젝트의 방식을 모른 채 낸 안이다. 지키고 싶은 경험이 있으면 알려 주면 된다 |

## 11. 미결

| 쟁점 | 내용 |
| --- | --- |
| 서술이 지어낸 세부 | 감각 모으기가 재료를 주면 줄어든다. 그래도 남는 것을 어떻게 기록하는가 — **보류** |
| 세계의 신호가 어디서 오는가 | 조짐(계획·사건)과 감각 모으기에서 온다고 본다. 그것으로 모자란지는 플레이로 본다 — **보류** |
| 되읽기를 턴마다 내는가 | 뻔한 선언에는 군더더기일 수 있다. 측정과 플레이로 |
| 흘러나오는 서술과 디스코드의 제한 | 고치는 간격, 글의 넘김. 구현하며 |
