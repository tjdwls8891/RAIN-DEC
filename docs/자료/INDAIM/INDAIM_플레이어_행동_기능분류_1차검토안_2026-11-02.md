# INDAIM 플레이어 행동 기능 분류 — 1차 검토안

> 작성: 2026-11-02 / 원자료: TRPG 플레이어 행동 가능성 353건 / **미승인 개념 분류(구현 지시가 아님)**

## A. 분류 원칙

1. 분류 대상은 *플레이어 선언*이며 성공 사실이 아니다. 플레이어 의도·수단·대상·조건과 결과를 분리한다.
2. 아래 18개는 **원자료의 1차 색인용 주 기능군**이다. 그대로 18개의 코드 모듈이나 판정 함수를 만들라는 뜻이 아니다.
3. 복합 행동은 복수 도메인을 건드릴 수 있으므로, 1차 분류만으로 구현하거나 결과를 확정하지 않는다. 복합·교차 기재를 함께 참조한다.
4. 세계 상태를 변경하는 기능과, 세계의 정보를 읽거나 주장/질문을 처리하는 기능을 구별한다.
5. 결과 반영 시 판단층위 결정 → 코드 검증·세계 정본 반영 → 확정 내용의 필요한 부분만 묘사층위 전달이라는 새 방향을 따른다.
6. 기존 설명서의 묘사 후 상태 추출 방식은 이번 작업의 작동 전제로 사용하지 않는다.

## E. 1차 교차·이상 사례

- **분해가 필요한 연쇄 선언:** A0162, A0201, A0327, A0332, A0346–A0347. 하나의 목표를 단일 성공·실패로 처리하면 위치·물품·NPC 의사·조직 변화의 중간 단계를 잃는다.
- **과거 확정 주장:** A0163–A0166. 해당 TRPG에 허용 규칙이 있다는 사실과 INDAIM에서 허용하겠다는 정책은 별개이다.
- **동시·다중 행위자:** A0168, A0322–A0324, A0329. NPC 및 여러 PC의 위치·시간·권한을 개별로 검증해야 한다.
- **세계의 사실 대 인지의 분리:** A0123, A0190, A0256, A0343. 조사 성공이 새 비밀을 즉석으로 창작하는 권리가 되면 안 된다.
- **인물의 자율성:** A0145–A0147, A0327, A0330–A0332, A0347. 설득 성공만으로 타인의 선택이나 관계를 자동 커밋해서는 안 된다.
- **장르 전용 수단:** A0016, A0079, A0333–A0336. 초자연 능력은 범용 변경 권한이 아니라 시나리오에 정의된 능력·대상·효과에서 출발한다.
- **메타 입력 및 불완전 선언:** A0026, A0166, A0341–A0342, A0344. 강제 판정·소급 변경·설명 요구를 세계 행동처럼 처리하면 안 된다.
- **선언과 결과의 역전 가능성:** A0336은 ‘화재가 주변에 번지는가’라는 확인이며 엄밀하게는 플레이어 행동보다 결과 질의다.

## F. 분류 검증 및 미확정 쟁점

- 원자료 ID가 A0001~A0353까지 연속이고, 중복·누락 없이 총 353개가 각기 한 개의 주 기능군에 들어갔음을 검증했다.
- **분류 목적 경계:** 이는 행동 패턴 검색·커버리지 검증을 위한 분류이지, 구현 단위별 확정 설계가 아니다.
- 세계 변경의 기본 연산과 상태 스키마, 추가 사실 생성의 권한, 여러 행위 충돌 해결, NPC 자율성의 처리 계약, 세계 시간 정책, 판정 룰은 후속 설계 대상이다.
- 파괴(기물/환경), 추적(감지/이동), 진단(인지/치료), 거점 운영(조직/시설) 등은 1차 귀속보다 *복합 연산 관계*가 더 중요하며 검토 필요하다.
