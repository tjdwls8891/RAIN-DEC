# 항목표 (3단계 확정판)

2026-11-14. [28](28-항목표-초안.md)의 초안에 그동안 정해진 것을 넣어 한 벌로 만들었다. 28을 대체한다.

- 영역 14개를 같은 깊이로 적는다. 항목마다 한 줄이다. 값의 범위, 목록의 실제 내용은 4단계다.
- **＋**는 사용자의 스케치에 없던 것을 더한 항목이다. 뺄 것은 사용자가 지적한다.
- "확정판"은 3단계의 기준이라는 뜻이다. 4단계에서 항목이 늘거나 나뉠 수 있다.

## 읽는 법

| 열 | 뜻 |
| --- | --- |
| 적는 꼴 | **값**(코드가 읽는 수·등급·열거) / **관계** / **규칙**(조건에서 귀결로) / **조건** / **가이드**(마스터가 따르는 기준) / **문장**(묘사) / **틀**(빈칸이 있는 묶음) |
| 꿰는 것 | 상태 · 위치 · 앎 · 조건 · 계승 · 권한 |
| 누가 | **코** 코드가 계산·유지 / **마** 마스터가 판단 / **저** 저작해 두고 읽기만 |

## 8. 규범

스케치에서 조직의 규칙, 관계의 권한, 인물의 권리/의무로 흩어져 있던 것을 모았다.

| 항목 | 적는 꼴 | 꿰는 것 | 누가 |
| --- | --- | --- | --- |
| ＋역할 | 정의 (기대되는 언행) | 계승 | 저. 그 역할의 인물이 물려받는다 |
| ＋관습 | 문장·가이드 (집단이나 지역의) | 계승, 앎 | 저. 그 집단이 아는 것 |

## 13. 행동선언

> **고침 (2026-11-14, [40](40-행동을-열거한-잘못.md)).** 사용자의 스케치에 있는 것은 유형 18가지의 이름뿐이다. 아래의 "유형마다 적는 것"은 Claude가 더한 것이고, 그 가운데 "뻔한 귀결"이 행동을 코드로 열거하는 잘못으로 이어졌다. 뺐다.
> **플레이어의 행동은 열거하지 않는다.** 유형은 선언을 나눠 보는 분류이며, 어떤 유형에도 들지 않는 행동이 막히는 일은 없어야 한다. 무엇이 일어나는가는 유형이 아니라 **항목의 조건과 규칙**에서 나온다.

**유형이 하는 일** (Claude가 더한 것. 유형이 실제로 이 일에 쓸모가 있는지는 확인되지 않았다)
