# 1회차 — 실제 플레이로 찔러 보기

## 1.1 방법

구 세션 기록 둘(영도 16턴, 설화재 12턴)의 실제 선언 28개를 현 설계의 턴 흐름에 넣어 봤다.
"심판은 무엇을 받고 무엇을 내는가, 서술자의 재료에는 무엇이 남는가"를 선언마다 따라갔다.

선언의 실제 모습:

| | |
| --- | --- |
| 선언의 평균 길이 | **20자** |
| 관찰이 들어간 선언 | 28개 중 **15개** |
| 조작 (꺼내기, 챙기기, 닫기) | 7개 |
| 말 | 6개 |
| 이동 | 5개 |
| 공격 | 2개 |
| 판정이 붙은 턴 | 28개 중 14개. 성공률은 **전부 78~89%** |

## 1.2 발견

### 가. 세부는 가장자리가 아니라 본론이다 — 가장 큰 발견

> 선언: "옷차림을 본다." (영도 9턴, 쓰러뜨린 감염자를 보며)

- 현 설계로 따라가면: 심판은 단계 하나("옷을 본다")를 내고, 장부는 바뀌지 않는다. PC가 새로 지각한 것은 감염자의 `외양` 한 줄뿐이다.
  서술자의 재료가 거의 비어 있다.
- 구 기록의 실제 서술: 낡은 체크무늬 셔츠와 빛바랜 면바지, 석 달 동안 찢기고 해진 옷감, 넝마가 된 소매, 점성이 강한 검붉은 피.
  이것이 **"본다"는 선언의 내용물**이다. 이것이 없으면 그 턴은 아무것도 아니다.
- 그런데 이 세부는 누구도 저작하지 않았다. 그 자리에서 만들어졌다.

현 설계에서 이 세부는 어디에 있는가:

| 질문 | 현 설계의 답 |
| --- | --- |
| 누가 만드는가 | 서술자가 "질감을 더하는" 식으로 만들 수밖에 없다. 그런데 서술자는 진실을 모른다 |
| 어디에 남는가 | **남지 않는다.** 서술이 지어낸 세부의 기록은 보류(P4)이고, 문장을 담을 자리인 무른 사실도 보류다 |
| 다음에 어떻게 되는가 | 플레이어가 "그 셔츠를 찢어 붕대로 쓴다"고 하면 장부에 셔츠가 없다. 다른 턴에 "작업복"이라고 서술해도 막을 수 없다 |

- 관찰이 선언의 절반을 넘는다. **저작되지 않은 세부를 보여 주는 일은 예외 처리가 아니라 이 엔진이 가장 자주 하는 일이다.**
- 지금까지 이 문제를 "서술이 어쩌다 지어낸 것을 어떻게 수습하나"로 다뤄 왔다. 방향이 틀렸다.
  세부를 만드는 일은 턴의 **정식 단계**여야 한다.

**필요성: 가장 높다.** "전달된 것은 철회되지 않는다"(확정)를 지키려면 전달된 세부가 어딘가에 남아야 한다.

### 나. 알아보는 데에는 단계가 있다

> 선언: "바위 틈의 물건이 뭔지 시선을 돌려 본다." (영도 6턴)

- 앞 턴에서 PC는 "바위와 어울리지 않는 인공적인 질감의 물건"을 봤다. 이번 턴에 그것이 배낭임을 알았다. 다음 턴에 열어서 내용물을 알았다.
- 현 설계의 시야는 사실을 **알거나 모른다.** "있다는 것은 알지만 무엇인지는 모른다"가 없다.
- 같은 문제가 세 군데에 있었다:
  - 이름을 모르는 인물 → "삿갓 쓴 사내", 대사 판의 "???"
  - 멀리서 본 물건 → "이질적인 물체"
  - 구 프로젝트가 구별하던 "존재만 앎 / 내용까지 앎"
- 지금은 이것을 **호칭**(인물용)과 **겉보기**(속성용)라는 서로 다른 장치 둘로 나눠 놓았다.

**필요성: 높다.** 추리와 탐험의 재미가 여기에 있고, 이름 누설을 막는 것도 이것이다.

### 다. 움직이는 일이 설계에 없다

> 선언: "어깨를 으쓱하곤 남동쪽으로 간다." (영도 4턴)

- 구 기록: 약 7분을 걸어 방치된 부두에 닿는다. 도착한 곳의 풍경이 다섯 문단으로 펼쳐진다.
- 현 설계에서 적을 수 없는 것:
  - **방위.** 장소와 통로는 있는데 "남동쪽"이 없다.
  - **거리와 걸리는 시간.** 통로에 길이가 없다.
  - **도착.** 새 장소에 들어서면 보이는 것이 한꺼번에 수십 개가 된다. 무엇부터 말할지를 정하는 것이 없다.
  - **가는 길에 지각하는 것.**
- 안내서의 예시 둘은 모두 한 방 안에서 일어났다. 이동은 실제 선언의 다섯에 하나인데 한 번도 따라가 보지 않았다.

**필요성: 높다.**

### 라. 멀리서 오는 것을 담을 곳이 없다

- 구 기록에서 가장 좋았던 것: 조선소 쪽에서 일정하게 피어오르는 연기, 바람에 실려 오는 망치질 소리. 가 볼 곳을 알려 주는 **세계의 신호**다.
- 현 설계의 지각은 "같은 장소에 있으면 지각한다"가 기본이다. 섬 반대편의 연기는 어느 장소의 사실인가.
- 분류 헤드는 쓸 수 없다. 사용자가 "지역이나 물리적 구역이 아니다"라고 못 박았다. **지리적으로 묶는 단위가 없다.**

**필요성: 높다.** 확정된 서술 지향("세계의 신호")의 재료다.

### 마. 판정이 사실상 없었다

- 판정 14번의 성공률이 전부 78~89%다. 실패는 28턴에 한 번이었다.
- 굴림이 긴장을 만들지 못하고 대기만 만들었다. "뻔한 일에 굴리지 않는다"가 이미 답이지만, 기록은 그 정도가 생각보다 심했음을 보여 준다.
- 3회차에서 다룬다.

## 1.3 부수고 다시

### 고침 1. 세부는 심판이 만들고, 장부에 문장으로 남는다

```
선언: "옷차림을 본다."

심판이 내는 것
  단계: 쓰러진 감염자의 옷을 살핀다
  새로 드러나는 세부:
    차림(감염자#3): "낡은 체크무늬 셔츠와 빛바랜 면바지. 석 달은 입은 듯 해지고 찢겼다."
    상처(감염자#3): "옆통수가 함몰됐다. 피는 검붉고 끈적하다."
```

- 세부를 **심판**이 만든다. 심판은 진실을 알기 때문에 진실과 어긋나는 세부를 만들지 않는다 (감염된 지 석 달이라는 것을 안다).
- 만든 세부는 서술보다 **먼저** 장부에 들어간다. 서술자는 그것을 재료로 받아 글로 쓴다.
- 그러면 보류 중인 P4("서술이 지어낸 것을 어떻게 기록하나")의 대부분이 사라진다. 서술이 지어낼 필요가 없어지기 때문이다.
  서술자에게 남는 것은 빛, 소리, 냄새 같은 **질감**뿐이고, 질감은 기록하지 않아도 어긋날 것이 없다.
- 사용자가 탐탁지 않아 한 추출 층위도 필요 없다. 추출은 "서술한 뒤에 사실을 뽑는" 것이었고, 이것은 "사실을 정한 뒤에 서술하는" 것이다.

**이 고침은 보류 중인 무른 사실을 필요로 한다.** 사용자의 보류를 뒤집자는 제안이므로 근거를 든다.

1. 사용자의 실제 플레이에서 선언의 절반 이상이 저작되지 않은 세부를 본다.
2. 확정된 원칙상 그 세부는 철회될 수 없다. 그러려면 남아야 한다.
3. "체크무늬 셔츠"를 미리 정의된 속성과 등급으로 적을 방법은 없다. 문장으로 적는 수밖에 없다.
4. 구 프로젝트의 추출 층위가 하던 일이 바로 이것이다. 즉 문장으로 된 사실은 구 프로젝트에도 **이미 있었다.** 문제는 그것이 서술 뒤에 뽑혔다는 것이었다.
5. 사용자가 겪은 자연어의 두 문제(호출마다 해석이 달라진다, 선별이 어렵다)에 대해: 이 문장들은 코드가 판단에 쓰지 않으므로 해석이 갈려도 세계가 어긋나지 않고,
   개체에 딸려 있어 그 개체가 장면에 있을 때만 들어간다.

- 이름을 **세부**로 바꾼다. "무른 사실"은 사실의 등급을 둘로 나누는 큰 제안이었다. 여기서 필요한 것은 그보다 작다:
  **개체에 딸린, 코드가 읽지 않는, 한 번 전달되면 고정되는 문장.** 저작된 `외양`·`성격`과 같은 종류이고, 플레이 중에 늘어난다는 점만 다르다.
- 생성의 한계(확정)는 그대로 적용된다. 세부로 만들 수 있는 것은 평범한 것뿐이다. 핵심 단서, 숨은 통로, 유일한 물품은 세부로 만들 수 없다.

### 고침 2. 인식 단계 하나로 합친다

누가 어떤 개체를 **어디까지 알아봤는가**를 한 가지로 적는다.

| 단계 | 뜻 | 플레이어에게는 |
| --- | --- | --- |
| 모름 | 있는 줄 모른다 | 나오지 않는다 |
| 기척 | 무언가 있다 | "이질적인 물체", "누군가의 그림자" |
| 겉 | 보이는 만큼 안다 | "낡은 배낭", "삿갓 쓴 사내" |
| 정체 | 무엇이고 누구인지 안다 | "이준혁", "뒷문 열쇠" |

- 호칭과 겉보기의 두 장치가 하나가 된다. 서술자는 개체마다 **그 단계의 부름말**만 받는다.
- 인물의 이름, 물건의 정체, 장소의 이름이 같은 방식으로 드러난다.

### 고침 3. 장면과 이동

- **통로에 방위와 걸리는 시간을 적는다.** 등급이면 된다(잠깐 / 몇 분 / 한참). 좌표는 두지 않는다.
- **장면**이라는 단위를 둔다. PC가 있는 장소와 지금 주목하는 것의 묶음이다. 장면이 바뀌면(도착, 큰 변화) 서술은 **펼침**이고, 그 안에서는 **이어감**이다.
- 펼칠 때 무엇부터 말할지는 심판이 고른다. 위협, 사람, 움직이는 것, 선언과 관련된 것이 먼저다. 나머지는 플레이어가 둘러보면 드러난다.
- 긴 이동은 여러 구간을 한 번에 가되, 지각할 것이 나타나는 구간에서 멈춘다. 이미 있는 "멈출 곳에서 멈춘다"를 그대로 쓴다.

### 고침 4. 권역

- 장소를 지리적으로 묶는 **권역**을 둔다. 분류 헤드(성격을 물려주는 머리)와는 별개다.
- "권역 안 어디서나 보이는 것, 들리는 것"을 권역에 적는다: 조선소의 연기, 망치질 소리, 성벽 위의 깃발.
- 이것이 세계의 신호의 **한 가지 출처**가 된다. 화면 밖 세계의 진행이 보류 상태여도, 고정된 신호는 이것으로 낼 수 있다.

## 1.4 1회차의 결론

- 서술 앞에 "세부를 만드는 일"을 정식으로 넣는다. 이것이 가장 중요하다.
- 호칭과 겉보기를 인식 단계로 합친다 (장치 둘 → 하나).
- 방위·시간·장면·권역을 더한다 (장치 넷 추가).
- 걱정: **장치가 또 늘었다.** 2회차에서 따진다.

# 2회차 — 걷어내기

## 2.1 방법

안내서에 나오는 개념을 세고, 각각에 물었다: **이것이 없으면 첫 플레이가 불가능한가. 한 번이라도 돌려 본 근거가 있는가.**

## 2.2 발견

### 가. Claude가 덧붙이기를 하고 있었다

현 설계의 개념:

> 개체, 사실, 정의, 시야, 사건, 틀 / 위치, 통로, 분류 헤드, 계승, 원형과 실물 / 기제 일곱, 규칙, 지침, 조건 언어 /
> 닫힌 범위, 호칭, 겉보기 / 심판, 인물, 서술자 / 단계, 전제, 주목, 정산, 결정의 순간 / 세 해상도와 승격 / 연출가, 시계 / 캐시, 실패의 물러서기

- 서른 개 가까이 된다. 1회차에서 넷을 더 얹었다.
- **이 가운데 실제 LLM으로 한 번이라도 검증된 것은 없다.**
- 이 프로젝트가 다시 시작된 이유는 "아쉬운 점과 추가하고 싶은 기능을 덧붙이는 식으로 개발해 수정 비용이 커졌다"였다.
  지난 며칠 동안 Claude는 자료를 읽을 때마다 장치를 하나씩 더했다. **같은 길을 걷고 있었다.**
- [17](17-통찰과-새-설계.md)에서 "서른 개의 빈틈을 하나씩 메우면 덧붙이기"라고 스스로 적고서도, 다섯 개의 새 장치로 답했다.

### 나. 조건 언어는 지금 필요하지 않다

- [14](14-조건-언어.md)에서 문법, 지시어, 파생 술어, 세 값 계산, 되읽기까지 설계했고 코드도 일부 만들었다.
- 쓰이는 곳은 규칙, 사건의 발동, 시계의 진행, 상태의 적용 대상, 변수의 제약이다. 그런데 **규칙을 실행하는 코드는 없고, 사건 틀도 시계도 없다.**
  쓰이는 곳이 없는 언어를 먼저 만들었다.
- 심판이 진실을 보고 판단하는 구조에서는 "피로가 높으면 몸을 쓰는 일에 불리"를 조건 언어로 적지 않아도 된다. 심판에게 건네는 문장 한 줄이면 된다.
- 조건 언어가 정말 필요한 것은 **코드가 LLM 없이 판단해야 하는 곳**뿐이다. 지금 그런 곳은 변수의 제약 하나다.

### 다. 기제 일곱, 틀, 연출가, 승격 규칙

| 장치 | 지금 없으면 안 되는가 | 판단 |
| --- | --- | --- |
| 기제: 오르내리는 값 | 등급을 올리고 내리는 것은 심판의 제안으로 된다. 자동 변화가 필요한 것은 허기 같은 몇 가지 | 미룬다 |
| 기제: 상태의 옮겨 감, 재료의 변환, 자리와 용량 | 날씨, 제작, 옷 겹쳐 입기. 첫 플레이에 필요 없다 | 미룬다 |
| 기제: 계승 | 원형과 분류 헤드에 쓴다. 저작 부담을 줄이는 핵심 | **남긴다** |
| 틀: 원형, 시나리오의 변수 | 쓴다 | **남긴다** |
| 틀: 사건 틀, 장소 조각, 단역 틀 | 종이 위의 개념. 쓰는 곳이 없다 | 미룬다 |
| 연출가 | "코드로 된 완급 조절자"라고만 적었고 무엇을 하는지 한 번도 구체화하지 못했다 | **버린다.** 3회차에서 다른 답을 찾는다 |
| 세 해상도의 승격 규칙 (몇 번 상대하면 주요) | 코드가 세지 않아도 심판이 "이 인물을 이제 따로 적자"고 제안하면 된다 | 규칙은 버리고 개념만 남긴다 |
| 닫힌 범위의 형식 | 범주별 기본값(출입구·인물·유일한 물품은 닫힘)만 있으면 시작할 수 있다 | 기본값만 남긴다 |

### 라. 전제를 따로 적을 필요가 없다

- 단계 계획에서 심판은 단계마다 전제("문이 잠기지 않았다")를 적고, 엔진이 그것을 장부에서 확인했다.
- 그런데 심판은 진실을 보고 있다. 문이 잠긴 것을 안다. 처음부터 "밀었으나 열리지 않는다"로 계획을 쓰면 된다.
- 엔진은 어차피 심판의 **제안을 검사한다.** 잠긴 문을 지나 옆 장소로 옮기자는 제안은 검사에서 걸린다. **검사가 곧 전제 확인이다.**
- 전제 필드, 그것을 적을 언어, 그것을 계산할 코드가 전부 필요 없다. 심판의 출력도 짧아진다.

### 마. 1회차의 추가분도 따진다

| 1회차의 추가 | 판단 |
| --- | --- |
| 세부 | 남긴다. 다만 새 요소가 아니라 **이미 있는 서술문 값이 플레이 중에 늘어나는 것**으로 본다. 장치가 늘지 않는다 |
| 인식 단계 | 남긴다. 둘을 하나로 줄인 것이다 |
| 통로의 방위와 시간 | 남긴다. 통로에 사실 두 줄을 더하는 것이지 새 장치가 아니다 |
| 장면 | **다시 본다.** 따로 저장할 것이 있는가. "지금 주목하는 것"은 주목이고, "이미 말한 것"은 PC의 시야다. 저장할 새것이 없다. 개념으로만 쓰고 저장하지 않는다 |
| 권역 | 남긴다. 다만 장소를 묶는 개체일 뿐이다. 위치 관계로 적힌다 (`위치(방파제 → 서쪽_해안) = 안에`). 새 장치가 아니다 |

## 2.3 부수고 다시 — 걷어낸 뒤의 구조

### 저장: 세 가지

| | 무엇 | 예 |
| --- | --- | --- |
| **개체** | 있는 것 | 강호민, 뒷문, 서쪽 해안 |
| **사실** | 개체에 대한 한 줄. 누구의 앎인지가 붙는다 | `위치(철검 → 강호민) = 허리에` / 주모가 아는 것: `정체(척후) = 흑풍채 척후` |
| **어휘** | 코드가 읽는 속성의 목록과 가능한 값 | `잠김: [참, 거짓]`, `피로: [없음 … 극심]` |

- 사실의 값은 둘 중 하나다: **코드가 읽는 값**(어휘에 있는 것) 또는 **문장**(세부. LLM만 읽는다).
- 시야는 따로 있는 요소가 아니라 **사실에 붙은 "누구의 앎인가"**다. 세계의 것이면 진실이고, 누군가의 것이면 그 사람의 앎이다. 인식 단계도 여기에 붙는다.
- 틀은 따로 있는 요소가 아니라 **두 가지 쓰임**이다: 원형에서 물려받기, 세션을 열 때 변수 정하기.
- 사건(기록 방식)은 보류이므로 요소에서 뺀다. 요구만 남긴다: 한 턴의 변화는 한 번에 확정되고, 되감을 수 있다.

여섯 요소가 셋이 된다.

### 작동: 그대로 두되 가볍게

```
선언 → 심판 → [버튼] → [인물] → 서술자 → 확정
```

- 심판이 내는 것: 되읽기, 단계(전제 없이), **새로 드러나는 세부**, 바뀌는 사실, 판정의 설계, 주목과 인물의 반응.
- 코드가 하는 것: 제안의 검사, 역량 세기, 주사위, 시간, 지각한 것 모으기, 확정.
- 규칙은 코드가 실행하지 않는다. **어휘에 딸린 문장으로 심판에게 건넨다.** ("피로가 높음 이상이면 몸을 쓰는 일에 불리하다")

### 미룬 것을 되살리는 기준

미룬 것은 버린 것이 아니다. 다음 가운데 하나가 **측정으로 확인되면** 되살린다.

- 심판이 같은 규칙을 턴마다 다르게 적용한다 → 그 규칙을 코드로 옮긴다 (그때 조건 언어가 필요해진다)
- 심판의 문맥이 지침으로 넘친다 → 지침을 조건으로 걸러 준다
- 저작자가 같은 묶음을 되풀이해 쓴다 → 틀로 만든다

- 설계의 순서를 뒤집는 것이다. 지금까지는 "필요할 것 같은 장치를 먼저 설계"했다. 앞으로는 **"돌려 보고, 부러진 곳에만 장치를 넣는다."**
- 이것은 [17](17-통찰과-새-설계.md)의 "무르게 시작해 굳힌다"를 엔진 자체에 적용한 것이다.

## 2.4 2회차의 결론

- 저장의 요소를 여섯에서 셋으로 줄인다.
- 조건 언어, 기제 여섯, 사건 틀, 장소 조각, 연출가, 승격 규칙, 전제 필드를 걷어낸다.
- 이미 만든 조건 언어의 코드와 문서는 매몰비용이다. 지우지는 않고 쓰지 않는다.
- 걱정: 걷어낸 것 가운데 **목표에 꼭 필요한 것**이 있는가. 특히 연출가를 버렸는데 완급은 누가 맡는가. 3회차에서 따진다.

# 3회차 — 목표에서 거꾸로 보기

## 3.1 방법

대목표와 거기서 나온 조건을 하나씩 놓고, 2회차까지의 구조가 그것을 **위해 무엇을 하는가**를 물었다.

> 유저는 매력적인 소설의 등장인물이 된 듯한 경험을 한다.
> 세계와 인물이 매력적이고, 서사가 흥미롭고, 반복해도 다채롭고, 개연성이 훌륭히 지켜지고, 완전히 자유롭게 선언할 수 있다.

## 3.2 발견

### 가. 설계가 한쪽으로 기울어 있다

| 조건 | 설계가 하는 일 | 평가 |
| --- | --- | --- |
| 개연성 | 장부, 검사, 정보 격리, 앎의 분리 | 설계의 거의 전부가 여기에 있다 |
| 자유로운 선언 | 무엇이든 단계로 옮긴다, 상태는 금지하지 않는다 | 있다 |
| 다채로움 | 변수 | 있으나 얕다 |
| **흥미로운 서사** | 세력의 계획, 시계, 연출가 | **전부 보류이거나 2회차에서 버렸다** |
| **매력적인 인물** | 성격·말투의 문장, 결정의 순간 | 저작과 LLM에 맡겼다 |

- 이 설계는 **틀리지 않는 세계**를 만드는 데 힘을 다 쓰고 있다. 틀리지 않는 세계는 지루할 수 있다.
- 구 기록에서 좋았던 순간을 다시 보면 전부 **긴장**이었다: 물이 차오르기 전에 닿아야 하는 물건, 고개를 천천히 돌리는 감염자, 작살을 겨눈 채 "쉿" 하는 사내.
  개연성이 아니라 **무언가가 다가오고 있다는 감각**이었다.
- 그리고 그 감각을 만드는 장치가 현 설계에서는 통째로 보류다.

### 나. 판정이 긴장을 만들지 못한다

- 성공률 78~89%의 굴림은 결과가 뻔하다. 그런데 사용자는 버튼을 누르는 경험을 지키고 싶어 한다(확정).
  **버튼이 값지려면 누를 때 무언가가 걸려 있어야 한다.**
- 지금의 뼈대는 "굴리는 문턱을 높인다"까지만 말한다. 문턱을 높이면 버튼이 드물어진다. 사용자가 원하는 것과 반대일 수 있다.
- 사용자는 더 나은 판정을 원한다고 했다(과제).

### 다. 사회적 장면에서 능력치가 사라진다

- "설득이 통하는지는 주사위가 아니라 인물이 정한다"고 했다. 순응을 막으려는 것이었다.
- 그런데 그러면 PC의 `언변`은 아무 일도 하지 않는다. 형사로 십 년을 일한 PC와 말주변 없는 PC가 같은 말을 하면 같은 결과가 나온다.
- TRPG에서 능력치는 "내가 만든 인물이 나와 다르게 잘하는 것"이다. 사회적 장면에서 그것을 지운 것은 지나쳤다.

### 라. 2회차에서 버린 연출가

- 버린 것 자체는 옳았다. 무엇을 하는지 적지 못한 장치였다.
- 그러나 그것이 맡으려던 일(완급)은 남아 있다.

## 3.3 부수고 다시

### 고침 1. 긴장을 가장 작은 형태로 넣는다 — 시계 하나

> **시계**: 다가오는 일 하나. 몇 칸으로 되어 있고, 칸이 찰 때마다 플레이어가 지각할 수 있는 **조짐**이 있다. 다 차면 일이 벌어진다.

```
시계: 밀물                       있는 곳: 해안 창고 일대
  ○○○○  →  창고 바닥까지 물이 든다. 바위 틈의 것은 쓸려 간다
  조짐:  1칸 "바위 아래에서 물이 넘실거린다"
         2칸 "파도 소리가 가까워진다"
         3칸 "창고 문턱까지 물이 찰랑인다"
  채워지는 때: 시간이 흐를 때 (20분마다 한 칸)

시계: 감염자의 주의              있는 곳: 감염자#3
  ○○○  →  달려든다
  조짐:  1칸 "턱관절 소리가 멎는다"   2칸 "고개가 이쪽으로 꺾인다"
  채워지는 때: PC가 소리를 낼 때
```

- 구 기록의 좋은 순간 둘이 모두 이 모양이다.
- **코드가 하는 일은 하나뿐이다**: 턴이 끝날 때, PC와 같은 권역에 있는 시계에 대해 흐른 시간만큼 칸을 채운다.
  "소리를 낼 때" 같은 채움은 심판이 제안한다.
- 서술자는 지금 칸의 조짐을 재료로 받는다. **세계의 신호와 압박의 두 번째 출처**다 (첫 번째는 1회차의 권역).
- 세력의 계획도 같은 모양이다: `흑풍채의 습격  ○○○○○`. 조짐은 소문과 낯선 얼굴이다.
- 완급은 따로 조절하지 않는다. **저작자가 시계의 칸 수와 속도로 정한다.** 연출가가 필요 없다.

보류와의 관계 — 근거를 들어 제안한다:

- 사용자는 "예약"과 "화면 밖 세계의 진행"을 보류했다. 시계는 그 영역에 닿는다.
- 다만 이 형태는 보류의 이유였던 것(사건 대기열, 세계 전체를 시간에 따라 돌리는 장치)을 쓰지 않는다. **턴 끝에 한 번, 가까운 시계만, 덧셈 하나**다.
- 먼 곳의 시계는 돌리지 않는다. PC가 그 권역에 들어설 때 "그동안 흐른 시간"만큼 한꺼번에 채운다. 사이의 사정을 모르는 것은 채우지 않고 심판에게 묻는다.
- 근거: 사용자가 좋게 본 것(흐르는 압박)이 확정된 지향인데, 그것을 만드는 장치가 설계에 하나도 없는 상태다. 이것이 가장 작은 답이다.

### 고침 2. 판정 — 두 축

> 버튼을 누르면 주사위 **둘**이 굴러간다. 하나는 **되는가**, 하나는 **형세가 어디로 기우는가**.

|  | 형세가 유리하게 | 형세가 불리하게 |
| --- | --- | --- |
| **된다** | 되고, 덤이 생긴다 | 되지만, 탈이 난다 |
| **안 된다** | 안 되지만, 틈이 생긴다 | 안 되고, 탈도 난다 |

```
자물쇠를 딴다
  되는가:   손재주로 굴린다         →  문이 열린다 / 열리지 않는다
  형세:     은밀함으로 굴린다       →  아무도 못 들었다 / 쇠 긁는 소리가 구석 탁자까지 갔다
```

- 사용자가 말한 **두 능력치를 결합한 판정**이 자연스럽게 나온다. "되는가"는 그 일을 하는 능력, "형세"는 그 일에 걸린 **위험을 다루는 능력**이다.
- 성공률이 높아도 굴릴 값이 생긴다. 문은 거의 열리겠지만 **소리가 났는가**가 걸려 있다. 버튼이 다시 뜻을 갖는다.
- "대가가 따르는 성공"과 "틈이 생기는 실패"가 따로 규칙 없이 나온다. 실패해도 이야기가 멈추지 않는다.
- 형세의 불리함은 **시계를 채운다.** 소리가 났다 → 감염자의 주의 한 칸. 판정과 긴장이 한 장치로 이어진다.
- 심판이 굴리기 전에 정하는 것: 되면 무엇이 되는가, 이 일에 걸린 위험은 무엇인가(=형세가 가르는 것). 지금의 뼈대와 같다.
- 형세에 걸 위험이 없는 일은 축이 하나다. 걸 것이 아예 없으면 굴리지 않는다.

- 이것은 후보다. 사용자가 "함께 연구"하자고 한 영역이고, 주사위의 종류와 수치는 정하지 않았다.
- 참고한 것: 성패와 부수 효과를 따로 내는 방식은 기존 TRPG에 여럿 있다(Genesys의 두 종류 기호, Blades in the Dark의 위험과 효과, Ironsworn의 약한 성공).
  그대로 가져온 것은 없다. Claude의 기억에 의한 것이며 이번에 원문을 확인하지는 않았다.

### 고침 3. 사회적 장면 — 능력치는 "어떻게 전해졌는가"를 가른다

- 인물이 무엇을 할지는 여전히 **인물이 정한다.** 숨길 것이 있는 사람은 주사위가 좋아도 자백하지 않는다.
- 주사위는 PC의 말이 **어떻게 전해졌는가**를 정한다. 그것이 인물의 판단에 들어간다.

```
"형사입니다. 무릎을 좀 보죠."        (언변으로 굴린다. 축은 형세 하나)

  유리하게:  윤서진에게는 이 말이 "거절하면 의심받겠다"로 들린다. 눈에 띄게 당황한다 (PC가 그것을 본다)
  불리하게:  윤서진에게는 "다짜고짜 무례한 사람"으로 들린다. 방어적이 되고, 다음부터 말을 아낀다
```

- 어느 쪽이든 윤서진이 무릎을 보여 줄지는 그녀의 호출이 정한다. 다만 그녀가 받는 **입력이 다르다.**
- 능력치가 다시 일을 하고, 순응도 막힌다. 좋은 주사위가 주는 것은 복종이 아니라 **더 유리한 판**이다.

### 고침 4. 인물의 매력에 대해 — 장치를 더하지 않는다

- 여기에는 답을 내지 못했다. 장치로 풀 문제가 아니라고 본다.
- 인물의 매력은 저작된 문장(성격, 말투, 바라는 것, 숨기는 것)과 그것을 살리는 지시문에서 나온다. 구조가 할 일은 **방해하지 않는 것**이다:
  인물이 자기 이해관계로 움직이게 하고(결정의 순간), 모르는 것을 말하지 않게 하고(격리), 같은 반응을 되풀이하지 않게 한다.
- 실제로 인물이 매력적으로 나오는지는 돌려 봐야 안다. 이 영역은 측정과 지시문 작업의 몫이다.

## 3.4 3회차의 결론

- 긴장을 **시계** 하나로 넣는다. 보류 영역에 닿으므로 사용자의 판단이 필요하다.
- 판정을 **두 축**으로 바꾸는 후보를 낸다.
- 사회적 장면에서 주사위는 "어떻게 전해졌는가"를 가른다.
- 2회차에서 버린 연출가는 되살리지 않는다. 시계의 칸 수와 속도가 완급이다.

# 검토 뒤의 구조

## 한눈에

**저장** — 셋

| | |
| --- | --- |
| 개체 | 인물, 물건, 장소, 통로, 권역, 분류 헤드, 시계 |
| 사실 | `속성(주체 → 대상) = 값`. 값은 코드가 읽는 값이거나 문장(세부). 누구의 앎인지와 인식 단계가 붙는다 |
| 어휘 | 코드가 읽는 속성과 가능한 값. 심판에게 건네는 문장이 딸린다 |

**작동**

```
선언 → 심판 → [버튼: 되는가 · 형세] → [인물: 결정의 순간] → 서술자 → 확정 → 가까운 시계를 채운다
```

| 역할 | 내는 것 |
| --- | --- |
| 심판 | 되읽기, 단계, 새로 드러나는 세부, 바뀌는 사실, 판정의 설계(되면 무엇이, 걸린 위험은 무엇인가), 주목과 인물의 반응 |
| 코드 | 제안의 검사, 역량 세기, 주사위, 시간, 시계, 지각한 것 모으기, 확정, 실패 처리 |
| 인물 | 결정의 순간의 선택과 대사 |
| 서술자 | 산문. 받는 것: 되읽기, 새로 지각한 것(세부 포함), 인물의 말, 조짐과 권역의 신호, 인식 단계에 맞는 부름말 |

## 달라진 것

| | 검토 전 | 검토 뒤 |
| --- | --- | --- |
| 저장의 요소 | 여섯 | 셋 |
| 저작되지 않은 세부 | 서술자가 지어내고 기록은 보류 | 심판이 만들어 서술 전에 장부에 넣는다 |
| 알아보기 | 호칭 + 겉보기 | 인식 단계 하나 |
| 규칙 | 조건 언어로 적고 코드가 실행 | 문장으로 심판에게 건넨다. 부러지는 곳만 코드로 |
| 전제 | 단계마다 적고 코드가 확인 | 없음. 제안의 검사가 대신한다 |
| 이동 | 없음 | 통로에 방위와 걸리는 시간. 지각할 것이 나타나면 멈춘다 |
| 멀리서 오는 것 | 없음 | 권역 |
| 긴장 | 연출가 (무엇인지 정하지 못함) | 시계와 조짐 |
| 판정 | 성공/실패, 대가는 따로 | 되는가 × 형세 |
| 사회적 판정 | 주사위 없음 | 주사위는 "어떻게 전해졌는가"를 가른다 |
| 미룬 것 | — | 조건 언어, 기제 여섯, 사건 틀, 장소 조각, 승격 규칙 |

## 사용자의 판단이 필요한 것

| # | 내용 | 성격 |
| --- | --- | --- |
| 1 | **세부를 문장으로 장부에 남긴다** | 보류 중인 무른 사실을 좁힌 형태로 되살리자는 제안. 근거는 1회차 고침 1 |
| 2 | **시계** | 보류 중인 예약·화면 밖 진행에 닿는다. 가장 작은 형태로 제안. 근거는 3회차 고침 1 |
| 3 | 저장의 요소를 셋으로 줄이고 조건 언어 등을 미룬다 | 지금까지 수용된 것(여섯 요소, 기제 일곱)을 뒤집는다 |
| 4 | 두 축 판정, 사회적 판정 | 판정 연구의 첫 후보 |
| 5 | 인식 단계, 권역, 통로의 방위와 시간 | 추가 |

## 이 검토가 하지 못한 것

- **LLM으로 돌려 보지 않았다.** 심판이 세부·단계·판정 설계·인물의 반응을 한 번에 잘 내는지가 이 구조 전체의 성패인데, 확인하지 못했다.
  2회차에서 걷어낸 만큼 심판의 일은 **늘었다.** 가장 큰 위험이 한 곳에 모였다.
- 실제 선언 28개는 한 사람의 두 세션이다.
- 전투, 캐릭터 생성, 결말, 디스코드 화면, 과금은 다루지 않았다.
- 인물의 매력에는 구조적인 답을 내지 못했다.
