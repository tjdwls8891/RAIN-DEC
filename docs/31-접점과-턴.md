# 접점과 턴 (3단계)

2026-11-13. 마스터의 층위와 코드가 만나는 방식, 그리고 한 턴의 흐름이다.
[10](10-턴-처리-흐름.md)(v0.2)을 [26](26-코드-권위의-세계.md)·[29](29-꿰는-것과-판정.md)·[30](30-진행-조직-계획-사건-과업.md)의 합의에 맞춰 다시 쓴다. 어긋나는 곳은 이 문서가 우선한다.
전부 **[제안]**이며, 확정된 것은 표시했다.

## 1. 접점의 원칙

| 원칙 | 출처 |
| --- | --- |
| 판단은 마스터가 한 번, 귀결은 코드가 | 확정 |
| LLM은 명확한 기준과 정해진 판단만 한다 | 확정 |
| 판단 물음은 되도록 없앤다. 정보가 모자라면 물음을 만들지 않고 **항목을 채운다** | 확정된 방향 |
| 대상을 선정하고, 세계 사실을 확정하고, 그 뒤에 묘사한다 | 확정 |
| 모르는 것은 주지 않는다 (지시가 아니라 문맥으로 막는다) | 확정 |

여기서 접점의 모양이 나온다.

> **LLM이 여는 곳은 둘뿐이다: 선언을 읽는 곳과 글을 쓰는 곳.** 그 사이는 코드가 묻고 LLM이 고른다.

| | 열려 있는가 | LLM이 하는 일 |
| --- | --- | --- |
| 해석 | 열림 | 자유로운 문장을 행동으로 옮긴다 |
| 판단 | **닫힘** | 코드가 낸 물음에 후보에서 고른다. 빈 항목을 채운다 |
| 서술 | 열림 | 확정된 것을 글로 쓴다 |

- 구 기록에서 물건 연산이 버려진 것은 LLM이 **연산을 지어냈기** 때문이다. 닫힌 판단에서는 후보 밖의 답이 나올 자리가 없다.

## 2. 한 턴

```
선언
 │
 ├─ ① 해석 (LLM)     선언 → 행동들. 유형, 대상, 수단, 방식, 의도, 말
 ├─ ② 준비 (코드)     유형이 가리키는 정보를 모은다. 대상을 확정한다. 물을 것을 추린다
 ├─ ③ 판단 (LLM)     코드가 낸 물음에 답한다
 ├─ ④ 판정 (코드)     기준값 → 버튼 → 주사위 → 정도                ← 필요할 때만
 ├─ ⑤ 귀결 (코드)     상태, 위치, 수량, 시간, 계획과 사건, 감각 모으기
 ├─ ⑥ 서술 (LLM)     PC의 감각만 받아 글로 쓴다
 └─ ⑦ 확정 (코드)     한 번에 반영. 상태판
       └─ 턴과 턴 사이: 막힌 계획의 재수립, 채운 것의 정리
```

### ① 해석

- 받는 것: 선언, **PC가 아는 것만**(지금 장면에서 PC가 가리킬 수 있는 대상의 목록), 행동 유형의 목록.
- 진실을 받지 않는다. 플레이어의 말이 무엇을 가리키는지는 PC가 아는 범위에서 정해져야 한다.
- 내는 것:

```
행동 1  유형: 이동/운송        대상: 계산대 뒤       따르는 행동인가: 아니오
행동 2  유형: 물체/설비 조작    대상: 뒷문            수단: 손      의도: 열어 본다
말: (없음)
PC가 밝힌 내면: (없음)
세계에 대한 단정: (없음)        ← 있으면 시도나 발견 선언으로 바꿔 적는다
뜻이 모호한가: 아니오           ← 그렇다면 되묻는다
```

- 선언에 **따르는** 행동(뚜껑을 연다, 꺼낸다)을 채운다. 선언에 **없는 선택**은 채우지 않는다. [확정]
- "미리 해 두었다"는 지금의 시도로 바꾼다. [확정]
- 작고 빠른 모델로 한다. 유형은 닫힌 목록에서 고른다.

### ② 준비

코드가 한다. LLM을 부르지 않는다.

| 하는 일 | 내용 |
| --- | --- |
| 정보 모으기 | 행동의 유형이 "열어 볼 정보"를 정해 두었다. 그것을 장부에서 꺼낸다 |
| 대상의 확정 | 대상이 아직 실물이 아니면 확정의 사다리를 탄다: 저작된 것 → 사전에서 후보를 추림 → 사전에도 없음 |
| 뻔한 것의 처리 | 코드가 정할 수 있는 것은 정한다. 잠긴 문은 열리지 않는다. 물에 들어가면 방수가 아닌 착용물은 젖는다 |
| 권한 | 이 행동이 누구의 무엇을 건드리는지 찾는다 |
| 물을 것 추리기 | 코드가 정하지 못한 것만 물음으로 만든다 |

- **이 단계에서 턴이 끝날 수 있다.** 뻔히 되거나 뻔히 안 되는 행동이고, 주목할 인물도 없고, 채울 항목도 없으면 판단을 부르지 않고 귀결로 간다.
  판단 물음을 줄일수록 이런 턴이 는다. 대기와 비용이 함께 준다.

### ③ 판단

- 받는 것: 코드가 추린 물음과 그 후보, 물음에 필요한 **진실**, 주목할 인물의 앎·태도·가이드.
- 물음의 종류는 정해져 있다.

| 물음 | 답의 꼴 | 예 |
| --- | --- | --- |
| 빈 항목 채우기 | 그 항목에 정해진 값 | `바람막이(뒷골목)` → 거짓 |
| 사전에서 고르기 | 후보 가운데 하나 또는 몇 | 서랍 속에 있을 법한 것 → 후보에서 |
| 일어난 일 | 후보 가운데 | 이 일로 손상이 생기는 것은 → 후보에서 |
| 난이도와 방법 | 등급 | 어려움 / 적절함 |
| 걸린 것 | 정해진 종류에서 고르고 한 줄로 | 되면 무엇이 되는가, 탈은 무엇인가 |
| 인물의 반응 | 그 인물의 가이드가 허락하는 태도 가운데 + 말 | 막아선다 / "그 손 치우시오." |
| 사건의 선택 | 시작할 수 있는 후보 가운데 | |
| 걸리는 시간 | 등급 | 잠깐 / 몇 분 / 한참 |

- 인물의 **말**은 열린 출력이다. 판단 가운데 유일하게 글을 쓴다. 말투와 가이드를 받아 쓴다.
- 세계 전체를 캐시로 주는 곳은 여기다. [선택]

### ④ 판정

- [29](29-꿰는-것과-판정.md) §7 그대로다. 코드가 기준값을 계산하고, 버튼을 내고, 플레이어가 누르고, 여유로 정도를 낸다.
- 한 턴에 둘이 필요하면 연달아 낸다. [확정]
- 정도에 따른 귀결은 ③에서 받은 "되면 무엇이, 탈은 무엇인가"와 사전의 규칙에서 나온다. 버튼 뒤에 판단을 다시 부르지 않는다.
- 기만과 설득이 성공하면 상대를 구속한다. 인물의 반응을 ③에서 받을 때 **성공했을 때와 실패했을 때**를 함께 받는다.

### ⑤ 귀결

코드가 한다.

1. 확정된 일을 장부에 올릴 준비를 한다 (위치, 수량, 상태).
2. 흐른 시간만큼 PC와 주변의 상태를 계산한다 (환경 → 물건 → 인물).
3. 바뀐 사실을 가리키는 계획과 사건의 조건을 다시 평가한다.
4. **감각을 모은다**: PC가 이번 턴에 보고, 듣고, 맡고, 닿고, 몸으로 느낀 것.
5. 주목 안의 인물이 지각한 것을 그들의 앎에 넣는다.

- 멈추는 곳: 판정이 실패했다, 다른 인물이 끼어들 수 있다, PC가 새로 지각한 것이 있다, 되돌릴 수 없는 일인데 유저가 말하지 않았다(확인을 묻는다).
  뒤의 행동은 일어나지 않는다.

### ⑥ 서술

- 받는 것: 되읽기, 실행된 행동, **감각 모으기의 결과**(새것이 중심. 이미 쓴 감각에는 표시), 인물의 말, 인식 단계에 맞는 부름말, 유저가 밝힌 내면, 문체.
- 받지 않는 것: PC가 모르는 사실과 이름, 남의 속마음.
- 감각 중심으로, 채울 새것이 없으면 짧게. 선언에 따르는 몸의 움직임만 채운다. PC 대신 결론을 내리지 않는다. [확정]
- 서술자가 재료에 없는 것을 지어낼 까닭이 줄어든다. 볼 것은 이미 확정되어 감각으로 들어와 있다.

### ⑦ 확정

- 턴의 모든 변화를 한 번에 반영한다. 도중에 실패하면 아무것도 반영하지 않는다.
- 상태판을 장부에서 그린다.

### 턴과 턴 사이

플레이어가 읽고 다음 선언을 쓰는 동안 뒤에서 한다. 대기에 걸리지 않는다.

- 막힌 계획의 재수립
- 이번 턴에 채운 항목의 정리 (사전의 "채운 것"으로)
- 주목 밖 인물의 정산 준비

## 3. 대기

| 구간 | 그 안의 LLM 호출 |
| --- | --- |
| 선언 → 버튼 | 해석, 판단 |
| 선언 → 첫 문장 (판정이 없는 턴) | 해석, 판단, 서술의 시작 |
| 버튼 → 첫 문장 | 서술의 시작 |
| 선언 → 첫 문장 (판단이 필요 없는 턴) | 해석, 서술의 시작 |

- 가장 긴 것이 "선언 → 첫 문장, 판정 없는 턴"이다. 호출 셋이 차례로 놓인다.
- 줄이는 길:
  - 해석은 작은 모델로, 사고 없이.
  - 서술은 사고를 쓰지 않거나 아주 적게. 구 기록에서 서술 호출 12초의 큰 부분이 사고였다.
  - **되읽기 한 줄을 해석 직후에 먼저 보낸다.** 플레이어는 1~2초 안에 첫 반응을 받는다.
  - 판단이 필요 없는 턴을 늘린다 (§2 ②).
- 15초 안에 드는지는 **측정해야 안다.**

## 4. 인물은 누가 움직이는가 [잠정]

- 기본: 판단(③)이 주목 안의 인물을 움직인다. 인물의 가이드(경우별 태도와 판단 방식)를 받고, **그 인물이 아는 것**을 따로 떼어 받는다.
- 기만과 설득은 판정이 강제하므로, 인물이 "받아들일지"를 판단이 정하는 일은 없다. 판단이 정하는 것은 **어떻게** 굴복하고 **어떻게** 버티는가다.
- 인물을 따로 부르는 호출(그 인물의 앎만 받는)은 선택으로 남긴다. 값이 있는지는 측정으로 가른다 ([21](21-주목-대기-실패.md) §4의 세 방식).
- 주목 밖의 인물은 무리로 남고, 주목이 돌아올 때 정산한다.

## 5. 실패

[21](21-주목-대기-실패.md) §6의 원칙을 그대로 둔다. 새 흐름에 맞춘 물러서기:

| 실패한 곳 | 물러서는 길 |
| --- | --- |
| 해석 | 다시 시도 → 다른 모델 → 플레이어에게 알리고 선언을 보존 |
| 판단 | 다시 시도 → 다른 모델. 닫힌 물음이므로 **물음마다** 기본값을 둘 수 있다 (난이도는 보통, 채우기는 위에서 물려받은 값) |
| 서술 | 다시 시도 → 다른 모델 → 짧은 서술 → 되읽기 한 줄과 감각 목록 |
| 턴 사이의 일 | 밀린 채로 다음 턴을 받는다 |

- 닫힌 판단은 실패에도 강하다. 후보 가운데 기본값이 있으면 판단 없이도 턴이 돈다.
- 한 일은 다시 하지 않는다. 주사위의 눈은 같은 턴 안에서 유지한다. [확정]

## 6. 미결

| 쟁점 | 내용 |
| --- | --- |
| 해석과 판단을 한 호출로 합칠 수 있는가 | 합치면 대기가 줄지만, 해석이 진실을 보게 된다 |
| 판단의 물음이 턴마다 몇 개나 되는가 | 많으면 한 호출의 부담이 크다. 측정 |
| 유형마다의 "열어 볼 정보"와 "고칠 수 있는 정보" | 4단계 (행동선언 18유형) |
| 감각 모으기의 경계 사례 | 옆방의 소리 같은 것. 항목(차음)으로 풀 수 있는 만큼 풀고 남는 것 |
| 인물의 말을 판단에서 쓸 것인가, 서술에서 쓸 것인가 | 판단에서 쓰면 서술자가 고치지 않는다. 서술에서 쓰면 호출 하나가 가벼워진다 |
